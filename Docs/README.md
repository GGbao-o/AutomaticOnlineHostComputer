# 自动化产线上位机系统

## 项目简介
本项目用于协调无人车间内多设备自动化运行，涵盖上料、双头镗加工、打标、斜床加工、动平衡、研磨等全流程。上位机负责调度管理、流程控制与状态监控，底层实时运动控制由各设备 PLC/CNC 完成。

## 系统架构
- **上位机**：C# + WPF (.NET8)
- **通信协议**：Modbus TCP（研磨机、天车、锦州斜床）、FANUC FOCAS（沈阳斜床）、Syntec SDK（双头镗）、三菱 MC 协议（货叉/辅助 PLC）、文件握手协议（打标机）
- **控制模式**：上位机下发目标坐标与启停指令，PLC/CNC 执行底层闭环控制

## 核心功能
- [x] 产线全流程生产调度与设备协同互锁
- [x] 10 台斜床 + 2 台双头镗 + 4 台研磨机的任务分配
- [x] 动平衡工序自动判断与分流
- [x] 线体能力匹配（工件长度 → 双头镗分派）
- [x] 设备状态实时监视与动画仿真
- [x] 打标机非标准文件握手协议集成

## 开发环境
- Visual Studio 2022, .NET 8.0
- 依赖库：NModbus4, CommunityToolkit.Mvvm, FOCAS 库, Syntec.OpenCNC
