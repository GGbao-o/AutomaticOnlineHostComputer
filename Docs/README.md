## 维护规则

1. 地址调整同步协议分册；阶段、锁、缓存调整同步设备交互和业务总文档；弹窗和恢复调整同步运维说明。
2. 分开写清命令发送、反馈到位、物理完成、软件状态与人工处置。通信成功或软件锁释放不能作为现场安全证明。
3. 异常必须核对catch之后的finally，不能把catch中的暂存状态写成动作最终状态。
4. 配置必须区分模型默认、仓库配置和实际运行目录配置；外部改文件没有自动热加载保证。
5. 明确M818/M821等软件缓存键与PLC位的不同含义；保留历史方案原始背景，附当前差异提示。
6. 本导航仅链接实际存在的文档。曾列出的完整流程兼容入口、寄存器速查总表、独立技术/日志手册等路径当前不存在，相关现行内容由上表文档承载。
