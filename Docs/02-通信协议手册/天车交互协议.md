# 天车交互协议（汇川 PLC，Modbus TCP）

## 概述
- **设备**：前天车、后天车（均使用汇川 PLC）
- **协议**：Modbus TCP
- **端口**：502
- **地址段**：D5000~D5029（读取），D3101~D3137（写入目标信息），D4000~D4518（控制写入）

## 自动绝对运动的到位与超时（2026-07-28）

上位机写目标坐标和D4520~D4522脉冲后，持续读取实际显示坐标；只有本次参与轴全部落入目标`±5mm`才视为到位。自动天车XY和Z每个阶段默认最多等待120秒，配置键为`absMove.xyTimeoutMs`、`absMove.zTimeoutMs`。复合移动按阶段分别计时，不共用旧的240秒总等待。

超时后上位机先尝试写`D4518=2→0`停止伺服，再复位参与轴触发位并抛出包含最后实际XYZ和未到位轴的运动超时异常。PLC/通信未能确认停止时，该异常仍按“位置未知”处理；不得继续下一步Z下降、退磁、回原点或自动派发。
