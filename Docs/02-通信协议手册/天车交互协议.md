# 天车交互协议（汇川 PLC，Modbus TCP）

## 概述
- **设备**：前天车、后天车（均使用汇川 PLC）
- **协议**：Modbus TCP
- **端口**：502
- **地址段**：D5000~D5029（读取），D3101~D3137（写入目标信息），D4000~D4518（控制写入）

---
