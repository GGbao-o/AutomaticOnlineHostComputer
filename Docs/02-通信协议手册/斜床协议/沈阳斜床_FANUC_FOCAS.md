# 沈阳斜床通信地址（FANUC FOCAS / 宏变量接口）

## 概述
- **设备数量**：6 台
- **系统**：FANUC CNC
- **接口**：FOCAS 库，读写宏变量
- **变量类型**：均为宏变量 `#1000` 起

---

| 功能描述 | 宏变量号 | 备注 |
|---------|----------|------|
| 机床准备就绪 | #1000 | 读，1=就绪 |
| 请求数据 | #1001 | 读，1=请求 |
| 尾座夹紧到位 | #1003 | 读，1=到位 |
| 请求下料 | #1004 | 读，1=请求 |
| 尾座分开到位 | #1005 | 读，1=到位 |
| 自动门开 | #1006 | 读，1=开 |
| Y 轴安全位置 | #1007 | 读 |
| Z 轴安全位置 | #1009 | 读 |
| 刀架安全位置 | #1010 | 读 |
| X 轴安全位置 | #1011 | 读 |
| 机床操作模式 | #1012 | 读，手动0/人工自动1/全自动2 |
| 刀具 1 寿命到期 | #1013 | 读，1=到期 |
| 刀具 2 寿命到期 | #1014 | 读，1=到期 |
| 版辊长度 | #800 | 读，FLOAT |
| 斜车成活直径 | #801 | 读，FLOAT |
| 堵孔 | #802 | 读，FLOAT |
| 加工模式 | #909 | 写，粗车1/精车2/研磨3/粗精4/精磨5/粗精磨6 |
| 数据下发完成 | #1101 | 写，1=下发完成 |
| 天车上料到位 | #1102 | 读，1=到位 |
