# 沈阳斜床协议（FANUC FOCAS 宏变量）

> 依据 `FanucSkewBedAddress.cs`、`FanucSkewBedService.cs` 和两条后端引擎整理，更新时间：2026-06-27。

## 1. 适用设备

| 线路 | 工位 | 数量 | 协议 | 默认端口 |
|------|------|:---:|------|:---:|
| 1号线 | ST112 | 1 | FANUC FOCAS2，宏变量读写 | 8193 |
| 2号线 | ST606~ST610 | 5 | FANUC FOCAS2，宏变量读写 | 8193 |

设备 IP 和端口优先从数据库 `machine` 表读取。当前生产实现通过 `_sdk.GetMacro/SetMacro` 访问宏变量，不使用旧文档所写的 PMC F/G 地址换算。

## 2. CNC到上位机状态

| 宏变量 | 信号 | 当前代码用途 |
|:---:|------|------|
| #1000 | 机床准备就绪 | `IsMachineReadyAsync` |
| #1001 | 请求数据 | 斜床允许上位机下发加工参数 |
| #1002 | 请求上料 | 允许后天车送料 |
| #1003 | 尾座夹紧到位 | 上料退磁前必须确认 |
| #1004 | 请求下料 | 加工完成，允许后天车取料 |
| #1005 | 尾座分开到位 | 下料时Y轴退出顶尖前必须确认 |
| #1006 | 自动门开 | 地址已定义，当前后端主流程未单独派发检查 |
| #1007 | Y轴安全位置 | 地址已定义 |
| #1009 | Z轴安全位置 | 地址已定义 |
| #1010 | 刀架安全位置 | 地址已定义 |
| #1011 | X轴安全位置 | 地址已定义 |
| #1012 | 操作模式 | 0手动、1半自动、2全自动，地址已定义 |
| #1013/#1014 | 刀具寿命到期 | 地址已定义 |

`ReadSignalsAsync` 一次读取 #1001~#1005，并在同一个服务锁内形成快照；任何一次读取异常都不会发布半新半旧状态。

## 3. 上位机写入

### 3.1 加工参数

| 宏变量 | 内容 | 格式 |
|:---:|------|------|
| #800 | 版辊长度 | double，mm |
| #801 | 斜车成活直径 | double，已叠加站号直径补偿 |
| #802 | 堵孔尺寸/版孔类型 | double |
| #909 | 加工模式 | int |

`SendMachiningParamsAsync` 写入后会读回校验，最多3次。只有长度、直径、堵孔和模式全部匹配，才写 #1101=1。

### 3.2 握手输出

| 宏变量 | 信号 | 写入时机 |
|:---:|------|------|
| #1101 | 数据下发完成 | 参数写入并读回校验成功后 |
| #1102 | 天车上料到位 | 后天车已到装料位置，允许尾座夹紧 |
| #1103 | 天车上料完成 | 尾座夹紧、退磁、Z升安全后 |
| #1104 | 天车下料到位 | 后天车吸住工件，允许尾座分开 |
| #1105 | 天车下料完成 | 尾座分开、Y退出、Z升安全后 |
| #651 | 尾座停止 | 异常处理专用 |

正常握手会在进入下一阶段前清理上一个上位机输出，避免旧的1被下一循环误识别。人工应急清理会把 #800/#801/#802/#909/#1101~#1105 全部写0，但不控制天车或机床物理动作。

## 4. 上料握手

```text
#1001=1 请求数据
  -> 写 #800/#801/#802/#909并读回校验
  -> #1101=1 数据完成
  -> 等 #1002=1 请求上料
  -> 后天车到位并写 #1102=1
  -> 等 #1003=1 尾座夹紧
  -> 后天车退磁、Z升安全
  -> 清上一阶段输出并写 #1103=1 上料完成
```

## 5. 下料握手

```text
#1004=1 请求下料
  -> 后天车到位、充磁并由X11确认吸住
  -> 写 #1104=1 下料到位
  -> 等 #1005=1 尾座分开
  -> Y退出顶尖位置、Z升安全
  -> 清上一阶段输出并写 #1105=1 下料完成
```

## 6. 连接与异常

- `FanucSkewBedService` 使用独立工作线程承载同步 FOCAS SDK 调用。
- 每个服务内部用 `SemaphoreSlim` 串行化 SDK 访问。
- 调用失败时断开并重连，默认最多3次；状态快照读取只尝试1次，失败即保持本轮信号无效。
- 连接建立、断开和超时最终落到 FOCAS 的 `cnc_allclibhndl3`、`cnc_freelibhndl` 等接口。
- 物理工件已被天车吸住或已放下但握手未确认时，后端引擎暂停并保留工件数据。
