# 沈阳斜床通信地址（FANUC FOCAS / 宏变量接口）

## 概述
- **设备数量**：1台 1号线 (ST605) + 5台 2号线 (ST606~ST610)
- **系统**：FANUC CNC
- **接口**：FOCAS 库，读写宏变量
- **代码**：`FanucSkewBedService`（Communication/DeviceServices/）、`FanucSkewBedAddress`（Communication/DeviceAddresses/）
- **变量类型**：均为宏变量 `#1000` 起

---

## 状态读取（CNC → 上位机）

| 宏变量 | 信号名称 | 值说明 |
|:---:|------|------|
| #1000 | 机床准备就绪 | 0=未就绪，1=就绪 |
| #1012 | 机床操作模式 | 0=手动，1=人工自动，2=全自动 |
| #1001 | **请求数据** | 0=无请求，1=请求上位机下发参数 |
| #1002 | **请求上料** | 0=无请求，1=请求天车送料 |
| #1003 | **尾座夹紧到位** | 0=未夹紧，1=已夹紧 |
| #1004 | **请求下料** | 0=无请求，1=请求天车取料 |
| #1005 | **尾座分开到位** | 0=未分开，1=已分开 |
| #1006 | 自动门开 | 0=门关，1=门已打开 |
| #1007 | Y轴安全位置 |  |
| #1009 | Z轴安全位置 |  |
| #1010 | 刀架安全位置 |  |
| #1011 | X轴安全位置 |  |
| #1013 | 刀具1使用寿命到期 | 0=正常，1=寿命到期 |
| #1014 | 刀具2使用寿命到期 | 0=正常，1=寿命到期 |

---

## 参数读取（CNC → 上位机）

| 宏变量 | 信号名称 | 格式 | 说明 |
|:---:|------|:---:|------|
| #800 | 版辊长度 | FLOAT | mm |
| #801 | 斜车成活直径 | FLOAT | mm |
| #802 | 堵孔 | FLOAT | mm |

---

## 控制写入（上位机 → CNC）

| 宏变量 | 信号名称 | 值说明 |
|:---:|------|------|
| #909 | 加工模式 | 粗车1/精车2/研磨3/粗精4/精磨5/粗精磨6 |
| #1101 | **数据下发完成** | 写1导通 |
| #1102 | **天车上料到位** | 写1导通（=上料到达锁紧位置） |
| #1103 | **天车上料完成** | 写1导通（天车退磁+Z升安全高度后写） |
| #1104 | **天车下料到位** | 写1导通（天车充磁取料后写） |
| #1105 | **天车下料完成** | 写1导通（天车Z升安全高度后写） |
| #651 | 尾座停止 | 写1导通（天车异常时停止尾座） |

---

## 握手流程（与研磨机对照）

| 步骤 | 研磨机信号 | 沈阳斜床等价信号 |
|:---:|------|:---:|
| PLC请求数据 | 40001-9 / R7301 | **#1001** |
| 上位机写参数 | 40012~40014 / R7316~7318 | #800, #801, #802 + #909 |
| 数据传输完成 | 40011-9 / R7311 | **#1101** |
| PLC请求上料 | 40001-10 / R7302 | **#1002** |
| 天车到位=上料到达 | 40011-10 / R7312 | **#1102** |
| PLC夹紧完成 | 40001-11 / R7303 | **#1003** |
| 天车退磁+Z升=上料完成 | 40011-11 / R7313 | **#1103** |
| PLC加工完成=请求下料 | 40001-12 / R7304 | **#1004** |
| 天车到位=下料到达 | 40011-12 / R7314 | **#1104** |
| PLC松开完成 | 40001-13 / R7305 | **#1005** |
| 天车Z升=下料完成 | 40011-13 / R7315 | **#1105** |

> ✅ 沈阳斜床握手信号与研磨机完全对应，上料/下料流程可直接复用三段式模式。
