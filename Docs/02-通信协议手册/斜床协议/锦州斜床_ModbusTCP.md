# 锦州斜床协议（信捷 PLC，Modbus TCP）

> 依据 `ModbusSkewBedAddress.cs`、`ModbusSkewBedService.cs` 与1号线后端引擎整理。适用 ST108、ST109、ST111、ST110；端口502，单元ID=1。

## 1. 数据格式与服务边界

- 状态和控制命令使用 FC03 读、FC06 写的 `INT16` 保持寄存器。
- 版长、堵孔、成活直径和加工时间使用两个连续寄存器的 IEEE754 `FLOAT`，高字在前。
- 当前服务只维护本页列出的地址；未在地址定义或服务快照中的现场点位，不能作为程序已使用的自动判断条件。

## 2. CNC/PLC 到上位机状态

| 地址 | 含义 | 业务用途 |
|---:|---|---|
| 10350 | 机床准备就绪=1 | 候选机床必须就绪。 |
| 10351 | 操作模式：0手动/1人工自动/2全自动 | 状态快照。 |
| 10352 | 请求数据=1 | 允许上位机写参数。 |
| 10354 | 请求上料=1 | 允许后天车开始上料交接。 |
| 10355 | 尾座顶紧=1 | 上料退磁前必须确认。 |
| 10357 | 请求下料=1 | 加工完成，请求后天车取料。 |
| 10358 | 尾座张开=1 | 下料时Y退出顶尖前必须确认。 |
| 10359 | 门开=1 | 当前状态快照字段；是否作为某一动作前置由后端流程决定。 |
| 10360~10362 | 磨头上限、X/Y安全位置 | 当前状态快照字段。 |
| 10363/10364 | 刀具1/2寿命到 | 当前状态快照字段。 |

| 地址 | 数据 | 格式 |
|---:|---|---|
| 10300~10301 | 版长 | FLOAT，mm |
| 10302~10303 | 堵孔尺寸 | FLOAT，mm |
| 10304~10305 | 成活直径 | FLOAT，mm |
| 10394~10395 | 加工时间 | FLOAT，分钟 |

## 3. 上位机控制输出

| 地址 | 写入 | 含义 |
|---:|---|---|
| 10370 | 模式值 | 加工模式：1粗车、2精车、3研磨、4粗精、5精磨、6粗精磨。 |
| 10371 | 1/0 | 远程尾座顶紧；上料到位后置1，进入后续阶段前按级联规则清0。 |
| 10372 | 1/0 | 远程启动；退磁、Z安全后置1，后续阶段清0。 |
| 10373 | 1/0 | 远程尾座张开；下料天车到位并确认持件后置1。 |
| 10374 | 1/0 | 尾座停止；异常处理使用，正常下料阶段也按流程清理。 |

当前服务不会假定 PLC 自动复位这些命令。`ClearMachiningModeAsync`、`ClearTailstockClampAsync`、`ClearRemoteStartAsync`、`ClearTailstockOpenAsync` 分别按级联阶段清0；主页面单机清空则把参数和10370~10374全部写0。

## 4. 上料与下料顺序

```text
10352=1请求数据
  → 写10300~10305与10370
  → 等10354=1
  → 后天车物理取板、到机床装料位 → 写10371=1
  → 等10355=1，退磁并Z升安全 → 清前一输出、写10372=1

10357=1请求下料
  → 后天车到位、充磁、X11确认持件 → 写10373=1
  → 等10358=1，Y退出、Z升安全 → 清前一输出/写10374处理完成阶段
```

参数写成功不等于机床已加工，命令写成功也不等于天车和尾座已完成物理交接；后端流程使用后续请求/反馈、X11、实际位置和安全Z共同闭环。

## 5. 通信与异常边界

- `ModbusSkewBedService` 对通信异常会断线重连并重试。读状态失败不得按“未请求/已安全”处理。
- 参数写目前没有逐项读回校验；有副作用命令的响应丢失时，重试成功不能证明第一次未执行。
- 工件已吸住或已放下但10371~10374闭环未知时，后端引擎按实际物理阶段暂停、保留工件或要求人工确认；仅清寄存器、清页面状态或释放软件锁不等于现场已安全。

## 6. 现场待确认项

门开、尾座最大退位/夹紧限位、远程启动保持为1的PLC响应、XYZ抖动、磁铁反馈和下压/有板信号，属于现场电气/PLC或机械验证项。它们不在当前 `ModbusSkewBedService` 的已实现确认逻辑中，不能写成“程序已处理”；如需改动，应单独记录现场证据和对应源码变更。
