# 锦州斜床通信地址（迅捷 PLC，Modbus TCP）

## 概述
- **设备数量**：4 台（ST601~ST604，1号线）
- **协议**：Modbus TCP，端口 502，单元 ID = 1
- **地址段**：保持寄存器 10300~10374，FC03 读 / FC06 写
- **代码**：`ModbusSkewBedService`（Communication/DeviceServices/）、`ModbusSkewBedAddress`（Communication/DeviceAddresses/）

---

## 状态读取（FC03，INT16 单寄存器）

| Modbus地址 | 信号名称 | 值说明 |
|:---:|------|------|
| 10350 | 准备就绪 | 0=未就绪，1=就绪 |
| 10351 | 操作模式 | 0=手动，1=人工自动，2=全自动 |
| 10352 | **请求数据** | 0=无请求，1=请求上位机下发参数 |
| 10354 | **请求上料** | 0=无请求，1=请求天车送料 |
| 10355 | **尾座顶紧信号** | 0=未顶紧，1=已顶紧 |
| 10357 | **请求下料** | 0=无请求，1=请求天车取料 |
| 10358 | **尾座张开到位** | 0=未张开，1=已张开 |
| 10359 | 门开到位 | 0=门关，1=门已打开 |
| 10360 | 磨头上限 | 0=未在上限，1=在上限位 |
| 10361 | X轴到位 | 0=未到位，1=在安全位置 |
| 10362 | Y轴到位 | 0=未到位，1=在安全位置 |
| 10363 | 刀具1寿命到 | 0=正常，1=寿命到期 |
| 10364 | 刀具2寿命到 | 0=正常，1=寿命到期 |
| 10339 | 设备报警 | 0=正常，非0=故障 |

---

## 参数读取（FC03，FLOAT 双寄存器，IEEE 754 单精度，高字在前）

| Modbus地址 | 信号名称 | 说明 | 寄存器数 |
|:---:|------|------|:---:|
| 10300~10301 | 版长 | mm | 2 |
| 10302~10303 | 堵孔尺寸 | mm | 2 |
| 10304~10305 | 成活直径 | mm | 2 |
| 10394~10395 | 加工时间 | 分钟 | 2 |

---

## 控制命令（FC06，INT16 单寄存器写）

| Modbus地址 | 信号名称 | 值说明 |
|:---:|------|------|
| 10370 | 加工模式 | 1=粗车，2=精车，3=研磨，4=粗精，5=精磨，6=粗精磨 |
| 10371 | **远程尾座顶紧** | 写1导通（=上料到达锁紧位置） |
| 10372 | **远程启动** | 写1导通（=上料完成，PLC开始加工） |
| 10373 | **远程尾座张开** | 写1导通（=下料到达位置） |
| 10374 | **尾座停止** | 写1导通（=下料完成/天车异常时停止尾座） |

---

## 握手流程（与研磨机对照）

| 步骤 | 研磨机信号 | 锦州斜床等价信号 |
|:---:|------|------|
| PLC请求数据 | 40001-9 / R7301 | **10352** |
| 上位机写参数 | 40012~40014 / R7316~7318 | 10300~10305 + 10370 |
| 数据传输完成 | 40011-9 / R7311 | PLC自动识别参数写入完成 |
| PLC请求上料 | 40001-10 / R7302 | **10354** |
| 天车到位=上料到达 | 40011-10 / R7312 | **10371**（远程尾座顶紧） |
| PLC夹紧完成 | 40001-11 / R7303 | **10355**（尾座顶紧信号） |
| 天车退磁+Z升=上料完成 | 40011-11 / R7313 | **10372**（远程启动） |
| PLC加工完成=请求下料 | 40001-12 / R7304 | **10357** |
| 天车到位=下料到达 | 40011-12 / R7314 | **10373**（远程尾座张开） |
| PLC松开完成 | 40001-13 / R7305 | **10358**（尾座张开到位） |
| 天车Z升=下料完成 | 40011-13 / R7315 | **10374**（尾座停止） |

> ⚠️ 锦州斜床没有独立的"数据传输完成"DO信号——上位机写完参数后，PLC通过检测寄存器值变化自动进入下一状态。
> 所有控制命令（10371~10374）均为写1导通，PLC执行后自动复位。
