## 特殊地址计算规则

- **Modbus TCP（新代双头镗/新代研磨机 R 区）**：地址 = R值 × 2 + 1。例如 R6101 → 12203。

- **三菱 MC 协议**：货叉 M区使用位读写+nibble编码；MC63/64/65 使用16点对齐字读写。详见《货叉及辅助PLC协议_三菱MC》。

- **FANUC FOCAS**：当前 `FanucSkewBedService` 通过宏变量接口读写 #800~#1105，默认端口8193。

### 读写结果的统一口径

1. **PLC/CNC 输入或现场 X 信号**表示设备报告的状态；它不是软件缓存。
2. **软件缓存**保存工件身份与工艺，不能替代“现场有板/允许动作”信号。
3. **写命令成功返回**只表示本次通信调用成功返回；除非源码随后读取了位置、反馈位或下游确认，不得表述为物理动作已经完成。
4. 当前多数设备服务对通信异常会重连重试。读操作可安全重试；对边沿命令、运动、磁铁和交接写，响应丢失时仍可能存在“对端已执行但上位机未知”的边界，需由流程的后续状态确认或人工处置。
