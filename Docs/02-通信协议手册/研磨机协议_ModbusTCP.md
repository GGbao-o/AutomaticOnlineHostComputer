**# 研磨机通信协议（Modbus TCP）

## 概述
- **协议**：Modbus TCP，端口 502
- **UnitId 规则**：
  - TypeA（西门子）：**unitId = 1**（西门子 Modbus TCP Server 默认）
  - TypeB（新代）：**unitId = IP 末段**（如 192.168.2.90 → 90，与数控站号一致）
- **设备**：4 台研磨机，两款系统各 2 台（IP 以数据库 `machine` 表为准）
  - 研磨机 1（ST701）→ TypeB 新代数控，192.168.2.90
  - 研磨机 2（ST702）→ TypeB 新代数控，192.168.2.91
  - 研磨机 3（ST703）→ TypeA 西门子 PLC，192.168.2.92
  - 研磨机 4（ST704）→ TypeA 西门子 PLC，192.168.2.93
- **TypeA 与 TypeB 的研磨流程完全一致**，仅寄存器地址体系不同
- **1 台 PLC = 1 台研磨机**
- **代码**：`PlcGrinderService`（Communication/DeviceServices/）、`PlcGrinderAddress`（Communication/DeviceAddresses/）

## TypeA — 西门子 PLC 点位表

### 通信地址说明
- 地址格式 `40001-8` 表示保持寄存器 40001 的第 8 位（从 bit0 右起，0-indexed）
- DI（机床→上位机）：FC03 读保持寄存器，Modbus 地址 = 通信地址 - 40001（零起始）
- DO（上位机→机床）：FC06 写单个寄存器（读-改-写，保护其他 bit）
- Word 参数：FC06 直接写入整字值
- DO 信号规范：**3 秒长信号**（写 1 → 等 3000ms → 写 0）

### 输入信号（机床 → 上位机，只读）— 40001

| 序号 | 站号 | 点位名称 | 通信地址 | 数据类型 | 备注 |
|:---:|------|------|------|:---:|------|
| 1 | 4#/5# | 1Hz 心跳 | 40001-8 | BOOL | PLC 心跳脉冲。连续读两次（间隔 500ms），值有变化=PLC 存活 |
| 2 | 4#/5# | 请求数据 | 40001-9 | BOOL | PLC=1 请求上位机下发加工参数（直径/版孔/长度） |
| 3 | 4#/5# | 请求上料 | 40001-10 | BOOL | PLC=1 请求天车送版辊到锁紧位置 |
| 4 | 4#/5# | 锁紧完成上料退出 | 40001-11 | BOOL | PLC=1 尾座已夹紧，天车可松开版辊并上移到原点 |
| 5 | 4#/5# | 请求下料 | 40001-12 | BOOL | PLC=1 加工完成，请求天车下来取工件 |
| 6 | 4#/5# | 松开完成 | 40001-13 | BOOL | PLC=1 尾座已松开，天车可带工件上移到原点 |
| 7 | 4#/5# | 加工中 | 40001-14 | BOOL | 仅上位机显示用，1=正在加工，不参与握手逻辑 |
| 8 | 4#/5# | 门开 | 40001-15 | BOOL | 1=安全门已打开。**天车取料/放料前必须确认门开=1（安全门打开，天车才能接近研磨机取放工件）** |
| 9 | 4#/5# | 报警 | 40001-0 | BOOL | 1=设备报警 |
| 10 | 4#/5# | 磨石 1 厚度报警 | 40001-1 | BOOL | 1=磨石 1 厚度异常。该机停止自动分配新任务；不暂停研磨引擎 |
| 11 | 4#/5# | 磨石 2 厚度报警 | 40001-2 | BOOL | 1=磨石 2 厚度异常。同上 |

> 40002~40010 为预留，暂不使用。

### 输出信号（上位机 → 机床，读写）— 40011

| 序号 | 站号 | 点位名称 | 通信地址 | 数据类型 | 备注 |
|:---:|------|------|------|:---:|------|
| 1 | 4#/5# | 数据传输完成 | 40011-9 | BOOL | 上位机下发参数完成后写 1，3 秒长信号 |
| 2 | 4#/5# | 上料到达锁紧位置 | 40011-10 | BOOL | 天车将版辊运到位后写 1，3 秒长信号 |
| 3 | 4#/5# | 上料完成 | 40011-11 | BOOL | 天车松开版辊上移到原点后写 1，3 秒长信号 |
| 4 | 4#/5# | 下料到达位置 | 40011-12 | BOOL | 天车下来吸到工件后写 1，3 秒长信号 |
| 5 | 4#/5# | 下料完成 | 40011-13 | BOOL | 天车带工件上移到原点后写 1，3 秒长信号 |

> 40011-8（天车心跳）暂不使用，仅使用 40001-8 的 PLC 心跳。

### 输出 Word（上位机 → 机床）— 40012~40014

| 序号 | 站号 | 点位名称 | 通信地址 | 数据类型 | 备注 |
|:---:|------|------|------|:---:|------|
| 1 | 4#/5# | 版辊直径 | 40012 | Word | 单位 mm |
| 2 | 4#/5# | 版孔 | 40013 | Word | 1=大孔，2=小孔 |
| 3 | 4#/5# | 版棍长度 | 40014 | Word | 单位 mm |

> 40015~40020 为预留，暂不使用。

## TypeB — 新代数控 R 区寄存器

### 地址转换
Modbus 地址 = R 编号 × 2 + 1。例：R7301 → 14603。

### 输入信号（机床 → 上位机，读）

| R编号 | Modbus 地址 | 信号名称 | 值说明 |
|:---:|------|------|------|
| R7301 | 14603 | 请求数据 | 0=关闭，1=请求数据 |
| R7302 | 14605 | 请求上料 | 0=关闭，1=请求上料 |
| R7303 | 14607 | 锁紧完成上料退出 | 0=关闭，1=锁紧完成 |
| R7304 | 14609 | 请求下料 | 0=关闭，1=请求下料 |
| R7305 | 14611 | 松开完成下料退出 | 0=关闭，1=松开完成 |
| R7306 | 14613 | 加工中 | 0=加工完成，1=加工中 |
| R7307 | 14615 | 安全门状态 | 0=门关闭，1=门打开 |
| R7308 | 14617 | 设备运行状态 | 0=空闲，1=忙碌中，2=机床报警 |

### 输出信号（上位机 → 机床，写）

| R编号 | Modbus 地址 | 信号名称 | 写入方式 |
|:---:|------|------|------|
| R7311 | 14623 | 数据传输完成 | 3 秒长信号（写 1→3s→0） |
| R7312 | 14625 | 上料到达锁紧位置 | 同上 |
| R7313 | 14627 | 上料完成 | 同上 |
| R7314 | 14629 | 下料到达松开位置 | 同上 |
| R7315 | 14631 | 下料完成 | 同上 |
| R7316 | 14633 | 版辊直径 | Word，mm |
| R7317 | 14635 | 版辊加工模式 | 1=大孔，2=小孔 |
| R7318 | 14637 | 版辊长度 | Word，mm |

> 握手规范：上位机写 1 触发 → PLC 执行动作并置反馈 R 地址=1 → 上位机读到后写 0 复位。

## 研磨流程（TypeA / TypeB 通用）

> TypeA 走 40001 bit / TypeB 走 R 区寄存器，流程完全一致。以下以 TypeA 地址为例。

```
1. 机台切联机 → PLC 请求数据=1（TypeA: 40001-9 / TypeB: R7301）
   → 上位机检查磨石厚度报警（仅 TypeA: 40001-1/40001-2）：有报警则停止该机自动分配、提示更换磨石；其他研磨机继续，不暂停研磨引擎
   → 上位机写版辊直径、版孔、版长（TypeA: 40012~40014 / TypeB: R7316~R7318）
   → 上位机写数据传输完成=1（TypeA: 40011-9 / TypeB: R7311），保持 3s→0
   → PLC 清请求数据，置请求上料=1（TypeA: 40001-10 / TypeB: R7302）

2. 天车将版辊运到位
   → 天车取料/放料前必须确认门开=1（TypeA: 40001-15 / TypeB: R7307），安全门打开后天车才能接近研磨机取放工件  安全门开的时候是1 不开是0 要检测地址是否为1
   → 上位机写上料到达锁紧位置=1（TypeA: 40011-10 / TypeB: R7312），3s→0
   → PLC 清请求上料，操作尾座夹紧
   → 夹紧完成 → PLC 置锁紧完成上料退出=1（TypeA: 40001-11 / TypeB: R7303）

3. 天车松开版辊，向上移动到原点
   → 上位机写上料完成=1（TypeA: 40011-11 / TypeB: R7313），3s→0
   → PLC 自动开始加工（加工中 TypeA: 40001-14 / TypeB: R7306 =1）
   → 加工完成 → 加工中=0

4. PLC 请求下料=1（TypeA: 40001-12 / TypeB: R7304）
   → 天车到研磨机位置，确认门开=1（TypeA: 40001-15 / TypeB: R7307）
   → 天车充磁吸住工件（防止松开尾座后工件掉落）
   → 上位机写下料到达位置=1（TypeA: 40011-12 / TypeB: R7314），3s→0
   → PLC 松开尾座 → 松开完成=1（TypeA: 40001-13 / TypeB: R7305）
   → 天车 Z 升到安全高度（绝对 Z=400），准备去往下料架

5. 天车带工件移动到下料架位置（ST710，数据库 xyz 坐标）
   → Z 下降到放料位置 → 退磁放下工件 → Z 升到安全高度
   → 上位机写下料完成=1（TypeA: 40011-13 / TypeB: R7315），3s→0
   → PLC 松开完成=0，请求数据=1（回到步骤1，开始下一循环）
```

### 天车调度策略（GrindingFlowEngine 主循环）

每 500ms 一轮，按以下顺序执行：

```
① 扫描 4 台研磨机状态
② 卡死检测（Loading/Unloading/WaitingForUnload 超过安全观察时间 → 暂停引擎，保留状态、Pending和缓存）
③ 加工监视（Machining + 请求下料=1 → WaitingForUnload）
④ 【优先】下料（WaitingForUnload + 天车空闲 → 取工件放 ST710）
⑤ 【次之】上料（Idle+请求数据=1 + 天车空闲 → ST709 取料送研磨机）
```

- **下料优先于上料**：成品占着研磨机必须优先卸出
- **加工期间天车不停等**：可服务其他研磨机的上料/下料
- **研磨机优先级**：ST701(新代1) > ST702(新代2) > ST703(西门子1) > ST704(西门子2)
- **工件缓存 FIFO**：充磁取料前失败自动放回队列，充磁后失败需人工处理

### 安全要点（TypeA / TypeB 通用）
- **门安全**：天车上下移动前必须确认 `门开=1`（TypeA: 40001-15 / TypeB: R7307）
- **磨石报警**：仅 TypeA 有（40001-1/40001-2），任一报警仅停止该机接收新的自动上料；取料前二次确认报警时工件回FIFO，其他研磨机继续，不暂停研磨引擎；两路位恢复后自动重新参与分配
- **心跳检测**：TypeA `IsHeartbeatOkAsync()` 连续两次（间隔 500ms）读 40001-8，值有变化=PLC 存活
- **加工中**：仅用于上位机状态显示，不参与握手逻辑

### 主页面单机清空

主页面“清空状态”对 ST701、ST702、ST703、ST704 分别提供独立按钮，点击哪个只清哪个研磨机：

- ST701/ST702（TypeB新代）：R7311~R7315握手输出和R7316~R7318加工参数全部写0。
- ST703/ST704（TypeA西门子）：40011输出字和40012~40014加工参数全部写0。
- 不清40001或R7301~R7307等PLC请求、反馈、门状态、报警和加工状态。

页面调用 `PlcGrinderService.ClearEmergencyRegistersAsync`，不再只调用 `ClearAllOutputsAsync`，因此不会遗漏参数。该操作不清 `GrindingFlowEngine` 的Pending、FIFO、状态和天车锁；如需处理软件状态或释放锁，必须使用主页面“应急处理”。执行前应停止或暂停研磨引擎并确认目标设备无动作。
