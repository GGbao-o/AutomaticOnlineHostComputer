# 研磨机通信协议（Modbus TCP）

## 概述
- **设备数量**：4 台（各 2 台不同系统）
- **4# PLC**：IP 192.168.1.71，2 台研磨机
- **5# PLC**：IP 192.168.1.81，2 台研磨机
- **端口**：502
- **地址段**：40001~40020

---
