# 天车/ 寄存器地址表（使用说明）

> 适用设备：5 台天车 + 机械手 1~3（`ManipulatorConnectionCache` 复用 `CraneService`，同一套汇川 PLC 布局）
> 协议：Modbus TCP，端口 **502**
> 源码依据：`Communication/DeviceAddresses/CraneAddress.cs`、`Communication/DeviceServices/CraneService.cs`、`Presentation/ViewModels/Home/CraneManualControlViewModel.cs`
>
> **本表只列实际被使用的寄存器。** 定义但无任何消费的（D5001~D5004、D5009、D5010、D5016~D5017、D5021、D5023~D5024、D5026~D5028、D4519、JOG 速度、D4000/D4003~D4013 等）见文末“未使用与排除项”。

## 一、通用约定

| 用途 | 功能码 | 说明 |
|------|--------|------|
| 状态读取 | FC03 | 从 `D5000` 连续读 30 个字到 `D5029` |
| X 输入读取 | FC01 | 每点独立线圈，地址 = `63488 + 物理序号`；**X 区为八进制编号**（故 X11=63497，不是十进制 63499） |
| 写单寄存器 | FC06 | 手动/触发位/速度参数 |
| 写多寄存器 | FC16 | 绝对移动目标（DINT） |

- **INT16**：单寄存器；状态读取中 `YPos/ZPos` 按 `ushort`（0~65535），其余多按 `short`。
- **DINT32 小端**：低字在前。例：X 坐标 D5018=低字、D5019=高字 → `(r[19]<<16)|r[18]`。
- **脉冲 `2→0`**：写 2 触发，随后必须写 0 复位。
- **手动模式前置**：除急停 `D4518` 外，所有手动命令前先 `D4001=2`（切手动）→ `D4500=2`（手动使能），由 `EnsureManualModeAsync` 首次写入并缓存。

设备默认 IP：天车1=`192.168.2.81`、天车2=`.82`、天车3=`.83`、天车4=`.84`、天车5(研磨)=`.80`；机械手1=`.85`、机械手2=`.86`、机械手3=`.87`。

## 四、手动操作页面：按钮 → 寄存器时序

> 页面 `Views/Motion/Controls/ManualMotionControlPanel.xaml`；VM `CraneManualControlViewModel`。
> 机械手无 X 轴、无接液盘。

### 4.1 点动按钮 X+ / X- / Y+ / Y- / Z+ / Z-（PLC 原生相对运动）

| 步 | 寄存器 | 值 |
|:---:|:---:|:---:|
| 1 | D4001 | 2（首次切手动） |
| 2 | D4500 | 2（手动使能） |
| 3 | D4501 | 步长(mm) |
| 4 | D4502 | 1=正向 / 2=负向 |
| 5 | D4505(X) / D4504(Y) / D4503(Z) | 2（触发该轴相对运动） |

> 触发位保持 2 由 PLC 执行一次相对运动，下一次点动覆盖参数；**不做 2→0 复位**。X 轴仅天车有。

### 4.2 相对移动按钮（相对移动 X±/Y±/Z±，读当前坐标后按绝对执行）

| 步 | 动作 |
|:---:|------|
| 1 | 读 `D5018~D5019`(X) / `D5022`(Y) / `D5025`(Z) 当前坐标 |
| 2 | 目标 = 当前 ± `RelativeMoveDistance` |
| 3 | 写绝对速度 `D2501~D2503`、`D2510~D2512`、`D2519~D2521` |
| 4 | `D4001=2` → `D4500=2` |
| 5 | 写目标 `D3102~D3103`(X) / `D3104~D3105`(Y) / `D3106~D3107`(Z) |
| 6 | 触发：对应轴 `D4522`/`D4521`/`D4520` **写 2 → 等 500ms → 写 0** |
| 7 | 轮询 `D5018/5022/5025` 到位（±5mm） |

### 4.3 绝对移动按钮（输入框 AbsX / AbsY / AbsZ）

同 4.2，直接把输入框坐标（机械手 X 传 -1 表示不动）写入 `D3102~D3107` 后按 Z 方向脉冲触发：**Z 下降**先 XY 后 Z；**Z 上升**先 Z 后 XY；**Z 不变**三轴同时。结束后 `finally` 把参与轴 `D4520~D4522=0`。

### 4.4 其它按钮

| 按钮 | 寄存器时序 |
|------|------|
| X 轴回原点 | `D4508=2` → 200ms → `D4508=0` |
| Y 轴回原点 | `D4507=2` → 200ms → `D4507=0` |
| Z 轴回原点 | `D4506=2` → 200ms → `D4506=0` |
| 充磁 | `D4510=2` → 轮询 `X6=1` → `D4510=0`（最多 3 次，单次 3s） |
| 退磁 | `D4511=2` → 轮询 `X7=1 且 X6=0` → `D4511=0`（最多 3 次） |
| 接液盘打开 | `D4512=2 → 0` |
| 接液盘关闭 | `D4513=2 → 0` |
| 清除报警 | `D4514=2` → 50ms → `D4514=0` |
| 伺服通电 | `D4516=2 → 0` |
| 伺服断电 | `D4515=2 → 0` |
| 减速停止 | `D4517=2 → 0` |
| 急停 | `D4518=2 → 0`（**不切手动，紧急直写**） |
| 应用绝对速度 | 写 `D2501~D2503`(X)、`D2510~D2512`(Y)、`D2519~D2521`(Z) |
| 应用相对速度 | 写 `D2504~D2506`(X)、`D2513~D2515`(Y)、`D2522~D2524`(Z) |

### 4.5 刷新按钮（读取当前位置与反馈）

- 一次批读 `D5000~D5029`：取 `D5018~19/D5022/D5025` 填目标框，取 `D5006/07/08`、`D5011/12/13` 显示。
- 逐个读 X 线圈：`X6/X7/X11/X2/X3/X4/X5`（天车加读 `X0/X1`）。

### 5.3 自动运动超时

XY 与 Z 阶段各有默认 120s 上限（`motion_settings.json` 的 `absMove.xyTimeoutMs/zTimeoutMs`）。任一参与轴未进入目标 ±5mm 时，读最终状态并尝试用不可取消写入 `D4518=2→0` 停伺服、复位 `D4520~D4522`，随后向上层报告“位置未知”，由业务层暂停等人工确认。

## 八、下压急停 D4523 / X2 处理链路

1. `MoveAbsoluteAsync` **仅在 Z 下降**的到位轮询中读 X2（FC01 63490）；Z 上升不监视，避免释放延迟误停。
2. 读到 X2=1 后，用不可取消令牌写 `D4523=2 → 500ms → 0`，再写 `D4518=2 → 0`，并复位参与轴 `D4520~D4522=0`。
3. 停止稳定后读实际 Z，若 `|实际Z-目标Z| ≤ safety.pressureStopNormalPositionToleranceMm`（默认 15mm）→ `RecoverFromPressureStopAsync` 后按本次下降成功返回（不暂停引擎）；否则抛 `PressureStopException`。
4. `RecoverFromPressureStopAsync` 顺序：`D4523=0` → `D4001=2`+`D4500=2` → `D4514=2→0` → `D4516=2→0` → 复位 `D4520~D4522=0` → 校验 D4523 清零（最多 3 次）。
5. 手动恢复三步：**① 写 `D4523=0` → ② 清除报警 `D4514=2→0` → ③ 恢复**。

> X2 是上位机约 200ms 轮询处理，不构成 PLC/驱动硬实时安全回路；现场硬限位与伺服安全功能必须独立有效。

## 十二、注意事项

1. 脉冲型寄存器写 2 后必须写 0；`D5103` 是持续状态不复位。
2. 除急停 D4518 外，手动命令前必须 `D4001=2` + `D4500=2`；下压急停后缓存失效，恢复时强制重写。
3. X 区读取失败不能当 0。
4. DINT 小端，写 D3102~D3107 / 读 D5014~D5019 均低字在前。
5. 绝对移动 `finally` 复位用 `CancellationToken.None`。
6. X 区为八进制，X11=63497。
