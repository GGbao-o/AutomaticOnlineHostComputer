# 打标机通信协议（基于文件交换的握手）

## 核心机制
上位机与打标机通过监控共享文件夹内的文件实现状态同步和任务触发。不使用标准工业协议。

## 共享文件夹
- **路径**：`D:\job1\`
- **权限**：双方均需读写权限

## 交互流程

```
1. 没版 → 天车将工件放到打标位 → 退磁 → Z升到安全高度

2. 上位机在 D:\job1\ 生成文件 A（无后缀）
   内容格式：
     第一行: 刻印内容（版号等文本）
     第二行: 工件直径（mm）

3. 打标机检测到文件 A → 开始打标

4. 打标完成 → 打标机在 D:\job1\ 生成文件 B（无后缀）

5. 上位机轮询检测到文件 B 存在 → 打标完成

6. 天车下降充磁取走工件 → Z升安全高度

7. 上位机删除文件 B（清理现场，准备下一轮）
```

## 文件清单

| 文件 | 用途 | 谁生成 | 内容 |
|------|------|:---:|------|
| `D:\job1\A` | 打标任务 | 上位机 | 第1行: 刻印内容 / 第2行: 工件直径(mm) |
| `D:\job1\B` | 打标完成信号 | 打标机 | 任意内容（上位机只判断文件是否存在） |

## 上位机伪代码

```csharp
// 1. 天车放好工件、回到安全高度
await crane.MoveAbsoluteAsync(markerX, markerY, markerZ, ct: ct);
await crane.MagnetOffAsync(ct);
await crane.MoveAbsoluteAsync(-1, -1, safeZ, ct: ct);

// 2. 生成打标任务文件
var taskPath = @"D:\job1\A";
await File.WriteAllTextAsync(taskPath, $"{markingContent}\n{diameter}");

// 3. 等待打标完成（轮询 B）
var donePath = @"D:\job1\B";
var deadline = DateTime.UtcNow.AddSeconds(120);
while (!File.Exists(donePath) && DateTime.UtcNow < deadline)
    await Task.Delay(500);

if (!File.Exists(donePath))
    throw new TimeoutException("打标机超时：120s 未生成文件 B");

// 4. 天车取走工件
await crane.MoveAbsoluteAsync(-1, -1, markerZ, ct: ct);
await crane.MagnetOnAsync(ct);
await crane.MoveAbsoluteAsync(-1, -1, safeZ, ct: ct);

// 5. 清理
File.Delete(donePath);
```

## 超时与异常

| 场景 | 超时 | 处理 |
|------|:---:|------|
| 等 B 出现 | 120s | 抛 TimeoutException，人工检查打标机 |
| A 写入失败 | 立即 | 抛 IOException，重试或人工处理 |
| 文件夹不存在 | 立即 | 抛 DirectoryNotFoundException |
| 文件 A 写入失败 | 立即 | 抛 IOException，重试或人工处理 |
