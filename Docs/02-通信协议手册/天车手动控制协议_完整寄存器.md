| D2526 | 中控写入Z JOG加速度 | INT |
| D2527 | 中控写入Z JOG减速度 | INT |

### 说明
- **绝对位移**：上位机指定目标坐标，PLC 自动规划轨迹（D3102~D3106 设目标值）
- **相对位移**：上位机指定距离+方向，PLC 按设定速度走指定距离（D4501 设距离、D4502 设方向、D4503~D4505 触发）
- **JOG（点动）**：上位机发触发信号，PLC 以 JOG 速度持续运动直到信号撤销
- 本项目手动按钮走的是 **相对运动模式**（D4501 距离 + D4502 方向 + D4503~D4505 触发），
  因此设置 **相对位移速度/加减速**（D2504~D2506 / D2513~D2515 / D2522~D2524）即可控制点动速度
