| 地址 | 定义 | 类型 |
|------|------|------|
| D2519 | 中控写入Z绝对位移速度 | INT |
| D2520 | 中控写入Z绝对位移加速度 | INT |
| D2521 | 中控写入Z绝对位移减速度 | INT |
| D2522 | 中控写入Z相对位移速度 | INT |
| D2523 | 中控写入Z相对位移加速度 | INT |
| D2524 | 中控写入Z相对位移减速度 | INT |
| D2525 | 中控写入Z JOG速度 | INT |
| D2526 | 中控写入Z JOG加速度 | INT |
| D2527 | 中控写入Z JOG减速度 | INT |

### 说明
- **绝对位移**：先将目标坐标写入 D3102~D3107，再写 D4522/D4521/D4520=2 触发 X/Y/Z 轴移动 → 等 500ms → 写 0 复位（脉冲模式）。
- **页面手动按钮**：采用“相对输入、绝对执行”。例如当前坐标为 `(100,100,100)`，点击 `X+100` 时，上位机计算目标为 `(200,100,100)`，写入 D3102~D3107 后触发 X 轴。
- **输入框绝对移动**：输入框中的坐标值直接作为绝对目标坐标写入 D3102~D3107，然后触发对应轴。
- **PLC 原生相对位移**：D4501 设置距离、D4502 设置方向、D4503~D4505 触发，仅作为 PLC 原生相对运动能力/调试接口保留，不作为当前页面按钮主流程。
- **JOG（点动）**：上位机发触发信号，PLC 以 JOG 速度持续运动直到信号撤销。
- 当前页面按钮和输入框移动均使用 **绝对移动速度/加减速**（D2501~D2503 / D2510~D2512 / D2519~D2521）。
- **D4520~D4522 的定位**：绝对移动触发/复位位，不承载坐标值。

## D4523 下压急停

| D编号 | 常量名 | 功能 | 读写方式 |
|:---:|--------|------|------|
| D4523 | `D_PressureEStop` | 下压急停状态 | **PLC 写 1，主机手动恢复时写 0 清除** |

**检测流程：**
1. **X2 线圈**（63490 FC01）检测磁铁下压限位=1（亮了）
2. PLC 自动写 **D4523=1**（下压急停触发）
3. 上位机轮询到 D4523=1 → 写 D4518=2→0（伺服急停）+ 复位 D4520~D4522=0
4. 手动恢复：①写D4523=0 ②清除报警D4514=2→0

## DINT 字节序

32位有符号整数，小端（低字在前）：

| 读地址 | 公式 |
|--------|------|
| D5014~D5015 | `(r[15]<<16) \| r[14]` |
| D5016~D5017 | `(r[17]<<16) \| r[16]` |
| D5018~D5019 | `(r[19]<<16) \| r[18]` |

| 写地址 | 顺序 |
|--------|------|
| D3102~D3103 | D3102=低字, D3103=高字 |
| D3104~D3105 | D3104=低字, D3105=高字 |
| D3106~D3107 | D3106=低字, D3107=高字 |
