# 双头镗通信协议（新代 Syntec SDK）

## 概述
- **设备数量**：2 台
- **系统**：新代 Syntec CNC
- **接口**：`Syntec.OpenCNC.dll` SDK，通过以太网读写
- **地址段**：R 区 R6101~R6110

---

## R 区交互信号

| 地址 | 信号原名 | 方向 | 功能描述 |
|------|---------|------|---------|
| R6101 | 设备准备就绪，请求数据 | CNC→上位机 | 读，1=请求 |
| R6102 | 下发数据，下发完成 | 上位机→CNC | 写，1=下发完成 |
| R6103 | 请求上料 | CNC→上位机 | 读，1=请求 |
| R6104 | 货叉上料推入到位 | CNC→上位机 | 读，1=到位 |
| R6105 | 卡钳夹紧完成 | CNC→上位机 | 读，1=夹紧 |
| R6106 | 货叉上料推出完成 | 上位机→CNC | 写，1=完成 |
| R6107 | 加工完成，请求下料 | CNC→上位机 | 读，1=请求 |
| R6108 | 货叉下料推入到位 | CNC→上位机 | 读，1=到位 |
| R6109 | 卡钳松开完成 | CNC→上位机 | 读，1=松开 |
| R6110 | 货叉下料推出完成 | 上位机→CNC | 写，1=完成 |

---

## 配方数据写入地址

| 数据项 | 地址 | 格式 | 说明 |
|--------|------|------|------|
| 版长 | @740 | FLOAT | mm |
| 外圆成活 | @705 | FLOAT | mm |
| 左堵厚 | @702 | FLOAT | mm |
| 右堵厚 | @703 | FLOAT | mm |
| 内孔锥度 | @708 | FLOAT | mm/m |
| 内孔成活 | @707 | FLOAT | mm |
