# 产线布局与工艺流程

## 1. 产线物理分区与设备布局
(建议使用 draw.io 绘制示意图并截图保存至 `Images/流程草图/`)

### 上料区
- **上料架**：工人手动放料 → 旋转夹紧
- **小机械手 1**：从上料架抓取工件 → 分派至双头镗线体

### 加工区 1（双头镗）
- **线体 1**：加工范围 400mm ~ 1.25m
- **线体 2**：加工范围 400mm ~ 1.5m
- **上料方式判断**：
    - 长工件 → **货叉** 送入双头镗
    - 短工件 → **前天车** 直接送入双头镗
- **交互设备**：货叉、前天车

### 中转与打标区
- **前天车**：双头镗下料 → 打标机 → 中转架 (3 个)
- **打标机**：基于文件交换的握手协议

### 加工区 2（斜床）
- **后天车**：从中转架取料 → 分配至 10 台斜床 (沈阳 6 + 锦州 4) → 工位架
- **动平衡判断**：
    - 长度 > 800mm → 送动平衡区
    - 长度 ≤ 800mm → 直接送研磨上料架

### 动平衡区
- **小机械手 2**：工件放至动平衡上料机架 → 人工取走 → 动平衡下料架
- **小机械手 3**：从动平衡下料架取料 → 放至研磨上料架

### 研磨区
- **研磨上料架**：旋转式，带记忆功能（记录每个工位的工件尺寸等信息）
- **研磨天车**：从上料架取料 → 分配至 4 台研磨机 → 加工完成后放至研磨下料架

## 2. 主工艺流程

```text
[人工上料] 
  → 上料架（旋转夹紧）
  → 小机械手1 抓取
  → 判断长度：>1.25m ? 线体2 : 线体1/2（优先空闲）
  → 判断上料方式：长工件(货叉) / 短工件(前天车)
  → 双头镗加工
  → 下料：货叉取至位置2 → 前天车取料
  → 打标机打标（文件握手）
  → 前天车放至中转架(3个)
  → 后天车取料
  → 分配至空闲斜床（10台）
  → 斜床加工完成 → 后天车取至工位架
  → 判断长度：>800mm ? 
      是 → 小机械手2 → 动平衡上料架 → (人工) → 动平衡下料架 → 小机械手3 → 研磨上料架
      否 → 小机械手2 → 研磨上料架
  → 研磨上料架旋转记忆
  → 研磨天车取料 → 分配至空闲研磨机(4台)
  → 研磨完成 → 研磨下料架
