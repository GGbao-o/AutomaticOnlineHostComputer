## 二、手动操作区（D4500~D4523，FC06 单寄存器写）

| D编号 | 常量名 | 功能 | 写入方式 |
|:---:|--------|------|------|
| D4001 | `D_ModeCmd` | 自动/手动切换（1=自动,2=手动） | 写2 |
| D4500 | `D_ManualMode` | 手动操作使能 | 写2 |
| D4501 | `D_ManualDistance` | PLC原生相对运动距离(mm) | 写步长值 |
| D4502 | `D_ManualDirection` | PLC原生相对运动方向（1=正,2=负） | 写1或2 |
| D4503 | `D_ManualMoveZ` | PLC原生Z相对运动触发 | 写2 |
| D4504 | `D_ManualMoveY` | PLC原生Y相对运动触发 | 写2 |
| D4505 | `D_ManualMoveX` | PLC原生X相对运动触发 | 写2 |
| D4506 | `D_ManualHomeZ` | Z回原点触发 | 2→0脉冲 |
| D4507 | `D_ManualHomeY` | Y回原点触发 | 2→0脉冲 |
| D4508 | `D_ManualHomeX` | X回原点触发 | 2→0脉冲 |
| D4510 | `D_ManualMagnetOn` | 充磁触发 | 2→0脉冲（800ms间隔） |
| D4511 | `D_ManualMagnetOff` | 退磁触发 | 2→0脉冲（800ms间隔） |
| D4512 | `D_ManualDrainOpen` | 开接液盘触发 | 2→0脉冲 |
| D4513 | `D_ManualDrainClose` | 关接液盘触发 | 2→0脉冲 |
| D4514 | `D_ManualClearAlarm` | 清除报警触发 | 写2，等待状态恢复后写0 |
| D4515 | `D_ManualServoPowerOff` | 伺服断电触发 | 2→0脉冲 |
| D4516 | `D_ManualServoPowerOn` | 伺服通电触发 | 2→0脉冲 |
| D4517 | `D_ManualSlowStop` | 减速停止触发 | 2→0脉冲 |
| D4518 | `D_ManualEStop` | 急停触发 | 2→0脉冲 |
| D4520 | `D_ManualZAbsTarget` | Z绝对目标坐标 | 直接写坐标值 |
| D4521 | `D_ManualYAbsTarget` | Y绝对目标坐标 | 直接写坐标值 |
| D4522 | `D_ManualXAbsTarget` | X绝对目标坐标 | 直接写坐标值 |
| **D4523** | `D_PressureEStop` | **下压急停状态** | **PLC写1，主机清0** |

> 页面上的手动按钮与坐标输入框统一走“绝对坐标”模式：上位机读取当前位置后计算目标绝对坐标，直接写入 D4520~D4522；D4501~D4505 仅保留为 PLC 原生相对运动能力/调试接口。D4523 不是脉冲——PLC检测到磁铁下压写1，主机手动恢复时清0

## 四、绝对移动目标与触发

### 4.1 目标坐标（D3102~D3107，FC16 批量写）

| 轴 | 地址 | 类型 | 字节序 |
|:---:|------|:---:|:---:|
| X | D3102~D3103 | DINT | 小端（D3102=低字，D3103=高字） |
| Y | D3104~D3105 | DINT | 小端（D3104=低字，D3105=高字） |
| Z | D3106~D3107 | DINT | 小端（D3106=低字，D3107=高字） |

### 4.2 触发与复位（D4520~D4522，FC06 单寄存器写）

| 轴 | 触发地址 | 触发值 | 到位后复位 |
|:---:|------|:---:|:---:|
| X | D4522 | 2 | 写 0 |
| Y | D4521 | 2 | 写 0 |
| Z | D4520 | 2 | 写 0 |

> 当前业务确认：绝对移动先写 D3102~D3107 目标坐标，再写 D4522/D4521/D4520=2 触发移动；轮询到位后，写 D4522/D4521/D4520=0 复位。页面按钮采用“相对输入、绝对执行”，例如当前位置 `(100,100,100)`，点击 `X+100` 时计算目标 `(200,100,100)` 并写入 D3102~D3107，再触发 X 轴。
