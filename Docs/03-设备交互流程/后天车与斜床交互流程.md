# 后天车与斜床交互流程

> 依据 `Line1RearFlowEngine`、`Line2RearFlowEngine`、`ModbusSkewBedService`、`FanucSkewBedService` 整理，更新时间：2026-06-27。

## 1. 设备与协议

| 线路 | 后天车 | 斜床 | 协议 |
|------|------|------|------|
| 1号线 | Crane#2（数据库站号ST902） | ST108、ST109、ST111、ST110 | 锦州迅捷PLC，Modbus TCP |
| 1号线 | Crane#2 | ST112 | FANUC FOCAS宏变量 |
| 2号线 | Crane#4（ST904） | ST606~ST610 | FANUC FOCAS宏变量 |

斜床IP和端口从数据库 `machine` 表读取；Modbus默认端口502，FANUC默认端口8193。

## 2. 调度原则

1. 主循环每500ms刷新斜床快照，下料优先于上料。
2. 只有本轮信号读取成功的斜床才能参与派发，不沿用旧请求位。
3. 上料必须同时满足：斜床Idle、请求数据、可加工当前长度、中转架现场有板、缓存存在、后天车锁可用。
4. 下料必须满足：请求下料、斜床保存的 `Wp` 存在、目的料架本轮状态有效且允许放料。
5. ST108/ST606靠近前天车打号/中转区域，额外使用 `SharedAreaLock`。

## 3. 中转架到斜床上料

### 3.1 来源

| 线路 | 中转架 | PLC信号 |
|------|------|------|
| 1号线 | ST105/ST101/ST106 | MC63 M811/M812/M813 |
| 2号线 | ST016/ST017/ST018 | MC63 M814/M815/M816 |

后天车按缓存到达序号选择最早工件，不按固定架号抢后到工件。现场有板但软件缓存缺失时禁止盲取。

### 3.2 锁顺序

- 普通斜床：主循环先取得中转架锁，再进入 `DoLoad`。
- ST108/ST606：主循环先释放中转架锁，`DoLoad`按 `SharedAreaLock -> 中转架锁` 重新获取，和前天车顺序一致。
- 所有锁都登记在动作令牌中，正常finally和应急路径最多释放一次。

### 3.3 动作与握手

```text
读取来源缓存和坐标
  -> 后天车X11=0检查
  -> XY到中转架、Z下降、充磁
  -> X11确认吸住，Z升安全
  -> 等斜床请求数据
  -> 写长度/直径/堵孔/模式并确认数据完成
  -> 等请求上料
  -> XY到斜床，Z下降，Y进入顶尖位置
  -> 写天车上料到位
  -> 等尾座夹紧
  -> 退磁，Z升安全
  -> 写天车上料完成
  -> 保存bed.Wp并进入加工状态
```

锦州Modbus和FANUC地址不同，但业务顺序相同。详细地址分别见 `02-通信协议手册/斜床协议/`。

## 4. 斜床下料

```text
本轮读取到请求下料
  -> 获取后天车锁；ST108/ST606还要SharedAreaLock
  -> XY到斜床，Z下降，充磁
  -> X11确认吸住
  -> 写天车下料到位
  -> 等尾座分开
  -> Y退出顶尖位置
  -> Z升安全
  -> 写天车下料完成
  -> ST108/ST606按配置距离退离共享区后释放SharedAreaLock
  -> 按长度/强制动平衡标志分流
```

尾座未确认分开时Y轴不能退出。工件已吸住但尚未放到下游时发生异常，后端引擎暂停并保留 `bed.Wp`。

## 5. 下料分流

`Length >= 800` 或任务 `ForceBalancing=true` 走动平衡；其余走研磨上料路径。

### 5.1 1号线

| 工件 | 目标 | 前置条件 | 完成动作 |
|------|------|------|------|
| 需动平衡 | ST019 | MC63 M817=0（空闲），拿锁后二次确认 | 放料并写 `_balWps["M817"]` |
| 不需动平衡 | ST010 | MC65 M720=1（允许放料），拿锁后二次确认 | 放料、Z升安全、写M721=1并入研磨FIFO |

1号线分流区统一取得 `_lockM817 + _lockM720`，因为两条路径位于同一相邻区域。

### 5.2 2号线 ST020/ST021

| 工件 | 目标 | 放料允许 | 后天车完成 | 缓存 | 后续取料 |
|------|------|------|------|------|------|
| 需动平衡 | ST020 | M818=1 | 放料并Z升安全后写M819=1 | `_balWps["M818"]` | M823=1后M2取，完成写M824 |
| 不需动平衡 | ST021 | M820=1 | 放料并Z升安全后写M821=1 | `_balWps["M821"]` | M825=1后M3取，完成写M826 |

M818/M821缓存键和位置锁名称是历史命名，不代表对应PLC位仍是“有板”。2号线分流区统一取得 `_lockM818 + _lockM821`，并在拿锁后二次读取放料允许位。

## 6. Y/Z坐标

斜床顶尖Y偏移由运行配置实时计算：

```text
Y偏移 = (centerDistances[站号] - 工件长度) / 2
        + (大孔 ? largeBoreOffset : smallBoreOffset)
```

每台斜床还必须通过 `maxWorkpieceLengthMm` 长度能力检查。目标坐标叠加数据库天车偏移；取放Z按照当前引擎的直径公式计算，不能使用默认直径。

## 7. 共享区退出

ST108/ST606正常上料或下料完成后，后天车读取当前X，并按 `skewBed.sharedAreaRetreatX[站号]` 向右退离。退避成功后才释放 `SharedAreaLock`；退避失败则保留锁并暂停引擎，等待人工确认。

## 8. 归位与状态清理

工件成功放到最终目的地并完成关键PLC通知后，才允许清除斜床 `Wp`、回Home并释放忙标志。归位X来自 `craneHomeX[2/4]`。物理放料成功但M819/M821/M721或缓存回调失败时，不当作普通告警继续生产，而是暂停等待人工补偿。
