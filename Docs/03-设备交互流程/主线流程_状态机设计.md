# 主线流程状态机设计（当前版）

## 货叉 + 双头镗状态机

| 阶段 | 触发/动作 | 下一阶段 |
|------|-----------|----------|
| Idle | 货叉 M900=1、M901=1、机械手1 Y安全、有在途工件 | Load_WriteParams 或 SkipBoring_GoPos3 |
| Load_WriteParams | 等 R6101=1，写 R2041/R2043/R2044/R2045/R2047，写 R6102=1，等 R6103=1 | GoingToBoring |
| GoingToBoring | 写 M912=1，等 M901=1 且 M900=0 | Load_WriteDone |
| Load_WriteDone | 写 R6104=1 | WaitingMachine |
| WaitingMachine | 等 R6107=1，写 M913=1 | Unload_GoPos3 |
| Unload_GoPos3 | 等 M902=1 且 M900=1，写 R6108=1，工件入前天车队列 | WaitingForkReturnFromBoring |
| SkipBoring_GoPos3 | 写 M914=1，等 M902=1 且 M900=1，工件入前天车队列 | WaitingForkReturnFromSkip |
| WaitingForkReturnFromBoring/Skip | 前天车取走工件后写 M911=1，等 M901=1 且 M900=0 | Idle |

## 双头镗地址

Modbus 地址 = `R * 2 + 1`。当前使用 R6101/R6102/R6103/R6104/R6107/R6108 和参数 R2041/R2043/R2044/R2045/R2047。

## SkipBoring

SkipBoring 不写双头镗参数和 R6102/R6104/R6108，但机械手1从总上料架取料前仍要求双头镗连接正常且 R6101=1。
