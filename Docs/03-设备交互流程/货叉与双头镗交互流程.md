# 货叉与双头镗交互流程

> 依据 `ForkService`、`BoringModbusService`、`Line1FrontFlowEngine`、`Line2FrontFlowEngine` 整理，更新时间：2026-06-27。

## 1. 设备对应

| 线路 | 货叉站号 | 双头镗站号 | 货叉协议 | 双头镗协议 |
|------|------|------|------|------|
| 1号线 | ST711 | ST103 | 三菱MC 1E，192.168.2.88:9000 | Modbus TCP，IP取数据库 |
| 2号线 | ST712 | ST402 | 三菱MC 1E，192.168.2.89:9000 | Modbus TCP，IP取数据库 |

## 2. 货叉信号

| M地址 | 方向 | 含义 |
|:---:|:---:|------|
| M900 | 货叉→中控 | 1=货叉上有板 |
| M901 | 货叉→中控 | 1=货叉在待机位 |
| M902 | 货叉→中控 | 1=货叉在Pos3天车取料位 |
| M911 | 中控→货叉 | 写1：回待机位 |
| M912 | 中控→货叉 | 写1：去双头镗送料并自动回待机 |
| M913 | 中控→货叉 | 写1：去双头镗取料并自动到Pos3 |
| M914 | 中控→货叉 | 写1：SkipBoring从待机直接到Pos3 |

中控写运动命令时先清 M911~M914，再把目标命令写1；不是对同一个命令写1后再写0。

## 3. 双头镗地址

Modbus地址=`R编号*2+1`。

| R地址 | Modbus地址 | 方向 | 格式 | 含义 |
|:---:|---:|:---:|:---:|------|
| R2041 | 4083 | 写 | uint32 | 长度，ERP整数原值，不乘100 |
| R2043 | 4087 | 写 | int | 直径*100 |
| R2044 | 4089 | 写 | int | 左堵厚*100 |
| R2045 | 4091 | 写 | int | 右堵厚*100 |
| R2046 | 4093 | 仅定义 | int | 内孔锥度，当前不写 |
| R2047 | 4095 | 写 | int | 内孔成活/版孔*100 |
| R2048 | 4097 | 仅定义 | int | 圆角大小，当前不写 |
| R6101 | 12203 | 读 | int | 请求数据 |
| R6102 | 12205 | 写1 | int | 数据下发完成 |
| R6103 | 12207 | 读 | int | 请求上料 |
| R6104 | 12209 | 写1 | int | 上料完成 |
| R6107 | 12215 | 读 | int | 请求下料 |
| R6108 | 12217 | 写1 | int | 下料完成 |

R6102/R6104/R6108正常流程只写1。人工应急清理是唯一主动写0的路径。

## 4. 状态机

| 阶段 | 条件或动作 | 下一阶段 |
|------|------|------|
| Idle | M900=1、M901=1、有在途工件、机械手1已回安全Y | Load_WriteParams或SkipBoring_GoPos3 |
| Load_WriteParams | 确认R6101=1，写参数，写R6102=1 | Load_WriteDone |
| Load_WriteDone | 等R6103=1 | GoingToBoring |
| GoingToBoring | M912只发送一次，等M901=1且M900=0 | WaitingMachine |
| WaitingMachine | 写R6104=1，持续等R6107=1 | Unload_GoPos3 |
| Unload_GoPos3 | 写M913=1，等M902=1且M900=1，写R6108=1 | WaitingForkReturnFromBoring |
| SkipBoring_GoPos3 | 写M914=1，等M902=1且M900=1 | WaitingForkReturnFromSkip |
| WaitingForkReturnFromBoring/Skip | 前天车取走后写M911=1，等M901=1且M900=0 | Idle |

## 5. 正常加工顺序

```text
R6101=1
  -> 写R2041/R2043/R2044/R2045/R2047
  -> R6102=1
  -> 等R6103=1
  -> M912=1送料，货叉自动回待机
  -> 等M901=1且M900=0
  -> R6104=1
  -> 等R6107=1
  -> M913=1取料并去Pos3
  -> 等M902=1且M900=1
  -> R6108=1
  -> 工件进入前天车取料阶段
  -> 前天车取走后M911=1回待机
```

## 6. SkipBoring

SkipBoring不写加工参数，也不写R6102/R6104/R6108。机械手1放到货叉后写M914=1，货叉直接送Pos3。为防双头镗节拍冲突，机械手1从总上料架取料前仍要求双头镗连接正常且R6101=1。

## 7. 启动与异常条件

货叉状态机启动必须同时满足：货叉有板、在待机位、有 `_currentWp`、状态机空闲、机械手1在安全Y。PLC/Modbus读取失败不能沿用旧状态。

任一握手异常会暂停对应前端引擎并保留当前阶段，不盲目复位Idle。货叉到Pos3并收到R6108后才把工件交给前天车阶段；前天车物理取走后才允许M911回待机。

## 8. 页面状态

- 货叉：M900、M901/M902、当前M911~M914命令。
- 双头镗：R6101、R6102、R6103、R6104、R6107、R6108。
