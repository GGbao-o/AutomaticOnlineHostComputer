# 天车调度逻辑

> 本项目使用「绝对位移模式」：上位机直接写目标坐标 + 触发绝对移动，自行控制整个到位流程。
> 详细寄存器定义见 `Docs/02-通信协议手册/天车手动控制协议_完整寄存器.md`。

## 绝对位移调度流程

上位机自行控制移动的完整流程（`CraneService.MoveAbsoluteAsync`）：

```
1. EnsureManualModeAsync: D4001=2, D4500=2
2. 写目标坐标（DINT 小端）:
   X → D3102~D3103
   Y → D3104~D3105
   Z → D3106~D3107
3. 读当前 Z，判断升降方向
4. Z↓ → 开接液盘(D4512=2→0) → 等500ms
5. 按方向触发:
   Z↓: 先触发XY(D4522/D4521=2) → 等XY到位 → 再触发Z(D4520=2)
   Z↑: 先触发Z(D4520=2) → 等Z到位 → 再触发XY(D4522/D4521=2)
   Z不变: 同时触发XYZ
6. 轮询 D5018/D5022/D5025，等全部到位(容差±5)
   包含Z轴目标时每200ms检查 X2 下压限位；其他到位轮询间隔500ms
   超时仍未到位 → 抛出异常，由上层按工件物理状态暂停或人工处理
7. finally: 复位全部触发(D4520~D4522=0)
   Z↑ → 关接液盘(D4513=2→0)
```

## 引擎调度层

`ProductionFlowEngine.MoveCraneToStationAsync` 在天车绝对移动之上增加：

1. 查 `station_coords` 缓存取目标坐标（数据库 `machine` 表）
2. 预约目标工位（防多天车同时去同一工位）
   - 已被占 → 等待最多 30s → 超时放弃
3. `CheckSafetyAsync` 安检（忙闲 D5006 / 故障 D5009 / 伺服报警 D5011 / 有版 D5029）
4. `SetAbsSpeedAsync` 写入 9 个速度寄存器
5. `MoveAbsoluteAsync` 执行绝对移动
6. 读到位坐标 → 偏差日志
7. finally: 释放工位预约；实时坐标只显示和参与安全判断，不写数据库

## 机械手调度

三台小机械手同样使用 CraneService（PLC 寄存器地址完全相同），但 X 轴传 -1 跳过：

- `MoveManipulatorToStationAsync`: 只取 Y/Z 坐标，`MoveAbsoluteAsync(-1, yTarget, zTarget)`
- 无充磁/退磁/接液盘功能

## 预约互斥

- 天车/机械手去工位前先 `ReserveStation(stationCode, ownerName)`
- 操作完成或异常后在 finally 中 `ReleaseStation`
- 同一预约者重复预约同一工位幂等（直接返回 true）

## 安全机制

详见 `Docs/天车机械手运动逻辑与安全机制.md`，包含：
- 任务前安检（四项检查）
- Z 轴安全顺序（下降先XY后Z，上升先Z后XY）
- 接液盘互锁（Z↓前开，Z↑后关）
- 下压急停 D4523 轮询
- 到位超时抛异常并复位触发位
- 超时复位
