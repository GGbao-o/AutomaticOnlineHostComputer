# 天车调度逻辑

## 前后天车职责
- **前天车**：双头镗下料 → 打标机 → 中转架
- **后天车**：中转架 → 斜床 → 工位架

## 任务分配逻辑
1. 读取 `D5000`（空闲请求数据）= 1 → 天车就绪
2. 写入目标信息 D3101~D3137
3. 写入控制命令 D5100~D5103
4. 监控 D5001~D5004 等待到位/完成信号
5. 任务结束，释放天车

## 关键互锁
- 打标未完成（文件 B 未出现）→ 禁止天车取料
- 斜床未请求数据（R7301=0）→ 禁止天车下料
