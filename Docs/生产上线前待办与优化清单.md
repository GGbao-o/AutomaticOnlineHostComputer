# 生产上线前待办与优化清单

> 本文记录静态审查发现的风险和现场验证项，不替代《全线业务逻辑详解》及通信协议文档。更新日期：2026-06-28。

## 一、实板连续生产前建议处理

| 编号 | 问题 | 影响 | 建议 |
|---|---|---|---|
| P0-1 | MC 同一对齐字的“读字-改位-写字”未在同一临界区完成 | M824/M826、M721/M731 等并发写入时可能互相覆盖，造成物理动作完成但 PLC 丢失完成位 | 在 MC 客户端或共享服务中按 `IP + 对齐字地址` 原子化整个读改写过程 |
| P0-2 | 手动天车控制与自动引擎没有统一动作互锁 | 操作员命令可能插入自动运动寄存器序列，存在碰撞风险 | 增加设备级自动动作占用标志和维护模式；急停始终保留 |
| P1-1 | 各引擎“暂停”语义不一致，已派发动作通常继续运行 | 操作员可能误以为当前动作已停止；研磨急停后后台动作仍存活 | 明确区分暂停派发、停止当前动作和急停，并让页面文字与行为一致 |
| P1-2 | `safeZHeight` 当前配置为 0，而部分文档写 400 | 安全高度的现场含义不明确，错误配置可能影响所有取放动作 | 带板前确认坐标方向、最高安全位和所有设备净空，再统一配置与文档 |

## 二、必须现场验证

| 编号 | 验证项 | 验证方法 | 通过标准 |
|---|---|---|---|
| V-1 | Z 轴压力 X2 在回升阶段的行为 | 工件接触后吸取并立即回升，记录 X2 和 Z 状态 | X2 延迟释放不会阻止安全回升；否则需限定压力保护仅用于下降 |
| V-2 | 货叉 M900~M915 整字写入 | PLC 监控 M900~M914，动作期间观察反馈位是否被上位机短暂覆盖 | M900~M902 反馈稳定；若有覆盖，应改为命令位独立写入或独立命令字 |
| V-3 | ST020/ST021 双握手并行 | 同时触发 M2/M3 可取条件并监控 M824/M826 | 两个完成位均可靠保留，不发生后写覆盖前写 |
| V-4 | MC65 完成位并行 | 监控 M721 与 M731 在接近时刻写入 | 两个位均可靠保留且 PLC 顺序正确 |
| V-5 | 应用重启恢复 | 在线路有模拟在途数据时停止并重启 | 操作规程能识别并人工重建工件身份，不允许盲目自动续跑 |

## 三、后续可靠性优化

1. 强制重新加载生产上下文前，完整停止并释放旧引擎、货叉、双头镗和斜床服务。
2. 为共享区域锁、位置锁和 PLC 长等待增加超时提醒与持续等待日志，不自动解除安全锁。
3. 跟踪所有派发动作任务，并在停止、重建和退出时等待任务结束，避免未观察异常。
4. 标记或移除未参与当前生产的旧 `ProductionFlowEngine` 模拟流程，避免维护人员误用旧站号和旧逻辑。
5. 将关键安全配置增加范围校验和现场确认记录，例如安全 Z、高度系数、后天车安全 X。

## 五、上线纪律

1. 完成 P0 项前只进行无板、单动作、受控联调，不进入双线连续自动生产。
2. 带板测试按照单设备、单线、双线并行逐级放开。
3. 每次测试记录版号、序号、设备、步骤、PLC 地址和异常原因。
4. 现场状态与软件缓存不一致时立即停止自动派发，先人工核对物理工件。
