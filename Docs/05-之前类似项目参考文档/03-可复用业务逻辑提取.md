## 一、天车任务安全校验

天车任务启动前必须通过的检查：

| 检查项 | 检测方式 | 不通过处理 |
|--------|---------|-----------|
| 天车已回零点 | 启动前多次检测 | 暂停调度，报警 |
| 天车已有版 | 读 DI 位 | 暂停任务，报警 |
| 磁铁偏了 | 读 DI 位 | 暂停，报警 |
| 充磁后未检测到版 | 充磁后验证 | 暂停，报警 |
| 手动模式 | 状态标记 | 暂停调度 |

## 二、信号交互规范 — 脉冲模式

所有天车与设备之间的握手信号均采用 **写2触发 → 写0复位** 的脉冲模式：

- 天车已靠近：写2 → 清0
- 天车已远离：写2 → 清0
- 天车上料到位：写2 → 清0
- 天车下料到位：写2 → 清0
- 天车上料完成：写2 → 清0
- 天车下料完成：写2 → 清0
- 数据传输完成：写2 → 清0

**原因**：PLC 侧 0 是常态，非0值代表触发。如果一直保持 2，PLC 认为指令一直在发。

## 三、天车取料（下料）完整握手流程

```
1. 天车到源位置上方
2. 等设备返回"请求下料"(113) > 0          ← 设备确认可以取
3. Z 轴快降到安全Z位置
4. Z 轴慢降到工作位
   ├── 触发磁铁下压限位 → 停止
   └── 或触发Z轴正限位 → 停止
5. 充磁吸住工件
6. 检测有版信号
   ├── 有版 → 继续
   └── 无版 → 暂停报警！
7. 写"天车已靠近"=2→0, "天车下料到位"=2→0
8. 等设备返回"已松开"(105) > 0            ← 设备松开工件
9. 清"天车已靠近", "天车下料到位"
10. 抖动工件（如果机器配置 DisShake > 0）
    └── X 轴往复微动 5 次，松动卡住的工件
11. XY 偏移（下料偏移值）
12. Z 轴快升到安全Z
13. Z 轴升到顶点 → 关接液盘
14. 完成
```

## 四、天车放料（上料）完整握手流程

```
1. 天车到目标位置上方
2. 写目标设备全部加工参数：
   ├── 外径
   ├── 内径
   ├── 版辊长度
   ├── 堵头厚度
   ├── 内孔斜度
   ├── 加工模式
   └── 打印内容 + 打印触发
3. 写"数据传输完成"=2→0
4. 开接液盘
5. 等设备返回"请求上料"(112) > 0          ← 设备准备好接收
6. Z 轴快降到安全Z → 慢降到工作位
7. XY 偏移（上料偏移值）                    ← 微调对准
8. 写"天车已靠近"=2→0, "天车上料到位"=2→0
9. 等设备返回"已夹紧"(104) > 0             ← 设备夹紧工件
10. 清"天车已靠近", "天车上料到位"
11. 转移加工信息，清源设备加工信息
12. 退磁松开工件
    └── 失败超过10次 → 先充磁再退磁（容错重试）
13. Z 轴快升到安全Z → 升到顶点
14. 写"天车已远离"=2→0, "天车上料完成"=2→0
15. 关接液盘 → 任务完成 → 清预约
```

## 五、调度引擎设计

### 5.1 扫描周期：500ms

### 5.2 机器状态分类

| 读取 | 条件 | 状态 | 含义 |
|:---:|------|:---:|------|
| 101(空闲) | idle=1 | 2 | 空闲可上料 |
| 103(完成) | over=1 | 1 | 加工完成，需要下料 |
| 101(空闲) | idle=0 | 3 | 忙碌中 |
| 102(检修) | err=1 | 0 | 跳过，不可调度 |
| 120(预约) | reservation=1 | 4 | 已被天车锁定，跳过 |

### 5.3 任务生成逻辑

```
遍历 Over 列表（加工完成的机器）：
  → 根据该工件的工艺路线，找到下一道工序需要的设备类型
  → 在 IDLE 列表中查找该类型的空闲机器
  → 生成搬运任务：源=Over机器，目标=IDLE机器

遍历上料架（有板）：
  → 从 TaskBordID 取未开始的任务
  → 找第一道工序的空闲机器
  → 生成搬运任务：源=上料架，目标=第一道工序机器
```

### 5.4 天车分配条件

```
天车可达范围：天车.StartX ≤ 任务路径.StartX && 天车.EndX ≥ 任务路径.EndX
路权区间不重叠
障碍物检测：如果有空闲天车挡路 → 指挥它移到安全距离（± 2 × 天车宽度）
```

## 六、关键容差值

| 场景 | 容差 | 说明 |
|------|:---:|------|
| X轴编码器对齐（正常） | abs < 50 | 编码器与天车位置对齐 |
| X轴大致对齐（允许Z慢降） | abs < 500 | |
| Z轴确定到位 | abs < 3 | Z轴精确到位 |
| 位置补偿 | 循环移动直到 < 50 | 编码器偏差大时补偿 |
| 退磁失败容忍 | 失败10次后切换策略 | 先充磁再退磁 |

## 七、预约机制

- 天车取料前 → 目标设备 Reservation=1（锁定）
- 任务完成 → 目标设备 Reservation=0（解锁）
- 其他天车看到 Reservation=1 → 跳过该设备
- **防止两天车同时去同一台机器**

---

## 八、设备通用生命周期

```
空闲(idle=1)
  → 天车预约(Reservation=1)
    → 天车上料 → 收到加工数据
      → 夹紧 → 加工中(idle=0)
        → 加工完成(over=1)
          → 天车预约(Reservation=1)
            → 天车下料 → 松开
              → 空闲(idle=1)
```

设备是被动方，只做三件事：
1. 发出状态（idle / over / 请求上料 / 请求下料 / 已夹紧 / 已松开）
2. 接收数据（加工参数）
3. 执行夹紧 / 松开

天车是唯一主动搬运者。

## 九、各设备端 PLC 需实现的逻辑

### 研磨机
- 收到"上料到达锁紧位置" → 夹紧 → 已夹紧=1
- 收到"上料完成"+"天车远离" → 开始研磨 → over=1
- 收到"下料到达松开位置" → 松开 → 已松开=1

### 斜车(FANUC)
- 主动发"请求数据"(#1001) → 天车下发加工参数
- 收到"天车上料到位"(#1102) → 尾座夹紧 → 已夹紧(#1003)=1
- 收到"天车上料完成"(#1103) → 关自动门 → 开始加工
- 加工完成 → 主动发"请求下料"(#1004)
- 收到"天车下料到位"(#1104) → 尾座分开 → 已松开(#1005)=1

### 双头镗床
- 收到"数据传输完成" → 接收全部加工参数
- 收到"上料到达锁紧位置" → 夹紧 → 已夹紧=1
- 收到"上料完成" → 开始镗孔 → over=1
