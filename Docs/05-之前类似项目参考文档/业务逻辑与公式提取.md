## 一、速度策略与加减速

### 1.1 速度分级

天车运动采用**快/慢两级速度策略**，定义在 config.xml 中：

| 参数 | X轴 | Y轴 | Z轴 | 单位 | 用途 |
|------|:---:|:---:|:---:|------|------|
| **FastRapidVel** | 70 | 25 | 25 | pulse/ms | XY水平移动到目标位置、Z轴快速升降 |
| **LowRapidVel** | 25 | 25 | 30 | pulse/ms | Z轴接近工件表面、XY轴微调 |
| **HomeRapidVel** | 40 | 40 | 40 | pulse/ms | 回原点快移 |
| **HomeLocatVel** | 5 | 5 | 5 | pulse/ms | 回原点定位（低速精确找原点） |

### 1.2 加减速参数

| 参数 | X/Y/Z轴 | 单位 | 用途 |
|------|:---:|------|------|
| **FastACC** | 1 | pulse/ms² | 快速移动加速度 |
| **FastDEC** | 1 | pulse/ms² | 快速移动减速度 |
| **LowACC** | 1 | pulse/ms² | 慢速移动加速度 |
| **LowDEC** | 1 | pulse/ms² | 慢速移动减速度 |
| **HomeAcc** | 0.1 | pulse/ms² | 回零加速度（更平缓） |
| **SpeedACC** | 1 | pulse/ms² | 手动JOG模式加速度 |
| **SpeedDec** | 1 | pulse/ms² | 手动JOG模式减速度 |
| **FastSpeed** | 1 | — | 手动JOG快速 |
| **NormalSpeed** | 1 | — | 手动JOG常速 |

### 1.3 各阶段速度选择

```
阶段                   X轴速度              Y轴速度              Z轴速度
─────────────────────────────────────────────────────────────────────
回零(goHome)          HomeRapidVel→Locat   HomeRapidVel→Locat   HomeRapidVel→Locat
Z轴上升回顶点          —                    —                    FastRapidVelZ (25)
XY移动到源/目标        FastRapidVelX (70)   FastRapidVelY (25)   —
Z轴快速下降(安全Z)      —                    —                    FastRapidVelZ (25)
Z轴慢速下降(取料/放料)  —                    —                    LowRapidVelZ (30)
X轴偏移(下料/上料)     LowRapidVelX (25)    LowRapidVelY (25)    —
X轴抖动(松工件)        LowRapidVelX (25)    —                    —
Z轴上升(取料后)        —                    —                    FastRapidVelZ (25)
X轴位置补偿            LowRapidVelX (25)    —                    —
障碍避让X轴移动        FastRapidVelX (70)   —                    FastRapidVelZ (25)
```

### 1.4 加减速决策逻辑

```csharp
// 加速度 = 基础加速度 × 减速比 (RatioX/Y/Z)
// 例: X轴快速移动加速度 = FastACCX * RatioX
// 减速比从数据库 CraneConf 表加载

m_TrapPrm.acc = acc * RatioX;   // 实际加速度
m_TrapPrm.dec = dec * RatioX;   // 实际减速度
m_TrapPrm.smoothTime = 0;       // 平滑时间为0(梯形曲线)
m_TrapPrm.velStart = 0;         // 启动速度为0

// 位置转换:
// moveDistance:     目标脉冲 = (目标位置 - 配置偏移) × 减速比
// moveOriDistance:  目标脉冲 = 原始脉冲值 × 减速比
// moveRelativeDistance: 目标脉冲 = 当前规划位置 + 位移 × 减速比
```

## 二、停止条件汇总

### 2.1 Z轴停止条件

| 停止条件 | 检测方式 | 发生位置 | 后续动作 |
|------|------|------|------|
| **磁铁下压限位** | `(v & 0x04) > 0` (DI2) | 步骤9(取料)、步骤24(放料) | stopMove(3) → 充磁/退磁 |
| **Z轴正限位** | `Axis3sta & 0x20` | 步骤9(取料)、步骤24(放料) | stopMove(3) |
| **Z轴原点开关** | `AXIS_STATUS_HOME_SWITCH` | 步骤2(Z上升) | 已到顶点 |
| **轴停止运行** | `AXIS_STATUS_RUNNING == 0` | 通用到位判断 | 进入下一步 |
| **pos.PosZ <= 5** | 规划位置判断 | 步骤2/18/31 | Z轴已到顶点 |
| **Z轴步进** | `RUNNING==0 且未触发限位` | 步骤9 | `tarPosZ += DisSetpPluseZ(10000)` 继续下探 |

### 2.2 X轴停止条件

| 停止条件 | 检测方式 | 位置 | 容差 |
|------|------|------|:---:|
| **编码器到位** | `abs(EncoderPos - CranePos) < 50` | 步骤5/20 | 50脉冲 |
| **编码器粗到位** | `abs(EncoderPos - CranePos) < 500` | 步骤23 | 500脉冲 |
| **轴停止+编码器确认** | `RUNNING==0 + count>1 + 偏差<50` | 步骤5/20 | — |
| **编码器补偿** | `偏差 >= 50` | 步骤50 | — |
| **障碍避让到位** | `abs(pos - CranePos) < 50` | CraneMovePosX 步骤5 | 50脉冲 |
| **绝对位置异常** | `curpos < 500` | 主循环 | 使用上次有效值 |

### 2.3 XY轴通用停止条件

```
轴已到位 = ((sta & AXIS_STATUS_RUNNING) == 0)
         = 轴状态中运行位清零

到位确认 = 轴已到位 + 等待一个周期(count>1) + 编码器位置校验
```

## 三、距离计算体系

### 3.1 X轴位置计算

```
天车绝对位置 epos:
  epos = 编码器原始读数 - 614400 + difDistance(校准偏移) + AbsXOffset(天车绝对偏移)

天车规划位置 pos.PosX:
  pos.PosX = lAxisPrfPos[0] / RatioX + conf.PosX

X轴相对移动量:
  disp = (EncoderPos - CranePos) × PulsePerMM
  // EncoderPos = 目标机器编码器坐标
  // CranePos = 天车当前位置
  // PulsePerMM = 19.33 (从数据库 CraneConf 配置)

X轴绝对移动:
  目标位置 = (目标位置 - conf.PosX) × RatioX  // moveDistance
  目标位置 = 原始脉冲值 × RatioX               // moveOriDistance
  目标位置 = 当前规划位置 + 位移 × RatioX       // moveRelativeDistance
```

### 3.2 障碍避让距离

```csharp
// 挡路天车在左侧:
tarposx = littlepos - 2 × Width
// littlepos = min(TaskStartPos, TaskEndPos)

// 挡路天车在右侧:
tarposx = largepos + 2 × Width
// largepos = max(TaskStartPos, TaskEndPos)

// Width = 25000 (天车宽度，从数据库加载)
```

### 3.3 天车安全距离

```
LaserSafeDis = 800 (配置值，两个天车之间的最小安全距离)
```

### 3.4 Z轴步进距离

```
DisSetpPluseZ = 10000 (Z轴到安全位置后，磁铁未触发限位时的步进脉冲数)

// 逻辑: Z轴到达目标位置但磁铁未接触工件
// → tarPosZ += 10000 → 再次向下移动 → 直到磁铁触发或限位
```

### 3.5 机器偏移距离 (XDis/YDis/ZDis)

存储在数据库 `MachineMapInfo` 表的公式字段中，运行时通过 CalPara 计算：

| 机器 | ZDis公式 |
|------|------|
| 粗车 | `{MCC1WJDQ}*(0-258.819)` |
| 下料架1 | `{MXL1WJDQ}*1.1*(0-1)*500` |
| 下料架2 | `{MXL2WJDQ}*1.1*(0-1)*500` |

公式中的 `{MXX}` 引用 DataPool 中对应机器的寄存器值（如外径读取值），然后在 `upDateDisValue()` 中计算为实际偏移量。

## 四、判断逻辑详解

### 4.1 天车任务启动前置判断

```
1. GetALLCraneGoHomeSta() == true
   → 所有天车三轴回零状态都为2(完成)
   → 失败>10次 → TaskPause=true, 切手动, 报警

2. DataPoolLoadOver == true
   → DataPool加载完成(控制设备和机器设备均已加载)

3. TaskPause == false
   → 非手动模式, 非暂停状态
```

### 4.2 机器调度状态判断

```csharp
// 优先级:
// 1. 检修状态 > 一切 (MachineSta=0 不可调度)
// 2. 预约状态 > 空闲/忙碌 (MachineSta=4 已预约)
// 3. 加工完成 > 空闲 (MachineSta=1 需下料)
// 4. 空闲 > 忙碌 (MachineSta=2 可上料)

if (Reservation == 0 || Reservation == -1)  // 未预约
{
    if (err == 0 || err == -1)  // 未检修
    {
        if (over == 1)           sta = 1;  // 加工完成→需下料
        else if (idle == 1)      sta = 2;  // 空闲→可上料
        else if (idle == 0)      sta = 3;  // 忙碌
        else                     sta = 0;  // 不可调度
    }
    else                         sta = 0;  // 检修→不可调度
}
else                             sta = 4;  // 已预约
```

### 4.3 FineIDLEMachine - 空闲机器匹配

```csharp
// 简单遍历: 找第一个 MachineType 匹配的空闲机器
// 无负载均衡，无等待队列，先到先得
int FineIDLEMachine(int machinetype, ref List<_MachineStaInfo> machine)
{
    for(int i = 0; i < machine.Count; i++)
        if (machine[i].MachineType == machinetype)
            return i;  // 立即返回第一个匹配
    return -1;
}
```

### 4.4 路权冲突判断

```csharp
// 区间重叠检测(4种情况):
(wspos <= spos && wepos >= spos) ||  // 旧区间包含新起点
(wspos <= epos && wepos >= epos) ||  // 旧区间包含新终点
(spos <= wspos && epos >= wspos) ||  // 新区间包含旧起点
(spos <= wepos && epos >= wepos)     // 新区间包含旧终点
// → 有重叠 → 任务不可调度, 从候选列表移除
```

### 4.5 天车可达性判断

```csharp
// 天车运动范围必须覆盖任务区间
(crstartx <= tstartx) && (crendx >= tendx)

// crstartx/crrendx = 天车运动范围 [StartX, EndX](从CraneConf表)
// tstartx/tendx = 任务区间 [min(源,目标), max(源,目标)]
```

### 4.6 障碍物检测

```csharp
// 天车当前位置是否在任务路径内:
(pos >= (TaskStartPos - cwidth)) && (pos <= (TaskEndPos + cwidth))

// cwidth = 天车宽度 (25000)
// 如果 ∈ 路径内 且 ≠ 执行天车 → 标记为障碍
```

### 4.7 天车有版/磁铁异常判断

```csharp
// 步骤1: 天车已有版(任务开始前)
if ((v & (1 << 3)) > 0)  // DI3=1, 有版信号
    → TaskPause=true, 报警, 红灯亮

// 步骤11: 磁铁偏了
if ((v & 0x30) > 0)  // DI4+DI5 同时有效
    → TaskPause=true, 报警, 红灯亮

// 步骤11: 没有检测到版(充磁后)
if ((v & 0x08) == 0)  // DI3=0
    → TaskPause=true, 报警, 红灯亮
```

### 4.8 编码器位置异常处理

```csharp
// 位置跳跃过滤:
if (curpos >= 500)  // 本次读数有效
    CranePos = curpos;
else  // 读数异常
    CranePos = (LastCranePos == 0) ? 500 : LastCranePos;  // 使用上次值

// 目的: 防止编码器跳变导致天车误运动
```

### 5.4 偏移公式 (XDis/YDis/ZDis)

存储在 `MachineMapInfo` 表的 `XDis, YDis, ZDis` 字段：

| 机器 | 公式字段 | 表达式 |
|------|------|------|
| 粗车 | ZDis | `{MCC1WJDQ}*(0-258.819)` |
| 下料架1 | ZDis | `{MXL1WJDQ}*1.1*(0-1)*500` |
| 下料架2 | ZDis | `{MXL2WJDQ}*1.1*(0-1)*500` |

**计算时机：** `Write(26, WorkInfo)` 被调用时，`upDateDisValue()` 解析公式并计算实际偏移值。

**语义：**
- `{MCC1WJDQ}` = 粗车的外径读取值
- Z轴偏移 = 外径 × (0-258.819) = 负向偏移（天车下降距离与外径成正比）
- 下料架 Z偏移 = 外径 × 1.1 × (-500) = 与工件尺寸成比例的下降量

### 5.5 地址编码公式

```
32位地址 = (控制器ID << 24) | 寄存器地址

示例:
  斜车1 XC1JJDW 地址 = 0x0D00006F
  → 控制器ID = 0x0D = 13 (IP末段15, 但这里用的是MachineInfoType配置)
  → 寄存器地址 = 0x00006F = 111

  实际上地址格式:
  CC = IP最后一字节 (如斜车=21的IP 192.168.1.21 → CC=21)
  AAAAAA = 内部读写地址 (101-140)
  
  完整地址 = (CC << 24) | AAAAAA
  例如斜车1空闲条件地址 218103819:
  → CC = 218103819 >> 24 = 13
  → AAAAAA = 218103819 & 0xFFFFFF = 0x0D0003EB低24位 = ...
```

## 七、充磁/退磁业务逻辑

### 7.1 充退磁时序

```
充磁(Magnetization(true)):
  setOutput(0, true)   // DO0 充磁线圈闭合
  setOutput(1, false)  // DO1 退磁线圈断开
  Thread.Sleep(30)     // 等待30ms
  读磁铁状态 getMagSta()
    → (value & 0x03) == 1 → 充磁成功

退磁(Magnetization(false)):
  setOutput(0, false)  // DO0 充磁线圈断开
  setOutput(1, true)   // DO1 退磁线圈闭合
  Thread.Sleep(30)     // 等待30ms
  读磁铁状态 getMagSta()
    → (value & 0x03) == 2 → 退磁成功
```

### 7.2 退磁失败处理

```csharp
// CraneTask 步骤28:
MagTCount++   // 失败计数
if (MagTCount > 10)  // 超过10次失败
{
    crane.Magnetization(true);   // 先充磁
    crane.Magnetization(false);  // 再退磁(防止卡死)
    MagTCount = 0;
}
```

### 7.3 磁铁状态位

```
getMagSta():
  Value = (DI & 0x00C0) >> 6
  → 0x01 = 充磁到位
  → 0x02 = 退磁到位
```

```csharp
// 触发条件: DisShake > 0 (数据库中配置，>0表示需要抖动)
count = 0;
count1 = DisShake;  // 基础抖动距离

// 抖动5个周期:
count=0: (+ 2*count1) → 正向2倍距离
count=1: (- 2*count1) → 反向2倍距离
count=2: (+ 2*count1) → 正向2倍距离
count=3: (- 2*count1) → 反向2倍距离
count=4: (+ 2*count1) → 正向2倍距离
count=5: (- count1)   → 回中(回到原位)
count>5: 完成 → 下一步

// 速度: LowRapidVelX (25 pulse/ms)
// 目的: 通过微小往复运动松动工件(克服机器夹持后的静摩擦)
```
