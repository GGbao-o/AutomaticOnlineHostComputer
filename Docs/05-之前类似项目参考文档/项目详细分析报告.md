# 三太自动线调度管理系统 — 详细分析报告

## 一、项目概述

**项目名称：** 三太自动线调度管理系统 (Axis_Move)

**技术栈：** C# WinForms (.NET Framework) + SQL Server

**核心功能：** 通过天车(行吊)在多台加工设备之间自动搬运版辊(印刷辊筒工件)，实现版辊加工全流程的自动化调度。

**版辊加工流程：** 上料架 → 打标机 → 研磨机 → 斜车 → 双头镗床（粗车）→ 下料架

## 四、天车（下位机设备）详细分析

天车是整个系统的核心执行机构，不经过Modbus/PLC，直接通过运动控制卡控制。

### 4.1 硬件配置

天车使用**东莞博派运动控制卡**（MultiCardCS），通过UDP网络协议通信。

**一号天车：**
- 控制卡IP: 192.168.1.4:60005
- 编码器IP: 192.168.1.5:1030
- 初始位置: X=170, Y=-215062, Z=-5327
- 宽度(PosWidth): 25000 (=250mm)
- 绝对X偏移: 490
- 运动范围: StartX=130000, EndX=299000
- Z轴限位: LimitZP=1099999, LimitZN=800000
- X轴脉冲/mm: 19.33
- 减速比: X=1, Y=1, Z=2

**二号天车：**
- 控制卡IP: 192.168.1.14:60001
- 编码器IP: 192.168.1.15:1030
- 初始位置: X=-521401, Y=-239430, Z=-2371
- 宽度: 25000
- 绝对X偏移: 9190
- 运动范围: StartX=20000, EndX=200000

### 4.2 天车三轴定义

| 轴号 | 功能 | 运动类型 | 限位 |
|:---:|------|------|------|
| Axis 1 | X轴 (水平行走) | 点位运动(Trap) | 正/负硬限位 + 软限位 |
| Axis 2 | Y轴 (横向移动) | 点位运动(Trap) | 正/负硬限位 + 软限位 |
| Axis 3 | Z轴 (升降) | 点位运动(Trap) | 正/负限位 + 原点开关 |

#### 数字量输入 (DI, getInput / getExtInput)

| 输入位 | 功能 | 位掩码 | 说明 |
|:---:|------|:---:|------|

| DI2 | 磁铁下压限位 | `v & 0x04` | Z轴下降到位(磁铁接触工件) |

#### 磁铁状态检测(getMagSta)

```csharp
Value = (Value & 0x00C0) >> 6;
// 0x01 = 充磁完成, 0x02 = 退磁完成
```

### 4.6 运动模式

三种运动方式：

1. **`moveDistance(Axis, Dis, speed, acc, dec)`** — 绝对定位
   - 目标位置 = `(Dis - conf.PosX/Y/Z) * Ratio`
   
2. **`moveOriDistance(Axis, Dis, speed, acc, dec)`** — 原始脉冲位置定位
   - 目标位置 = `Dis * Ratio`（不减去配置偏移）

3. **`moveRelativeDistance(Axis, Dis, speed, acc, dec)`** — 相对移动
   - 读取当前规划位置 `dPrfPos`
   - 目标位置 = `dPrfPos + Dis * Ratio`

4. **`JogMove(Axis, speed)`** — 速度模式(JOG)
   - 连续移动，用于手动控制

## 五、天车任务状态机 (CraneTask, 31步)

### 5.1 阶段总览

```
阶段A: 准备出发 (步骤1-3)
  → 检测有版、退磁、Z轴上升、关接液盘

阶段B: 去源位置取料 (步骤4-9)
  → XY移动到源机器、开接液盘、Z下降

阶段C: 取料+抖动 (步骤10-15)
  → 充磁、等机器松开、抖动松件、XY偏移

阶段D: 搬运到目标 (步骤16-22)
  → Z上升、下发加工数据、XY移动到目标、开接液盘

阶段E: 放料+收尾 (步骤23-31)
  → Z下降放料、等机器夹紧、退磁、Z上升、关接液盘

补偿: 步骤50 (X轴位置补偿)
```

### 5.2 详细步骤

#### 步骤1 — 检查+退磁+Z轴上升

```
判断: DI3(有版) == 1 → 暂停任务、报警红灯亮
动作: 退磁(false)、Z轴移动到原点(0)
```

#### 步骤2 — 等待Z轴到位+关接液盘

```
等待: AXIS_STATUS_RUNNING == 0 或 HOME_SWITCH == 1
条件: pos.PosZ <= 5 (已到顶点)
动作: LiquidTray(false) 关闭接液盘
```

#### 步骤3 — 等待接液盘关闭到位

```
等待: (v & 0x02) > 0
动作: 清理接液盘关闭信号
```

#### 步骤4 — XY轴移动到源位置

```
X轴: moveRelativeDistance(1, (EncoderPos-CranePos)*PulsePerMM, FastRapidVelX)
Y轴: moveDistance(2, mpos.PosY, FastRapidVelY)
```

#### 步骤5 — 等待XY到位

```
等待: X+Y轴 RUNNING==0, count>1
判断: abs(EncoderPos - CranePos) < 50
  → 是: 跳步骤6
  → 否: 跳步骤50(X轴补偿)
```

#### 步骤6 — 打开接液盘+Z轴快速下降

```
前置: 接液盘打开到位 (v&1)>0
前置: 读机器(113)请求下料 >0
动作: Z轴快速移动到安全Z位置(posSafeZ)
CraneMoveSta = 1 (到达源位置上方)
```

#### 步骤7 — 等待Z轴到安全Z位

```
判断: abs(pos.PosZ - tarPosZ) < 3 → 步骤8
否则重新发送移动指令
```

#### 步骤8 — 到达安全Z位置

```
直接跳步骤9
```

#### 步骤9 — Z轴慢速下降取料

```
速度: LowRapidVelZ
到位条件: (v & 0x04) > 0 (磁铁下压限位) 或 Axis3sta & 0x20 (Z正限位)
  → 停止Z轴 → 步骤10
未触发限位但轴已到位:
  → tarPosZ += DisSetpPluseZ, 继续步进
```

#### 步骤10 — 充磁吸取工件

```
动作: Magnetization(true)
  → DO0=1, DO1=0, 等30ms
  → 检测磁铁状态 (value&0x03)==1 → 成功
```

#### 步骤11 — 检查取料结果

```
磁铁偏了 (v & 0x30) > 0 → 暂停报警
有版 (v & 0x08) > 0:
  → 写"天车靠近"(CrownBlockNear)=1
  → 写"天车下料到位"(CraneCuttingInPlace)=1
  → 步骤12
无版 → 暂停报警
```

#### 步骤12 — 等待机器松开工件

```
读机器(105)已松开状态 >0
清除: 天车靠近=0, 天车下料到位=0
判断: DisShake > 0 → 步骤13(抖动), 否则→步骤14
```

#### 步骤13 — 抖动工件(松件)

```
X轴往复抖动5次:
  count<5:
    奇数(1,3): 正向移动 2*count1
    偶数(2,4): 反向移动 -2*count1
  count==5: 回中 -count1
  count>5: 步骤14
```

#### 步骤14 — XY偏移(下料偏移)

```
setLoaderSta(0) 下料模式
moveRelativeDistance: -mpos.PosX, -mpos.PosY (反向偏移)
```

#### 步骤15 — 等待XY偏移到位

#### 步骤16 — Z轴快速上升到安全Z

```
moveDistance(3, PosSafeZUp, FastRapidVelZ)
```

#### 步骤17 — 下发加工数据到目标机器

这是**数据量最大**的步骤，向目标机器写入：

| 数据项 | 线号 | 说明 |
|--------|------|------|
| 天车下料完成 | CrownBlockDischargegCompleted | 通知源机器 |
| 加工信息(WorkInfo) | Write(26) | 整体加工信息对象 |
| 外径 | OutsideDiameter | |
| 内径 | InsideDiameter | |
| 长度 | Length | |
| 大小孔标记 | BigOrSmall | 内径>阈值→1(大孔) |
| 加工模式 | ProcessingMode | LatheProcessNum |
| 打印内容 | PrintContents | |
| 堵头厚度 | Thickness | |
| 内孔斜度 | InnerInclination | |
| 数据传输完成 | DataTranOver | 通知目标机器数据已下发 |

然后Z轴上移到顶点 `moveOriDistance(3, 0)`

#### 步骤18 — 等待Z到顶+关接液盘

```
pos.PosZ <= 5 + (v&2)>0
```

#### 步骤19 — XY移动到目标位置

```
X: moveRelativeDistance(1, (TargetEncoderPos-CranePos)*PulsePerMM)
Y: moveDistance(2, 目标上料位置)
CraneMoveSta = 2 (去目标位置)
```

#### 步骤20 — 等待XY到位

```
abs(EncoderPos - CranePos) < 50
```

#### 步骤21 — 开接液盘+确认目标机器请求上料

```
读机器(112)请求上料 >0
清除源机器下料完成信号
```

#### 步骤22 — 等待接液盘打开+Z到安全Z

#### 步骤23 — 确认X到位后Z慢速下降

```
abs(EncoderPos - CranePos) < 500
```

#### 步骤24 — 等待Z到位

```
磁铁下压限位 或 Z正限位 → stopMove(3)
```

#### 步骤25 — XY偏移(上料偏移)

```
setLoaderSta(1) 上料模式
moveRelativeDistance: +mpos.PosX, +mpos.PosY
```

#### 步骤26 — 等待XY到位+发信号

```
写"天车靠近"=1, "天车上料到位"=1
```

#### 步骤27 — 等待目标机器夹紧

```
读机器(104)已夹紧 >0
转移加工信息: Write(26, WorkInfo)
源机器: WorkInfoClear()
```

#### 步骤28 — 退磁松开工件

```
Magnetization(false)
失败超过10次: 先充磁再退磁(防止卡死)
```

#### 步骤29 — Z轴快速上升到安全Z

#### 步骤30 — 等待Z到位+发信号

```
写"天车远离"=1, "天车上料完成"=1
```

#### 步骤31 — Z上升到顶+关接液盘+清理

```
pos.PosZ <= 5 + (v&2)>0
清理所有信号, 任务完成(taskSta=0), 释放路权
```

#### 补偿步骤50 — X轴位置补偿

```
循环: 当 abs(EncoderPos - CranePos) >= 50
  moveRelativeDistance(1, (EncoderPos-CranePos)*PulsePerMM, LowRapidVelX)
直到偏差 < 50, 跳回原步骤
```

              │   遍历Over机器:                │
              │    根据工艺找下一道空闲机器     │
              │   遍历上料架(有板):            │
              │    找第一道工序空闲机器         │
              │   遍历下料架(有板):            │
              │    到达即删除任务              │
              └───────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │ 5. 路权冲突检测 → 过滤任务     │
              │   新任务 [start,end] 与已有     │
              │   路权区间不重叠才可执行        │
              │   任务之间路径不冲突            │
              └───────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │ 6. 天车分配                    │
              │   空闲天车 + 可达范围匹配       │
              │   最近原则选择                  │
              └───────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │ 7. 障碍物检测                  │
              │   天车路径上是否有其他天车挡路  │
              │   有障碍 → CraneMovePosX()避让 │
              │   无障碍 → CraneTask()执行任务  │
              └───────────────────────────────┘
```

### 6.2 机器状态判定

| 条件 | MachineSta | 含义 | 调度行为 |
|------|:---:|------|------|
| Read(101) idle=1 | 2 | 空闲可上料 | 作为目标机器 |
| Read(103) over=1 | 1 | 加工完成需下料 | 作为源机器 |
| Read(101) idle=0 | 3 | 忙碌中 | 不参与调度 |
| Read(102) err=1 | 0 | 检修中 | 不可调度 |
| Read(120)=1 | 4 | 已预约 | 不可调度 |

### 6.3 任务生成逻辑

```
1. 遍历 ListMachineOver(加工完成):
   - 取该机器的加工信息(WorkInfo)
   - 从TaskInfo中查找工艺工序列表
   - 获取下一道工序 WorkShip[1]
   - FineIDLEMachine(工序机器类型, ListMachineIDLE) 找空闲目标
   - 找到 → 生成 CraneTaskInfo {源, 目标, 编码器位置}

2. 遍历上料架(MachineType==1):
   - 从TaskBordID取未开始的任务
   - 找第一道工序的空闲机器
   - 生成 CraneTaskInfo

3. 遍历下料架(MachineType==2):
   - 有板 → 到达即从TaskBordID/TaskInfo删除任务
```

### 6.4 路权(Road Right)管理

每个天车在 `WayRightHash` 中维护独占区间 `[start, end]`：

```
天车任务路径区间 = [min(源,目标), max(源,目标)]

冲突检测: 新区间与已有区间不重叠
  (wspos <= spos && wepos >= spos) ||  // 已有区间包含新起始
  (wspos <= epos && wepos >= epos) ||  // 已有区间包含新结束
  (spos <= wspos && epos >= wspos) ||  // 新区间包含旧起始
  (spos <= wepos && epos >= wepos)     // 新区间包含旧结束

动态收缩:
  CraneMoveSta=0 (去源位置):
    - 源>目标: 收缩end=CranePos; 或收缩start=CranePos
  CraneMoveSta=2 (去目标位置):
    - 源>目标: 收缩end=CranePos; 或收缩start=CranePos
```

### 6.5 障碍物避让 (CraneMovePosX)

当空闲天车挡在任务天车的路径上：

```
1. 挡路天车Z轴上升到顶点
2. 接液盘关闭
3. X轴移动到任务路径外的安全距离:
   - 挡路天车在主天车左侧 → 移到任务区间左侧: littlepos - 2*Width
   - 挡路天车在主天车右侧 → 移到任务区间右侧: largepos + 2*Width
4. 到位后用 ContinueWith 启动主天车的 CraneTask
```

### 6.6 天车分配原则

1. 天车运动范围必须覆盖任务区间 `[start, end]`
2. 优先分配距离任务起点最近的天车
3. 一个天车同时只能执行一个任务
4. 任务之间按源位置排序(从大到小)，按序分配

## 九、地址路由机制 (DataPool 三层映射)

### 9.1 地址编码

```
0xCCAAAAAA (32位整数)

  CC      = 控制器ID (IP最后一字节, 如 192.168.1.33 → CC=33)
  AAAAAA  = 实际寄存器地址 (24位, 如 100-140)
```

### 9.2 路由流程

```
线号 (如 "XC1YSK")
  ↓ LineNoHash[线号] → 32位地址
  ↓
地址 0xCCAAAAAA
  ↓ (addr & 0xFF000000) >> 24 → 控制器ID (CC)
  ↓ (addr & 0x00FFFFFF) → 寄存器地址 (AAAAAA)
  ↓
controlHash[CC] → 具体设备对象
  ↓
设备对象.Read(AAAAAA) 或 .Write(AAAAAA, value)
```

### 9.3 公式表达式系统 (CalPara)

公式示例：
```
{@XC1WZFK}==1:已松开:255,0,255
```

- `{@线号}` → 查DataPool → 查controlHash → 读设备具体寄存器
- `{M线号}` → 查机器DataPool → 查MachineHash → 读UniversalMachine
- 支持数学运算：`+ - * / ( )`
- 使用 `CalculatorDec` 中缀→后缀表达式计算器

### 10.1 取料流程（源机器：下料）

              ↓

```

### 10.2 放料流程（目标机器：上料）

## 十一、异常处理与暂停条件

| 条件 | 触发位置 | 处理 |
|------|------|------|
| 天车未回零点(>10次) | ScheduledTasks入口 | 暂停所有任务、报警 |
| 天车已有版(DI3=1) | CraneTask步骤1 | 暂停、切手动、红灯亮 |
| 磁铁偏了 `(v&0x30)>0` | CraneTask步骤11 | 暂停、报警 |
| 未检测到版 `(v&0x08)==0` | CraneTask步骤11 | 暂停、报警 |
| 手动模式切换 | `TaskPause = true` | 天车三轴停止 |
| 控制卡连接断开(>100次) | DataTask线程 | `OpenFlag = false` |
| 退磁失败(>10次) | CraneTask步骤28 | 先充磁再退磁(防卡死) |
| 编码器位置异常(<500) | CraneTask主循环 | 使用上次有效位置 |
| 公式计算返回Error | CalPara | 使用null判断跳过 |

## 十五、运动业务逻辑深度总结

### 15.1 天车运动的本质

天车是沿X轴(水平轨道)行走的桥式起重机，Y轴为横向微调，Z轴为升降。整个系统是一个**多天车共享轨道的空间调度系统**，核心约束是：

1. **轨道独占**：同一段X轴区间同时只能被一个天车使用（路权机制）
2. **任务不可抢占**：天车一旦分配任务，执行到底
3. **障碍检测**：空闲天车不能挡路

### 15.2 取料与放料的物理过程

```
取料(下料)：
  天车移动到机器上方 → Z轴快降到安全高度 → Z轴慢降接触工件
  → 磁铁充磁吸附 → 等机器松开工件 → 抖动松件
  → X/Y偏移(离开机器范围) → Z轴快升 → 搬运

放料(上料)：
  天车移动到目标上方 → 下发加工数据 → Z轴快降到安全高度
  → Z轴慢降放工件 → X/Y偏移(进入机器范围) → 退磁释放
  → 等机器夹紧 → Z轴快升 → 离开
```

### 15.3 偏移公式系统

每个机器配置了X/Y/Z偏移公式，根据上料/下料状态动态计算偏移值：

```csharp
// 下料偏移值 = 机器坐标 + 偏移公式计算结果
getDownPos(): pos.PosX = posX + XDisValue; pos.PosY = posY + YDisValue; ...

// 上料偏移值 = 机器坐标 + 偏移公式计算结果  
getUpPos(): pos.PosX = posX; pos.PosY = posY; pos.PosZ = posZ + ZDisValue;
```

偏移公式存储在数据库中，格式如：
```
{MXC1CDDQ}*(0-500)-40000-({MXC1DXKDQ}*51000)
```

### 15.4 抖动机制

抖动的目的是在取料后松开机器夹持时产生的静摩擦力。天车X轴以微小位移往复运动5次：

```
正向位移 → 反向位移 → 正向位移 → 反向位移 → 回中
距离逐步增大: DisShake → 2*DisShake → 反向2*DisShake → ...
```

### 15.5 安全保护层级

| 层级 | 保护措施 |
|:---:|------|
| 硬件 | 正/负硬限位开关、急停开关(DI15) |
| 固件 | 软限位(GA_SetSoftLimit)、报警输入 |
| 软件 | 路权互斥、障碍物避让、天车安全距离(LaserSafeDis=800) |
| 逻辑 | 天车宽度避让(±2*Width)、位置异常过滤、编码器补偿 |

### 15.6 Z轴速度策略

```
快速移动 (FastRapidVelZ):
  - Z轴上升回原点
  - Z轴快速下降到安全Z位置

慢速移动 (LowRapidVelZ):
  - Z轴接近工件(安全Z→工件表面)
  - 防止磁铁撞击工件
```
