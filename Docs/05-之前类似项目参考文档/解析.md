


# 天车运动逻辑完整分析

整个天车系统是一个基于状态机的调度执行系统，核心文件：
- **Form1.cs** — 调度主逻辑 (ScheduledTasks, CraneTask, CraneMovePosX)
- **CraneDGBP.cs** — 东莞博派控制卡硬件封装（三轴运动、IO控制）
- **Crane.cs** — 摩升泰控制卡硬件封装

---

## 一、整体架构

```
ScheduledTasks() 调度线程
  ├── 1. 扫描所有机器状态 (空闲/忙碌/完成/预约)
  ├── 2. 生成任务列表 (_CraneTaskInfos)
  ├── 3. 路权冲突检测 → 过滤不可达任务
  ├── 4. 天车分配 (空闲天车 + 可达范围匹配)
  ├── 5. 障碍物检测 → 决定是否需要让路
  └── 6. 启动 CraneTask() / CraneMovePosX()
```

---

## 二、天车任务状态机 (CraneTask, 共 31 步)

### 阶段 A：准备出发 (TaskProgress 1-3)

| 步骤 | 动作 | 判断条件 |
|:---:|------|----------|
| **1** | 检查天车是否有版 | `(v & 0x08) > 0` → 有版则暂停任务、报警 |
| | 退磁 + Z轴上升到顶点(0位) | 无条件执行 |
| **2** | 等Z轴到位 | `AXIS_STATUS_RUNNING == 0` 或 `HOME_SWITCH == 1` |
| | 关闭接液盘 | 要求 `pos.PosZ <= 5` (已到顶) |
| **3** | 等接液盘关闭到位 | `(v & 0x02) > 0` 反馈信号 |

### 阶段 B：去源位置取料 (TaskProgress 4-9)

| 步骤 | 动作 | 判断条件 |
|:---:|------|----------|
| **4** | X轴相对移动到源机器编码器位置 `EncoderPos - CranePos`，Y轴绝对移动到 `mpos.PosY` | 快移速度 `FastRapidVelX/Y` |
| **5** | 等XY到位 | X+Y 停止运行 + `count>1` + `abs(EncoderPos - CranePos) < 50` |
| | 不到位则跳步骤50补偿 | ← X轴位置补偿逻辑 |
| **6** | 打开接液盘 | `(v & 0x01) > 0` 到位 + 读机器(113)请求下料状态 >0 |
| | Z轴快速下降到安全Z位置 | `mpos.PosSafeZ` → `FastRapidVelZ` |
| **7** | 等Z到位 | `RUNNING==0` + `abs(pos.PosZ - tarPosZ) < 3` |
| **8** | 到达安全Z位置 | 直接跳步骤9 |
| **9** | Z轴慢速下降 | `LowRapidVelZ` 下降 |
| | 等磁铁下压限位或Z轴正限位 | `(v & 0x04) > 0` 或 `Axis3sta & 0x20` → 停止Z轴 |
| | 若轴已到位但未触发限位 | `tarPosZ += DisSetpPluseZ` 再走一步 |

### 阶段 C：取料 + 抖动 (TaskProgress 10-15)

| 步骤 | 动作 | 判断条件 |
|:---:|------|----------|
| **10** | 充磁吸取工件 | `Magnetization(true)` 成功 |
| **11** | 检查磁铁状态 | `(v & 0x30) > 0` → 磁铁偏了，暂停报警 |
| | 检查有版信号 | `(v & 0x08) > 0` → 下发"天车靠近"+"下料到位"信号给PLC |
| | | 无版 → 暂停报警 |
| **12** | 等源机器松开工件 | 读机器(105)已松开状态 >0 |
| | 若机器有抖动需求 | `DisShake > 0` → 进入步骤13，否则直接14 |
| **13** | 抖动工件 (X轴往复5次) | `count<5` 时奇偶次反向移动 → `2*count1` |
| **14** | X轴Y轴偏移(下料偏移) | `setLoaderSta(0)` → `moveRelativeDistance(-mpos.PosX, -mpos.PosY)` |
| **15** | 等XY到位 | `RUNNING==0` |

### 阶段 D：搬运到目标 (TaskProgress 16-22)

| 步骤 | 动作 | 判断条件 |
|:---:|------|----------|
| **16** | Z轴快速上升到安全Z | `PosSafeZUp` |
| **17** | 等Z到位 + 下发加工数据 | 内径、外径、长度、堵头厚度、内孔斜度、加工模式、打印内容等全部写入目标PLC |
| | Z轴上升到顶点 | `moveOriDistance(3, 0)` |
| **18** | 等Z到顶 + 关接液盘 | `pos.PosZ <= 5` + `(v&2)>0` |
| **19** | X相对移动到目标编码器位置，Y绝对移动到目标上料位置 | `CraneMoveSta = 2` (更新路权) |
| **20** | 等XY到位 | `abs(EncoderPos - CranePos) < 50` |
| **21** | 打开接液盘 + 读目标机器(112)请求上料 | 清除源机器下料完成信号 |
| **22** | 等接液盘打开 + Z轴到安全Z | `(v&1)>0` |

### 阶段 E：放料 + 收尾 (TaskProgress 23-31)

| 步骤 | 动作 | 判断条件 |
|:---:|------|----------|
| **23** | 确认X到位后Z慢速下降 | `abs(EncoderPos - CranePos) < 500` |
| **24** | 等Z到位 | 磁铁下压限位 或 Z正限位 → `stopMove` |
| **25** | XY偏移(上料偏移) | `setLoaderSta(1)` → `moveRelativeDistance(mpos.PosX, mpos.PosY)` |
| **26** | 等XY到位 + 下发"天车靠近"+"上料到位" | |
| **27** | 等目标机器夹紧 | 读机器(104)夹紧状态 >0 → 转移加工信息 |
| **28** | 退磁松开工件 | `Magnetization(false)`，失败超过10次先充磁再退 |
| **29** | Z轴快速上升到安全Z | `PosSafeZUp` |
| **30** | 等Z到位 + 下发"天车远离"+"上料完成" | |
| **31** | Z轴上升到顶点 + 关接液盘 + 清除信号 | `pos.PosZ <= 5` + `(v&2)>0` → 任务完成 |

### 补偿步骤 50：X轴位置补偿

当 XY 到位但编码器偏差 `>= 50` 时触发，循环移动直到 `abs(EncoderPos - CranePos) < 50`。

## 三、路权(Road Right)管理

- 每个天车在 `WayRightHash` 中维护路权区间 `[start, end]`
- `CraneMoveSta=0`（去源位置）：动态收缩 `wayInfo.start/end`
- `CraneMoveSta=2`（去目标位置）：收缩到天车当前位置
- 新任务必须与所有已有路权不重叠才能执行

---

## 四、障碍物避让

当有空闲天车挡路时（`CraneMovePosX`）：

1. 挡路天车Z轴上升到顶 → 接液盘关闭
2. X轴移动到任务路径外的安全距离（`± 2*Width`）
3. 到位后 `ContinueWith` 启动主天车的 `CraneTask`

## 五、异常暂停条件汇总

| 条件 | 触发位置 |
|------|----------|
| 天车未回零点（超过10次检测） | `ScheduledTasks` 入口 |
| 天车检测到有版(DI3=1) | 步骤1 |
| 磁铁偏了 `(v & 0x30) > 0` | 步骤11 |
| 没有检测到版 | 步骤11 |
| 手动模式切换 | `TaskPause = true` |


- **CC** = 控制器 ID (取 IP 最后一字节)
- **AAAAAA** = 实际寄存器地址

**两层映射表（来自数据库）：**
- `MachineMapPara` 表：ParaCode ↔ ParaAddr
- `MachineRegInfo` 表：Code ↔ MachineAddr

## 二、上下料架 (MaterialRack) — Modbus TCP

**协议:** 读 Input Coil (功能码02)，写 Holding Register (功能码06)

### 读取

从地址 0 开始，一次性读取 4 个线圈

| 内部 Read Addr | Modbus地址 | 功能 |
|:---:|:---:|------|
| 100 | 线圈 0 | 状态位0 |
| 101 | 线圈 1 | 状态位1 |
| 102 | 线圈 2 | 状态位2 |
| 103 | 线圈 3 | 状态位3 |

### 写入

无（只有 case 1 初始化连接参数，case 2 启动读取线程）

### 状态机

上下料架为被动设备，只提供状态位，不做主动控制。调度逻辑中：
- **MachineType == 1**：上料架有板 → 从 `TaskBordID` 取未开始任务 → 生成 CraneTask
- **MachineType == 2**：下料架有板 → 到达即删除任务

## 七、UniversalMachine 统一读写映射

每个机器在 `loadMachines` 中被包装为 `UniversalMachine`，`Read(101-120)` 通过公式计算得到值（公式中的 `{@线号}` 会查询 DataPool → ControlHash → 具体设备的 Read）。

### 调度中用到的机器 Read

| 调用位置 | Addr | 功能 | 用途 |
|------|:---:|------|------|
| ScheduledTasks | 101 | 空闲状态 | 判断机器是否空闲可上料 |
| ScheduledTasks | 102 | 检修状态 | 排除检修中的机器 |
| ScheduledTasks | 103 | 加工完成 | 需要下料 |
| ScheduledTasks | 120 | 预约状态 | 已被天车预约则不可调度 |
| CraneTask 步骤6 | 113 | 请求下料 | 确认机器要下料才下降Z轴 |
| CraneTask 步骤12 | 105 | 已松开 | 等待机器松开工件后提轴 |
| CraneTask 步骤21 | 112 | 请求上料 | 确认目标机器要上料才继续 |
| CraneTask 步骤27 | 104 | 已夹紧 | 等待机器夹紧后退磁 |

## 八、天车与机器交互的信号时序

### 取料流程 (Source Machine: 下料)

```
天车 → 机器:  天车已靠近 (CrownBlockNear)                → PLC 位 置 1
天车 → 机器:  天车下料到位 (CraneCuttingInPlace)         → PLC 位 置 1
机器 → 天车:  已松开 (Read 105)                          → 天车等这个信号
天车 → 机器:  天车已靠近 (CrownBlockNear)                → PLC 位 清 0
天车 → 机器:  天车下料到位 (CraneCuttingInPlace)         → PLC 位 清 0
天车 → 机器:  天车下料完成 (CrownBlockDischargegCompleted) → PLC 位 置 1
(后续清 0)
```

### 放料流程 (Target Machine: 上料)

```
天车 → 机器:  write(26, WorkInfo)                        → 传输加工数据(外径/内径/长度/堵头厚度/内孔斜度/打印/加工模式)
天车 → 机器:  数据传输完成 (DataTranOver)                 → PLC 位 置 1
天车 → 机器:  天车已靠近 (CrownBlockNear)                → PLC 位 置 1
天车 → 机器:  天车上料到位 (CraneLoadInPlace)            → PLC 位 置 1
机器 → 天车:  已夹紧 (Read 104)                          → 天车等这个信号
天车 → 机器:  天车已靠近 (CrownBlockNear)                → PLC 位 清 0
天车 → 机器:  天车上料到位 (CraneLoadInPlace)            → PLC 位 清 0
天车 → 机器:  write(26, WorkInfo)                        → 转移加工信息
源机器:       WorkInfoClear()                             → 清空源机器加工信息
天车 → 机器:  天车已远离 (CrownBlockAway)                → PLC 位 置 1
天车 → 机器:  天车上料完成 (CrownBlockLoadingCompleted)  → PLC 位 置 1
(后续清 0)
```

## 九、各设备状态机（调度判断条件）

所有机器的状态通过 `CalPara` 公式计算，公式格式例如：

```
{@XC 1 YSK}==1:已松开:255,0,255
```

- `{@XXX}` → 查 DataPool → ControlHash → 具体设备 Read
- `==1` → 条件判断
- `:已松开` → 显示文字
- `:255,0,255` → RGB颜色

### 机器调度状态判定 (ScheduledTasks)

| 读取 | 条件 | MachineSta | 含义 |
|:---:|------|:---:|------|
| 101(空闲) | idle=1 | 2 | 空闲可上料 |
| 103(完成) | over=1 | 1 | 需要下料 |
| 101(空闲) | idle=0 | 3 | 忙碌 |
| 102(检修) | err=1 | 0 | 不可调度 |
| 120(预约) | Reservation=1 | 4 | 已预约 |

### 调度核心循环

1. 遍历 `ListMachineSta`，读每台机器的 101/102/103/120
2. 按状态分入 4 个列表：`Over` / `IDLE` / `Busy` / `Reservation`
3. 遍历 `Over` 列表 → 根据工艺找下一道空闲机器 → 生成 `CraneTaskInfo`
4. 遍历上料架(有板) → 找第一道工序的空闲机器 → 生成 `CraneTaskInfo`
5. 遍历下料架(有板) → 到达即删除任务
6. 路权冲突检测 → 过滤不可达任务
7. 分配空闲天车 → 障碍物检测 → 启动 `CraneTask` / `CraneMovePosX`

## 核心要点

- **天车**不经过Modbus，直接通过控制卡 IO 位控制（0-7路输出，8路DI输入）
- **5种加工设备**都是通过 `UniversalMachine` + 具体协议类（Modbus TCP / FANUC）双层封装
- **地址分为三层**：设备内部地址(100-140) → DataPool路由层(`0xCCAAAAAA`) → 实际PLC寄存器/宏变量
- **完整的寄存器地址配置**存储在数据库表 `MachineMapPara` 和 `MachineRegInfo` 中
