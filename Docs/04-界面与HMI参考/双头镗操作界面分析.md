## 界面元素分析

### 运行模式
- **全线运行模式**：上位机联动控制
- **加工方式**：完整=0 / 单独=1

### 交互信号状态
| 信号名 | 地址 | 界面上显示 | 备注 |
|--------|------|-----------|------|
| 设备准备就绪，请求数据 | R6101 | ✅ | 状态指示灯 |
| 下发数据，下发完成 | R6102 | ✅ | 下发按钮联动 |
| 请求上料 | R6103 | ✅ | |
| 货叉上料推入到位 | R6104 | ✅ | |
| 卡钳夹紧完成 | R6105 | ✅ | |
| 货叉上料推出完成 | R6106 | ✅ | |
| 请求下料 | R6107 | ✅ | |
| 货叉下料推入到位 | R6108 | ✅ | |
| 卡钳松开完成 | R6109 | ✅ | |
| 货叉下料推出完成 | R6110 | ✅ | |

### 数据下发区
- @740 版长
- @705 外圆成活
- @702 左侧堵厚
- @703 右侧堵厚
- @708 内孔锥度
- @707 内孔成活

## 上位机对应设计要点
- 运行模式应在上位机同步切换
- 所有 R 区交互信号需在 WPF 界面上实时显示
- 数据下发区对应上位机配方管理模块****
