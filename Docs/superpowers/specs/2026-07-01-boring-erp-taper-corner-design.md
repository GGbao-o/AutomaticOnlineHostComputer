# 双头镗ERP内孔锥度与圆角参数设计

## 目标

ERP任务由11列升级为严格13列，在末尾依次增加内孔锥度和圆角大小。手工添加任务提供两个输入框，默认值分别为10和8。两个数值随工件完整流转，并在正常双头镗加工时分别按乘100写入R2046和R2048。

## 明确不变的业务

- 不改全局FIFO、M800复位门和1/2号线分配条件。
- 不改机械手、货叉、天车、斜床、动平衡和研磨流程。
- 不改SkipBoring判断；SkipBoring任务携带并显示参数，但不写双头镗。
- 不改R2046/R2048地址、16位整数格式和乘100倍率。
- 不改R6101/R6102/R6103/R6104/R6107/R6108握手顺序、等待策略和异常策略。
- 不改直径偏移、其他双头镗参数及其倍率。

## ERP格式与校验

固定格式：

```text
打印内容,版号,序号,长度,直径,堵孔,斜床工艺,左堵厚,右堵厚,是否做动平衡,是否跳过双头镗,内孔锥度,圆角大小
```

- 只接受13列；旧11列按字段数量错误处理，保留原行并沿用现有错误备份/日志流程。
- 第12列内孔锥度、第13列圆角大小均按InvariantCulture解析浮点数。
- 两项都必须大于0且不超过655.35，保证乘100并四舍五入后可写入16位无符号寄存器。

## 数据流

两个正式字段依次经过：

```text
ErpTaskImportParser / AddTaskDialogViewModel
  -> TaskRowViewModel
  -> HomeViewModel.BuildWorkpieceCache
  -> WorkpieceCache
  -> Line1FrontFlowEngine / Line2FrontFlowEngine
  -> BoringModbusService.SendMachiningParamsAsync
  -> R2046 / R2048
```

涉及工件复制的路径必须保留这两个字段，不能在中转架、动平衡或研磨缓存转换时丢失。

## 页面

- 添加任务弹窗新增“内孔锥度”和“圆角大小”输入框，默认10和8。
- 手工确认时执行与ERP一致的范围校验。
- 主页面任务列表新增两列，直接显示任务实际值。

## 双头镗写入

- `BoringModbusService.SendMachiningParamsAsync`接收内孔锥度和圆角大小参数。
- R2046写`Round(内孔锥度 × 100, AwayFromZero)`。
- R2048写`Round(圆角大小 × 100, AwayFromZero)`。
- 服务层再次执行有限值、范围和16位校验，防止绕过UI/ERP的调用写入非法值。
- 日志同时输出原始值和最终寄存器整数，便于现场核对。

## 验证

- 13列合法ERP行解析成功，两个字段值正确。
- 11列、零值、负值、超过655.35和非数字均解析失败并保留原行。
- 手工添加默认显示10/8，可编辑，非法值不能创建任务。
- 1号线和2号线正常任务都把实际值传给双头镗。
- SkipBoring不写任何R2041~R2048参数。
- 编译成功；检索确认不再存在R2046=1000/R2048=800的活动写入。
