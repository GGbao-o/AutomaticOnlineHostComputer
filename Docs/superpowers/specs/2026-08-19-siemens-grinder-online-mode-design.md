# 西门子研磨机联机模式准入设计

## 目标

西门子研磨机 ST703、ST704 新增输入 `40001-3`：`0` 为单机、`1` 为联机。只有联机状态为 `1` 的西门子研磨机才能接收新的自动上料任务；单机不暂停研磨引擎，也不影响其他研磨机或本机已经开始的下料。

## 规则

1. `40001-3` 按现有 TypeA 协议的 bit0 起算规则对应 bit3；同一份 `TypeAStatusSnapshot` 解析为 `OnlineMode`。
2. ST701、ST702（新代 TypeB）不读取、不受此条件影响。
3. `FindReadyGrinder()` 保留原有 Idle、请求数据、连接、无 Pending、无磨石报警条件；对 TypeA 额外要求 `OnlineMode=true`。条件不满足时 FIFO 不出队、不抢天车锁、不创建动作。
4. 正式上料流程在已有的 TypeA 取料前二次快照中再次检查联机状态。若已切单机，工件仍在 ST709：目标机回 Idle、Pending 清空、工件回 FIFO 队头并释放天车锁；不暂停引擎。
5. 设备总览卡和全流程状态共用的 ST703/ST704 站卡显示“联机”或“单机模式，停止自动分配”；原始 DI 详情中保留 `联机=0/1`。

## 不变项

- 不改变 ST709/M730 实时确认、FIFO 先后、天车锁、派发门闩、PLC 写入、X11、门锁及上/下料握手。
- 单机模式仅拦截新的 `Loading`；Machining、WaitingForUnload、Unloading 保持既有流程。
- `40001-0/1/2` 的故障及磨石报警语义不变。
