# 动平衡机械手来源缓存转在途与提前释放位置锁设计

## 目标

缩短后天车等待动平衡区域位置锁的时间，同时保持工件身份、物理归属、人工结案和缓存不丢失。

机械手2和机械手3的提前释放时机不同：

1. 机械手2持板从 M817/ST019 或 ST020/M818 前往 ST008/M710 时，在该段既有轮询得到的实际 `Y < 配置阈值` 后释放本趟 M817/M818 来源区域锁。此后机械手2继续完成 ST008 的下降、退磁、Z 安全回升和 M711 通知。
2. 机械手3必须完成 ST010/M720 放料、Z 安全回升、M721 和研磨 FIFO 通知；随后从 ST010 回安全 Y 的途中，在既有轮询得到的实际 `Y < 配置阈值` 后释放 M821/M720 锁。

## 不变边界

1. 不能以“充磁调用成功”作为取走证据。只有 X11=1 且 Z 已到安全高度，才能确认工件已离开来源。
2. 机械手2持板去 ST008 的全程，在轮询得到实际Y小于M2阈值前必须继续持有本趟位置锁；不能在开始持件、写 M824 或读取 M710 时提前释放。
3. 机械手3持板去 ST010、目标下降、退磁、M721 和研磨 FIFO 闭环前必须继续持有 M821/M720 锁。
4. 位置锁提前释放不改变 M2Busy、M3Busy、动作版本、取消令牌、动作账本或安全暂停语义。
5. 阈值仅由配置文件和配置管理页面提供，不增加范围、上下限、相对坐标或自动合法性校验。现场人员负责配置正确的物理安全值。
6. 不能在 `MoveAbsoluteAsync` 返回后读取 Y 再决定释放；必须以该次运动过程中的实际 Y 反馈为证据。
7. 通信失败、移动超时、取消、Y 读取失败或尚未得到小于阈值的实际Y时，不执行正常路径的提前释放；仍由既有异常/`finally` 收尾语义处理。

## 核心状态模型

来源缓存不再一直代表“本趟工件仍在来源”。在确认取走后，工件必须从来源缓存转为动作自身的在途数据。

1. `AtSource`：工件在 `_balWps["M817"]`、`_balWps["M818"]` 或 `_balWps["M821"]` 中，尚未确认由机械手持有。
2. `OnCarrier`：X11=1 且 Z 安全到位后，来源缓存原子移除，完整工件转入机械手对应的 `InFlightWorkpiece`；动作账本归属为机械手持件。
3. `AtTargetPendingHandoff`：目标退磁成功后，工件事实为已在 ST008/M710 或 ST010/M720；等待 M711、M721 或研磨 FIFO 闭环。
4. `Completed`：目标通知成功、必要缓存回调成功且动作正常结束后，清除本动作的在途数据。

`InFlightWorkpiece` 必须是业务状态，不能只复用页面展示字段。它至少保存完整 `WorkpieceCache`、来源位置、目标位置、动作版本和当前归属阶段，供异常页面、人工账本结案和应急逻辑使用。

来源缓存转在途必须以单个同步辅助操作完成：确认本趟来源缓存仍为预期工件、移除来源键、写入在途记录。该过程不得插入 `await`，不得出现“来源缓存已删除但在途记录尚未建立”的可观察中间状态。

## 机械手2流程

1. M817 来源取得 M817、M818 两把位置锁；ST020/M818 来源只取得 M818 锁。
2. ST020 来源在锁内二次确认 M823=1。
3. 从来源缓存取得完整工件；缓存最多等待 5 秒，缺失则暂停。
4. 读取来源坐标，确认 X11=0，写入机械手2本趟速度。
5. Y 到 M817/ST019 或 ST020/M818；Z 下降到按直径计算的取料高度。
6. 充磁并最多三次确认 X11。
7. X11=1 后 Z 上升至安全高度。
8. Z 安全确认后，将 M817 或 M818 来源缓存转为 M2 `InFlightWorkpiece`；位置锁仍保持。
9. ST020 来源写 M824=1；M817 来源不写 M824。失败时工件仍为 M2 持件，不能恢复来源缓存。
10. 二次确认 M710=1；读取失败或 M710=0 时，保持持件并按既有暂停处理。
11. 发出 Y 到 ST008/M710 的运动。由这次运动自身的状态轮询观察 Y。
12. 仅当本段运动轮询观察到实际Y小于M2阈值时，释放本趟实际持有的锁：M817 来源释放 M818 后再释放 M817；ST020 来源只释放 M818。记录实际 Y、阈值、来源和释放锁名。
13. 即使锁已释放，M2Busy、动作账本和 `InFlightWorkpiece` 继续保持；机械手继续完成 ST008 的 Z 下降、退磁、Z 安全回升。
14. 退磁成功后归属转为 `AtTargetPendingHandoff`。写 M711 成功后完成目标交接；不再按来源键删除缓存。
15. 动作结束时清理 M2 `InFlightWorkpiece`、任务牌和 Busy；`finally` 仅兜底释放尚未提前释放的锁，必须保持幂等。

## 机械手3流程

1. 固定取得 M821、M720 两把位置锁。
2. ST021/M821 来源在锁内二次确认 M825=1，并读取完整来源缓存；M700 来源从 MC65 D100 读取有效直径。
3. 读取来源坐标，确认 X11=0，写入机械手3本趟速度。
4. Y 到 M700/ST009 或 ST021/M821；Z 下降、充磁并最多三次确认 X11。
5. X11=1 后 Z 上升至安全高度。
6. M821 来源在 Z 安全确认后转为 M3 `InFlightWorkpiece`；M700 来源在此时建立只有可靠直径的 M3 在途工件。M821/M720 锁仍保持。
7. ST021 来源写 M826=1；M700 来源写 M701=1。
8. 二次确认 M720。M720=0 时保持持件、安全 Z、两把锁和 M3Busy，持续等待；读取失败仍按状态未知暂停。
9. M720=1 后，Y 到 ST010/M720，Z 下降、退磁、Z 回安全高度。
10. 工件归属转为 `AtTargetPendingHandoff`，依次完成 M721、研磨 FIFO 和必要来源账本闭环；不得再按 M821 来源键删除已转移的旧工件。
11. 从 ST010 回机械手3安全 Y。由这次 Y 回程自身的状态轮询观察 Y。
12. 仅当本段回程轮询观察到实际Y小于M3阈值时，先释放 M720，再释放 M821；记录实际 Y、阈值和释放信息。M3 继续回到安全位。
13. 到达安全 Y 后清理 M3 `InFlightWorkpiece`、任务牌和 Busy；`finally` 仅兜底释放仍持有的锁，必须保持幂等。

## 配置与页面

在 `balancing` 配置节新增两个整数配置：

```json
"m2ReleaseLocksBelowY": 0,
"m3ReleaseLocksBelowY": 0
```

1. 配置管理页面显示并允许修改、保存这两个字段。
2. 运行中的新动作读取当前内存配置；不要求重启。
3. 不增加数值范围校验、默认安全阈值推导或坐标关联校验。配置值由现场人员负责。

## 运动反馈设计

1. 在 `CraneService` 现有绝对移动与轮询路径中提供仅观察的运动状态回调/观察器。
2. 回调使用本次 `PollAxesAsync` 已获得的 `CraneStatus.YPos`，不额外启动并发 Modbus 读取循环。
3. 回调只允许向上报告实际位置；不得从回调中再发送移动、磁铁、PLC 或 Modbus 命令。
4. 平衡引擎在满足动作阶段、持锁状态和实际Y小于阈值三个条件时，调用现有幂等锁释放逻辑。
5. 释放后继续等待原始移动到目标；运动完成、超时和取消语义不变。

## 异常、应急和人工结案

1. 来源缓存转在途之前失败，来源缓存保持原样，允许既有“仍在来源”路径。
2. 转在途之后失败，工件只能按 `OnCarrier` 或 `AtTargetPendingHandoff` 处理；不能自动恢复来源缓存。
3. 人工确认“仍在来源”时，仅可在对应来源缓存为空且现场确认工件确实已回来源后恢复缓存；若新板已写入同名来源缓存，拒绝覆盖并要求人工单独处置。
4. 动平衡应急清理和人工结案不得按旧动作的来源字符串无条件删除 M817/M818/M821 缓存；必须按动作版本和在途工件处理，避免提前释放后删掉后天车新写入的缓存。
5. 正常提前释放、`finally` 兜底释放和应急残留释放必须共用持锁标记，任何一把锁最多释放一次。

## 验收

1. M2 从 M817 或 M818 取料后，来源缓存已转为 M2 在途工件；锁在去 ST008 的实际Y小于阈值前保持，满足后只释放本趟取得的锁。
2. M2 提前释放后，后天车向同一来源位置写入下一块缓存；旧 M2 完成或异常时不得删除、覆盖该新缓存。
3. M2 在得到小于阈值的实际Y前移动失败、Y 读取失败或取消时，不走提前释放；既有异常收尾保持。
4. M3 在放料、M721、研磨 FIFO 和来源账本闭环前持续持有两把锁；仅在回安全 Y 的实际Y小于阈值后释放。
5. M3 提前释放后，后天车写入新的 M821 缓存；旧 M3 的异常、应急或人工结案不得删除该新缓存。
6. M700 来源仍不伪造来源缓存；D100 读取失败仍暂停。
7. 提前释放不允许 M2/M3 在同一动作未完成时被重复派发。
8. 所有提前释放日志包含机械手、动作版本、来源、实际 Y、配置阈值及释放锁。
