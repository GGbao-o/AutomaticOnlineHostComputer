# 手动页 XYZ 原点输入显示设计

## 目标

在手动操作页的“设备选择”右侧既有状态栏中，只读展示当前选中设备的三路物理原点输入。该显示用于人工观察，不改变任何自动线或设备业务。

## 范围

- 适用于手动页全部八台设备：五台天车与三台机械手。
- 复用当前“刷新设备状态”的单次读取，不创建定时轮询、不增加新的连接或写入路径。
- 在现有 X6、X7、X11、X2 等实际反馈旁增加：
  - X3（FC01 线圈 63491）：X 轴原点信号；
  - X4（FC01 线圈 63492）：Y 轴原点信号；
  - X5（FC01 线圈 63493）：Z 轴原点信号。
- 三项分别独立读取。某项读取失败只显示该项“读取未知”，不伪造为未触发，也不覆盖其余两项的结果。
- 选中设备切换或刷新开始时，三项先清为“未知”，避免旧设备结果短暂显示到新设备。

## 显示语义

- `1`：显示“X/Y/Z轴原点已触发（X3/X4/X5=1）”。
- `0`：显示“X/Y/Z轴原点未触发（X3/X4/X5=0）”。
- 未读到或读取异常：显示“X/Y/Z轴原点读取未知”。

## 明确不做

- 不写入 PLC，不发送回原点、运动、伺服、急停、清报警或任何其他命令。
- 不参与自动派发、暂停、报警、位置锁、动作账本、工件缓存、回原点完成判断或线路启动判断。
- 不修改 D5006、D5007、D5008 的既有“回原点完成”只读显示及其语义。
- 不修改现有 X2 下压限位、X6/X7 磁铁反馈、X11 有板等业务和显示逻辑。

## 验收

1. 切换或刷新任意设备时，会读取 X3、X4、X5 三个线圈并在状态栏显示各自结果。
2. 三项状态仅用于显示；代码中不新增任何 PLC 写入或自动流程条件。
3. 三项任何一项读取失败时，该项显示未知，页面其余状态仍可正常刷新。
