# MC 完成通知位取消写后回读设计

## 目标

修复 M701、M711、M721、M731、M801、M819、M821、M824、M826 等完成通知位被 PLC 快速消费并清零后，上位机回读为 0、重复写入三次并误报失败的问题。

## 修改边界

- 保留按 `PLC IP + Port + 16位对齐M字地址` 的进程级共享锁。
- 保留“读取最新整字 → 修改目标 bit → 写回整字”，防止上位机写一个 bit 时直接覆盖同字其他 bit。
- 删除写成功后的目标 bit 回读、20ms 间隔及因回读不符产生的三次重复写。
- 不修改任何调用点、PLC 地址、bit 偏移、握手顺序、运动顺序和上层状态机。
- M801 原有“写1 → 等500ms → 写0”脉冲顺序保持不变。

## 真实失败重试

一次完整尝试包含：确认连接、必要时重连、读取最新整字、合并目标 bit、写入并取得 PLC 协议应答。

以下真实通信失败最多进行三次完整尝试：连接失败、连接断开、读取失败、读写超时、Socket/IO 异常、PLC 返回非零完成码、写入应答失败。每次重试都必须重新连接并重新读取最新整字，不得复用旧字值。

调用方主动取消不重试。三次仍失败时抛出包含 PLC、M字、目标 bit、期望值、失败阶段、次数及最后异常的最终异常，继续触发现有上层暂停、弹窗、缓存保留和锁释放逻辑。

## 日志

- 首次成功不增加底层日志。
- 失败重试记录 PLC、M字、目标 bit、期望值、失败阶段、次数和异常。
- 重连成功以及重试后恢复成功记录一次。
- 三次失败记录最终错误并抛出。

## 验证

1. M721 被 PLC 快速清零时，上位机不再回读误报或重复发送。
2. M721/M731、M819/M821/M824/M826 并发写时，同字其他 bit 不被上位机并发覆盖。
3. 模拟断线、写超时和 PLC 错误码，最多三次完整尝试后仍进入原上层异常流程。
4. M801 的 500ms 脉冲顺序保持不变。
5. 编译通过，并确认调用点、地址、bit、业务条件和运动顺序无变化。
