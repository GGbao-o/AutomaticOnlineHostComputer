# 磨石厚度报警按单机禁派发设计

## 背景与目标

西门子 TypeA 研磨机的 `40001-1/2` 是磨石厚度报警。现有上料流程在取料前检测到该信号后，把它升级为研磨引擎安全异常并暂停整个研磨引擎。该报警不改变天车、磁铁、工件位置或共享区域安全状态；在该检查点工件仍在 ST709。因此改为：报警机停止接收新的自动上料任务，其他研磨机继续调度。

## 业务规则

1. 仅 TypeA 的磨石1或磨石2报警参与本规则；任一为 `1` 即为“磨石报警”。TypeB 行为不变。
2. 每台 `GrinderContext` 保存最近一次磨石1/2报警和由此导出的“禁止新任务分配”状态。
3. `FindReadyGrinder` 必须排除禁止分配的机台；报警清除后的下一次有效 TypeA 扫描自动恢复可分配资格。
4. 已处于 Machining、WaitingForUnload 或 Unloading 的工件不受禁派发影响，仍按既有流程完成下料；禁派发仅阻止新的 Loading。
5. 上料流程在缓存出队、天车锁取得后仍需重新读取磨石报警，防止扫描与正式动作之间信号变化。若重新读取到报警，工件尚未取走：保持机台 Idle、清 PendingWorkpiece、放回 FIFO 队头、释放天车锁；不得暂停研磨引擎、不得发出安全停机弹窗。
6. 报警进入和恢复只记录一次状态转换日志；持续报警时最多按一分钟输出一次“仍停止自动分配”的心跳日志。

## 页面显示

设备总览和全流程状态复用现有研磨机卡片/站点卡片的数据源：

- 任一磨石报警时，设备总览主状态显示 `⚠ 磨石N厚度报警 · 已停止自动分配`，使用红色状态文字与红色连接标记。
- 全流程状态对应 ST703/ST704 主状态也显示同样文本和红色状态色；详细信号保留原始 `磨石1/2=0/1`。
- 信号恢复后，下一次轮询恢复现有基于请求数据、上料、下料、加工等信号的显示。

## 安全边界

- 磨石报警不是天车坐标未知、X11 未确认、持件通信失败、门锁异常或动作超时的替代处理；后者现有暂停策略不变。
- 本改动不向 PLC 写停止、复位或报警确认命令，不干预研磨机本体。
- TypeA PLC 读失败时仍按现有逻辑清除可触发的请求信号，因而不会将该机作为就绪机派发。
