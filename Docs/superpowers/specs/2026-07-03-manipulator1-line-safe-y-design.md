# 机械手1分线路安全Y设计

## 目标

机械手1是1/2号线共用设备，但送完两条线货叉后的最近安全点不同。将单一安全Y拆为：

- 1号线 ST711：Y=1000。
- 2号线 ST712：Y=11500。

减少机械手送完板后的无效长距离返回，同时保持现有业务顺序不变。

## 业务边界

- 机械手送完本线货叉后，仍先退磁、Z回零，再移动到本线路安全Y。
- 到达本线路安全Y后才写M801取料完成脉冲。
- 本线货叉状态机仍必须确认机械手到达本线路安全Y，才允许进入双头镗或SkipBoring流程。
- M801、R6101、R6102、R6103、M912、M914等信号地址和顺序不变。
- 1000与11500均已由现场确认对1/2号线前天车安全。因此前天车和主页面总安全状态将任意一个位置视为安全。
- 安全判断容差保持±10mm。

## 配置与兼容

新增 `Manipulator1Line1SafeY` 和 `Manipulator1Line2SafeY`，生产默认分别为1000和11500。保留旧 `Manipulator1SafeY` 配置字段作为兼容入口，但正常流程不再依赖该单值。配置页面分别显示两个可编辑输入框，避免含义混淆。

## 验证

- 1号线送ST711后回Y=1000，确认到位后才写M801并启动货叉状态机。
- 2号线送ST712后回Y=11500，确认到位后才写M801并启动货叉状态机。
- 前天车在机械手处于1000或11500时都通过安全检查，其他Y值继续等待。
- 编译并检查差异，确认未修改握手地址、状态机阶段或任务派发。
