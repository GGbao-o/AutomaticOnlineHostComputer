# ST010 放板标志抑制 M731 设计

## 目标

防止研磨天车5从 ST709 取板后写入 M731 使研磨上料架传送带转动时，机械手3或2号天车正在向 ST010 放板而造成落点偏差。

使用两个仅存在于上位机内存的流程标志，让研磨天车决定本趟是否跳过 M731：

- `M3St010Placing`：机械手3正在执行向 ST010 放板的最终流程。
- `Crane2St010Placing`：2号天车正在执行向 ST010 放板的最终流程。

PLC 已按现场要求修改内部握手：本趟因上述标志跳过 M731 时，上位机不等待、不补写 M731，仍可继续去目标研磨机。

## 范围

本功能只影响：

1. 机械手3和2号天车对两个内存标志的置位、清除；
2. 研磨天车5 ST709 取板后对标志的只读判断；
3. 对应运行日志、流程文档和回归测试。

不修改：

- M720 位置锁的获取、拥有、释放或 `CurrentCount`；
- 机械手3、2号天车的现有运动、M720 检查、退磁、M721 写入及研磨 FIFO 回调；
- M731 位写入方法、MC65 连接和重试行为；
- PLC 程序或现场安全互锁。

## 共享标志

增加独立的线程安全 `St010PlacementFlags` 内存对象，由 `HomeViewModel` 创建后注入机械手3所属的 `BalancingFlowEngine`、2号天车所属的 `Line1RearFlowEngine` 和 `GrindingFlowEngine`。

该对象仅保存两个原子布尔标志，提供：

- `BeginM3Placement()` / `EndM3Placement()`；
- `BeginCrane2Placement()` / `EndCrane2Placement()`；
- `Snapshot()`，返回两个标志的当前值。

它不包含 `SemaphoreSlim`、PLC 通信、坐标读取、运动调用、等待或队列操作。

## 标志生命周期

### 机械手3

1. 已持件并安全 Z 回升后，继续沿既有逻辑重新读取 M720。
2. M720=0 时保持既有持件等待，标志保持 `false`。
3. M720=1 成功后、发送机械手3 Y 轴去 ST010 命令之前调用 `BeginM3Placement()`。
4. 正常 M721 成功后可调用 `EndM3Placement()`；最终 `finally` 必须再次调用 `EndM3Placement()`，保证任意异常、取消、提前 return 或重复清理后最终值均为 `false`。

### 2号天车

1. 只在 1号线后端的短板 ST010 分支使用该标志；长板去 ST019 不触碰标志。
2. 既有 M720 最后确认成功后、发送天车2 XY 去 ST010 命令之前调用 `BeginCrane2Placement()`。
3. 正常 M721 成功后可调用 `EndCrane2Placement()`；最终 `finally` 必须再次调用 `EndCrane2Placement()`，保证任意异常、取消、提前 return 或重复清理后最终值均为 `false`。

两个 `End` 必须幂等。标志不承担动作账本、人工结案或现场工件事实的表达职责。

## 天车5 M731 决策

保持原流程：天车5确认持件后启动 Z 回安全并等待 `grinding.m731NotifyDelayMs`。

延时结束后读取一次 `St010PlacementFlags.Snapshot()`：

- 任一标志为 `true`：不写 M731，等待 Z 安全到位后直接进入目标研磨机流程；该分支是正常成功路径。
- 两个标志均为 `false`：完全保持现有逻辑，写 MC65 M731=1，并等待“Z 安全到位 + M731 写成功”后继续。

天车5只读取快照，不改变任一标志。

## 日志

记录：

- M3/天车2标志置位；
- M3/天车2标志清除（含 finally 兜底）；
- 天车5因 M3、天车2或两者标志占用而跳过 M731；
- 天车5标志全空闲时按既有方式写 M731。

跳过 M731 不记为 PLC 写入失败，不触发暂停或人工报警。

## 验证

1. M3 在最后 M720=1 后、Y 去 ST010 前置位；其 finally 清除标志。
2. 天车2仅短板 ST010 分支在 M720=1 后、XY 去 ST010 前置位；长板 ST019 不置位；其 finally 清除标志。
3. 两个标志任一为 true 时，天车5等待 Z 安全到位后继续，但不调用 M731 位写入。
4. 两个标志均为 false 时，天车5仍写 M731=1。
5. 标志对象和天车5分支不获取、释放或读取 M720 锁，也不读机械手/天车坐标。
