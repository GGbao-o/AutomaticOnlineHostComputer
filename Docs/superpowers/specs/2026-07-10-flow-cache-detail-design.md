# 全流程缓存摘要设计

## 目标

在“全流程状态”页顶部的 1 号线缓存、2 号线缓存、研磨缓存卡片中，保留原有缓存数量，并显示最多两块缓存工件的直径和长度。

## 展示规则

- 每张卡片继续显示数量。
- 缓存为空时显示“无缓存”。
- 缓存不为空时按现有 FIFO 列表顺序显示最多两条摘要：`D=147mm  L=800mm`。
- `Length <= 0` 时只显示 `D=147mm`，不显示虚假的长度值。
- 即使未来缓存数量超过两条，界面只展示前两条；数量仍反映真实总数。

## 数据与线程模型

1/2 号线前端和研磨引擎已经各自以锁保护 `WorkpieceCache` 列表来计算缓存数量。为页面增加只读快照方法：在原有缓存锁内复制列表并返回数组。主页面 ViewModel 将快照格式化为文本属性，页面仅绑定这些文本。

不读取 PLC、不建立通信连接、不修改 FIFO、不会出队或入队，也不改变任务、设备或引擎状态。快照列表现场上限为两块，且只在现有状态刷新时格式化，因此不产生可感知的性能负担。

## 文件范围

- `Service/FlowEngine/Line1FrontFlowEngine.cs`：暴露只读缓存快照。
- `Service/FlowEngine/Line2FrontFlowEngine.cs`：暴露只读缓存快照。
- `Service/FlowEngine/GrindingFlowEngine.cs`：暴露只读缓存快照。
- `Presentation/ViewModels/Home/HomeViewModel.cs`：新增三个缓存摘要绑定属性，并在既有刷新点通知属性变化。
- `Views/FlowStatus/FlowStatusView.xaml`：在三张现有缓存卡片内绑定摘要文本。

## 验证

1. 编译通过。
2. 三类缓存为空时页面显示“无缓存”。
3. 有一块且长度有效时显示直径和长度；长度缺失时只显示直径。
4. 有两块时显示两条摘要；三块及以上仍只显示两条，数量不变。
5. 静态检查确认没有新增 PLC、通信、队列写入或设备控制调用。
