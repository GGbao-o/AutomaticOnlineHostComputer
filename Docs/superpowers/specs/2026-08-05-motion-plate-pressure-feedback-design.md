# 运动参数页有板与下压反馈设计

## 目标

在“运动参数设置”页的设备选择区，补充所选机械手或天车的 X11 有板和 X2 磁铁下压限位实际反馈。

## 方案

沿用已有 X6 充磁和 X7 退磁状态卡：切换设备或用户点击刷新时，使用同一个已连接的 `CraneService` 依次读取 X6、X7、X11、X2。页面不新增定时轮询，也不发送 PLC 写入命令。

每个信号使用独立的 `bool?` 状态。`true` 与 `false` 分别代表 PLC 实际位值；任何单项读取失败都保留为 `null` 并显示“读取未知”，不能误显示为无板或下压未触发。设备切换期间，旧设备读取结果不得覆盖新设备状态。

## 语义与显示

- X11：`1=有板`、`0=无板`。
- X2：`1=下压触发`、`0=下压未触发`。X2 是磁铁物理下压限位，不称为“下压正常到位”。
- 标签置于现有“磁铁实际反馈”同一行，刷新按钮同时刷新四项状态。

## 验收

1. 刷新一次会读取 X6、X7、X11、X2 四个实际线圈。
2. 状态卡显示四项独立文本，X11/X2 的真值语义正确。
3. 单项读取失败显示未知；切换设备后不会显示旧设备结果。
4. 现有运动、充退磁命令和后台刷新策略不变。
