# 研磨下料先 Z 回原点再返回 ST709 设计

## 目标

调整天车5从研磨机下料到 ST710 后的空载收尾顺序：先完成 Z 轴回原点，再并发执行研磨机下料完成信号与天车空载 XY 回 ST709。

## 时序

前提保持不变：ST710 已退磁放料、Z 已升安全、M721 已成功写入。

1. 调用并等待 `crane.HomeZAsync(ct)` 成功返回。
2. 仅当 Z 回原点成功后，同时启动：
   - `grinder.Svc.SetUnloadDoneAsync(ct)` 的持续三秒研磨机下料完成信号；
   - 天车5空载 `MoveAbsoluteAsync(...ST709..., -1)` 的 XY 返回动作。
3. 两项均成功后，才将研磨机设为 `Idle` 并清除 `PendingWorkpiece`。

## 异常边界

- Z 回原点失败、超时或取消时，绝不启动研磨机下料完成信号或空载 XY 返回；沿用既有下料异常分支暂停引擎并保留 `Unloading` 与 `PendingWorkpiece`。
- Z 回原点成功后，两项并发任务任何一项失败时，沿用既有异常分支；不得提前回 `Idle` 或清 Pending。

## 非范围

- 不修改取料、M720 等待、退磁、M721、锁、异常归属或手动页面。
- 不改变空载 XY 返回的偏移计算。
