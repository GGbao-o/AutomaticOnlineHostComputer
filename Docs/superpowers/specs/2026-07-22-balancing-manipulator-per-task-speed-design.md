# 动平衡机械手按任务设置速度设计

## 目标

机械手2（M2）和机械手3（M3）每次开始一趟新的自动搬运任务时，按当前 `MotionConfig.manipulatorSpeeds` 写入本机三轴绝对速度、加速度和减速度；同一趟任务内的所有 Y/Z 移动、充退磁和 X11 重试不重复写速度。

## 范围

- M2：`M817/ST019` 或 `M818/ST020` 取料并送 `M710/ST008`。
- M3：`M700/ST009` 或 `M821/ST021` 取料并送 `M720/ST010`。
- 速度写入使用既有 `CraneService.SetAbsSpeedAsync`，即写 D2501~D2503、D2510~D2512、D2519~D2521 九个寄存器。
- 更新完整业务逻辑和流程总览文档，描述触发、来源优先级、锁、二次确认、X11、握手、缓存、异常和速度策略。

## 设计

1. 引擎初始化阶段只连接机械手2/3，不再把速度设置当作一次性初始化状态。
2. M2/M3 完成来源握手、工件身份与直径获取、坐标计算、取料前 X11 无残留检查后，在各自第一次 `MoveAbsoluteAsync` 前调用共享速度设置辅助方法。
3. 辅助方法每次从共享 `MotionConfig` 读取对应机械手速度并完整写入九个绝对速度寄存器；写入失败直接中断当前动作。此时尚未发出任何物理移动或充磁命令，现有 finally 会释放锁和 busy 标志。
4. 同一任务后续的 Y/Z 移动、X11 下探重试、放料和安全位返回复用本次 PLC 速度，不再重复写。
5. 正常暂停后恢复不额外写速度；恢复后的下一趟实际 M2/M3 任务会在首次物理移动前写一次，避免“恢复一次 + 首任务一次”的重复下发。

## 不变边界

- 不改变任何来源选择、PLC 握手、锁顺序、X11、磁铁、坐标、缓存、暂停或应急逻辑。
- 不在速度写入成功前发送运动命令；不在任务中途改变速度。
- M2 和 M3 可并发执行，但各自只写各自 PLC，不共享速度寄存器。

## 验收

- 每个 `M2Flow`、`M3Flow` 均恰有一次任务级速度配置，且发生在首次物理移动之前。
- 初始化阶段不再直接设置 M2/M3 速度。
- 业务逻辑文档和流程总览准确说明上述策略及完整 M2/M3 数据/信号闭环。
