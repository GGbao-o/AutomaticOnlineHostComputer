# 斜床上料前命令输出清理设计

## 目标

每次后端调度已经选定斜床并开始自动上料时，在后天车从中转架取板之前，清掉该目标斜床上一轮由上位机写入的命令/握手输出。

## 清理范围

- Modbus 斜床（ST108～ST111）：`10370～10374` 清零。
- FANUC 斜床（ST112、ST606～ST610）：`#1101～#1105` 清零。
- 不清长度、直径、堵孔及FANUC `#909` 加工模式；不清机床反馈/请求输入；不操作天车、磁铁、尾座或机床物理运动。

## 时序与失败处理

`DoLoad` 已收到经过候选筛选的 `bed` 和中转架缓存。它会先暂存该缓存、校验长度，再执行目标斜床命令输出清理；此时天车尚未获取中转架/碰撞区锁，也尚未移动或充磁。

- 清理成功：继续现有取料、送床、握手流程。
- 清理失败：将工件缓存和到达顺序恢复到原中转架，目标斜床恢复 `Idle`，释放后天车锁并结束本次派发；不取板、不写新的斜床信号。

这样避免设备旧命令未清而天车已把板取离中转架。
