# Line 1 M721 Overlap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let line 1 rear crane start ST010 post-placement Z recovery, then write M721 after a configurable delay and enqueue the workpiece immediately after M721 succeeds while Z is still returning.

**Architecture:** Add an independent line-1/ST010 completion-notification delay in the existing grinding configuration section and expose it in the configuration page. In `Line1RearFlowEngine.DoUnload`, retain all existing M817→M720 locking and M720 wait semantics, but use Z start → configured delay → M721 start → M721 success → FIFO callback → Z completion; existing exception handling continues to preserve the destination-pending state and pauses on failure.

**Tech Stack:** C#/.NET, WPF binding, JSON configuration, xUnit source-contract tests.
