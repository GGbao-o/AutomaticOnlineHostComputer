# 手动JOG定时按钮实施计划

**目标：** 仅在手动操作页增加M70～M75六向JOG，点击后置1、等待配置时长、finally置0并回读。机械手无X轴。用户已确认设计并要求直接实施，不处理断网/断电/强杀的PLC兜底。

**实现边界：** 不改Service/FlowEngine、不读写工件队列或机床业务状态、不调用线路启动/暂停/恢复。不修改原相对移动、绝对移动、停止或急停行为。HomeViewModel仅向手动VM传共享配置。

## 核对点

- 0写入不能受原取消令牌影响；写1响应未知时也复位，不能等成功后才登记收尾。
- 大于5秒的合法脉冲时长不被旧手动按钮的5秒整趟超时截断；设备IO仍有各自超时。
- 六个JOG互斥只约束新增按钮；不引入生产区域锁或业务许可。
- 不写JOG速度寄存器，使用PLC现有JOG速度；复位确认仅证明线圈为0，不代表物理位置校验。
- 用apply_patch逐文件修改，不用Python改源码。
