> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a three-zero X11 pickup failure finish physical recovery, release all locks, pause the corresponding line, and require manual confirmation on both rear-crane engines.

**Architecture:** Reuse each engine's existing `LoadHandshakeState`, catch recovery, shared-area retreat, lock release, and `OnRearCraneSafetyAlarm`. Add one explicit failure flag and one recovery summary; create the final alarm only after all lock releases so ordinary beds and ST108/ST606 share the same pause contract.

**Tech Stack:** C# 12, .NET 8, existing xUnit source-contract tests.

- [ ] **Step 1: Add the post-lock X11 pause block**

After `operation.TryRelease("RearCrane", _craneRearLock)` and before `if (pendingSafetyAlarm != null)`, add:

```csharp
if (loadState.X11PickupFailed)
{
    _paused = true;
    string x11Alarm = $"{lineName}后天车从中转架{rs}取料时，X11连续三次为0。" +
                      $"异常恢复：{loadState.X11RecoverySummary}。引擎已暂停，请人工确认中转架、磁铁、Z轴和天车位置";
    pendingSafetyAlarm = pendingSafetyAlarm == null
        ? x11Alarm
        : $"{x11Alarm}；{pendingSafetyAlarm}";
}
```

Use the existing line-specific literals (`1号线`/`2号线`) and existing `rs` variable; do not add a new runtime dependency.
