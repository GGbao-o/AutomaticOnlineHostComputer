# 2026-05-16 开发记录

## 一、DINT 字节序修正

**问题**：天车/机械手汇川 PLC 的 32 位寄存器为**小端（低字在前）**，代码之前按大端读写，导致 X 坐标显示和写入值与 PLC 不一致。

**修法**：

| 操作 | 改前（大端） | 改后（小端） |
|------|-----------|-----------|
| 读 XPos(D5018~D5019) | r[18]<<16 \| r[19] | (r[19]<<16) \| r[18] |
| 写 DINT(WriteInt32Async) | hi@startAddr, lo@startAddr+1 | **lo@startAddr**, hi@startAddr+1 |

**涉及地址**：D3102~D3107（绝对目标）、D5014~D5019（X编码器/坐标）

---

## 二、X 区输入信号读取

**问题**：充磁/退磁反馈、限位信号等 X 输入一直读不到（返 0x02 异常）。

**解决过程**：
1. 最初以为 X 区直接映射到 D63488 保持寄存器（FC03 读 16bit 字）→ 0x02
2. 改为 FC04 读输入寄存器 → 0x02  
3. **最终确认**：每个 X 点是一个独立**线圈**，功能码 **FC01**（Read Coils），地址 = **63488 + X编号**

**关键 X 点地址**：

| X编号 | 线圈地址 | 信号 | 用途 |
|:---:|------|------|------|
| X6 | 63494 | 充磁反馈 | MagnetOnAsync 确认充磁到位 |
| X7 | 63495 | 退磁反馈 | MagnetOffAsync 确认退磁到位 |
| X2 | 63490 | 磁铁下压限位 | Z轴下降到位检测 |
| X11 | 63499 | 检测有版 | 取料确认 |
| X27 | 63515 | 天车急停按钮 | 安全监控 |
| X23 | 63511 | X轴定位完成 | 伺服到位 |
| X26 | 63514 | Y轴定位完成 | 伺服到位 |
| X36 | 63524 | Z轴定位完成 | 伺服到位 |

**代码**：
```csharp
// ModbusTcpClient.cs — 新增 ReadCoilAsync (FC01)
public async Task<bool> ReadCoilAsync(int address, CancellationToken ct = default)

// CraneService.cs — ReadXBitAsync 改用 FC01
public async Task<bool> ReadXBitAsync(int address, CancellationToken ct = default)
    => await _client.ReadCoilAsync(address, ct);
```

## 三、充磁退磁优化

**改前**：固定延时等待（2秒/800ms），无反馈确认。

**改后**：
- 充磁：D4510=2 → 轮询 X6(FC01)等=1（超时3s兜底）→ D4510=0
- 退磁：D4511=2 → 轮询 X7(FC01)等=1（超时3s兜底）→ D4511=0 → 查D5029确认
- 容错：失败10次→先充磁再退磁，总上限50次

---

## 四、Z 轴下压急停 D4523

**新增寄存器**：D4523 — 下压急停状态（PLC写1，主机清0）

- `IsPressureEStopAsync()` — 查 D4523 ≠ 0
- `ClearPressureEStopAsync()` — 写 D4523 = 0
- 手动恢复流程：① D4523=0 ② 清除报警 D4514=2→0

**集成点**：`MoveAbsoluteAsync → PollAxesAsync`，Z轴下降时每500ms查D4523，触发则停止全部轴（复位D4520~D4522）

---

## 五、接液盘互锁

`MoveAbsoluteAsync` 增加了自动接液盘开关：
- Z ↓ 下降 → 移动前开接液盘（D4512=2→0）
- Z ↑ 上升 → 移动后关接液盘（D4513=2→0）

无需手动点按钮。

---

## 六、Z 轴步进下探

新增 `StepDownUntilPickupAsync(stepDistance=5, maxSteps=10)`：
- 取料时 Z 到位但未检到版 → 每次降 5mm → 查 D5029
- 最多降 10 次（50mm），检到版或用完步数返回

---

## 七、到位补偿重试

`PollAxesAsync` 首次超时时自动补偿一次：
- 未到位 → 偏差日志 → 重新触发 D4520~D4522（2→0）→ 再轮询
- 补偿后仍不到位才报超时

---

## 八、充电退磁卡片状态显示

天车卡片 Line3 用 D5029（HasRoller）显示磁铁状态：
- D5029=1 → 「充磁到位」
- D5029=0 → 「退磁到位」

之前尝试通过 D63488 X 区读，因功能码问题一直失败。现已修复（FC01）。

## 九、速度按轴独立

`SetAbsSpeedAsync` 和 `SetRelSpeedAsync` 改为每轴独立参数（9 个参数），手动面板输入框改为每轴独立：

```
绝对速X [speed][accel][decel] Y [speed][accel][decel] Z [speed][accel][decel] [应用速度]
相对速X [speed][accel][decel] Y [speed][accel][decel] Z [speed][accel][decel] [应用速度]
```
