# 天车 / 机械手运动逻辑与安全机制

> 生成日期：2026-05-13  
> 最后更新：2026-07-07
> 适用范围：全项目天车(1~5号)、机械手(1~3号)所有运动操作

---

## 一、机械手 X 轴禁用的六层防护

| 层 | 机制 |
|---|------|
| **UI 层** | `IsCraneSelected = false` → X±/X回原点/充磁/退磁/接液盘按钮 `IsEnabled=False` |
| **VM 命令层** | `MoveAxisAsync('X')` 检测到机械手 → 直接 `return` 不执行 |
| **VM 命令层** | `HomeXAsync()` / `MagnetOnAsync()` / `MagnetOffAsync()` / `DrainOpen/CloseAsync()` → 全有 `IsCraneSelected` 守卫 |
| **VM 绝对移动层** | `MoveAbsoluteAsync` 强制 `xTarget = -1` |
| **引擎调度层** | `MoveManipulatorToStationAsync` 只读 Y/Z 坐标，X 不读 |
| **PLC 层** | `MoveAbsoluteAsync` 中 `xTarget < 0` → 不写 D3102/D3103，不触发 D4522，轮询永远判 OK |

## 二、安全机制清单

| # | 机制 | 实现位置 | 作用 |
|---|------|---------|------|
| 1 | **任务前安检** | `CheckSafetyAsync` | 检查忙闲(D5006)、故障(D5009)、伺服报警(D5011)、有版(D5029)，四项全通过才放行 |
| 2 | **手动模式守卫** | `EnsureManualModeAsync` | 所有手动操作前先写 D4001=2 + D4500=2，急停除外 |
| 3 | **Z 下降安全顺序** | `MoveAbsoluteAsync` | Z↓：先走 XY → XY 到位 → 再走 Z（防工件撞下方设备） |
| 4 | **Z 上升安全顺序** | `MoveAbsoluteAsync` | Z↑：先走 Z → Z 到位 → 再走 XY（防低高度拖拽） |
| 5 | **接液盘互锁** | `MoveAbsoluteAsync` | Z↓前自动开液盘，Z↑后自动关液盘 |
| 6 | **防重入** | `AsyncRelayCommand` | 按钮命令执行中 `CanExecute=false`，防止连点重复写寄存器 |
| 7 | **2→0 脉冲规范** | 全部触发寄存器 | 写 2 触发 → 写 0 复位，PLC 不卡在触发态 |
| 8 | **超时复位** | `MoveAbsoluteAsync` finally | 绝对移动无论成功超时都在 finally 复位触发 |
| 9 | **到位超时保护** | `PollAxesAsync` | 超时后抛异常，由上层按物理状态处理，不自动重发运动 |
| 10 | **预约互斥** | `ProductionFlowEngine` | 天车/机械手去工位前先预约，防止两台同时去同一工位 |
| 11 | **工位等待** | `WaitForStationAsync` | 工位被占最多等 30s，超时放弃 |
| 12 | **退磁容错** | `MagnetOffAsync` | 10次失败→充磁再退磁，总上限50次(~25s) |
| 13 | **运动范围约束** | 配置文件 `start_x/end_x` | 数据库已有字段，引擎可校验（待接入） |

## 三、运动寄存器速查

### 绝对移动（到指定坐标）

| 步骤 | X | Y | Z | 协议 |
|------|------|------|------|------|
| 写目标坐标 | D3102~D3103 | D3104~D3105 | D3106~D3107 | FC16 DINT，低字在前 |
| 触发移动 | D4522=2 | D4521=2 | D4520=2 | FC06 INT，脉冲触发 |
| 读位置 | D5018~D5019 | D5022 | D5025 | FC03 |
| 脉冲复位 | D4522=0 (等500ms后) | D4521=0 (等500ms后) | D4520=0 (等500ms后) | FC06 INT |
| 速度 | D2501~D2503 | D2510~D2512 | D2519~D2521 | FC06 |

> 当前业务确认：D3102~D3107 是目标绝对坐标区；D4522/D4521/D4520 是 X/Y/Z 轴绝对移动触发/复位位，不承载坐标值。

> 注：Z 轴位置读取以 PLC 实际实现为准；若当前程序只读 `D5025` 单点，则请保持与代码一致，不要在文档中拆成双字。

### 页面手动按钮（相对输入，绝对执行）

页面上的 `X+ / X- / Y+ / Y- / Z+ / Z-` 按钮不直接走 PLC 原生相对运动寄存器。上位机先读取当前坐标，再根据按钮输入的距离计算新的绝对目标坐标，最后统一走绝对移动流程。

| 示例 | 当前坐标 | 页面输入 | 计算后的绝对目标 | 执行动作 |
|------|------|------|------|------|
| X+100 | (100,100,100) | X +100 | (200,100,100) | 写 D3102~D3103=200，触发 D4522=2 |
| X-80 | (100,100,100) | X -80 | (20,100,100) | 写 D3102~D3103=20，触发 D4522=2 |
| 输入目标 | 任意 | (200,100,100) | (200,100,100) | 写 D3102~D3107，触发 D4522/D4521/D4520=2 |

## 五、Z 轴特殊逻辑

```
Z ↓ 下降（取料/放料场景）：
  开接液盘 → 等500ms → 写XY目标绝对坐标并触发XY → 等XY到位 → 写Z目标绝对坐标并触发Z → 等Z到位

  `StepDownUntilPickupAsync` 当前没有生产调用方，坐标方向仍需现场确认，不作为现行取料步骤。

Z ↑ 上升（取料后提起）：
  写Z目标绝对坐标并触发Z → 等Z到位 → 写XY目标绝对坐标并触发XY → 等XY到位 → 关接液盘

Z 不变（水平移动）：
  写XYZ目标绝对坐标并触发XYZ → 等全部到位
```

### 5.1 生产流程中的“XY前确认Z=0”保护

`MoveAbsoluteAsync` 本身会根据本次目标判断Z升降顺序，但如果上层流程直接准备做水平XY横移，而上一动作异常后Z实际不在0位，就可能出现低高度横移风险。为此当前代码在以下生产入口额外调用 `EnsureZAtZeroAsync(5, ct)`：

| 场景 | 设备 | 保护动作 |
|---|---|---|
| 1号线前天车去货叉Pos3取料 | 天车1 | XY去ST713前读取Z；若绝对值超过5mm，先回Z=0；回零失败则抛异常，不横移 |
| 2号线前天车去货叉Pos3取料 | 天车3 | XY去ST714前同样确认Z=0 |
| 研磨天车去ST709取料 | 天车5 | XY去ST709前确认Z=0 |
| 研磨天车去研磨机下料取板 | 天车5 | XY去目标研磨机前确认Z=0 |

该保护只确认和回升Z轴，不控制X/Y、不控制磁铁、不吞异常。误差5mm以内视为已在安全零位。若读取Z失败或回零失败，上层按原异常流程处理。

## 七、绝对移动完整流程

```
MoveAbsoluteAsync(xTarget, yTarget, zTarget)
│
├─ 1. EnsureManualModeAsync: D4001=2, D4500=2
├─ 2. 写入本次指定轴的目标坐标
├─ 3. 若包含Z目标，读取当前Z判断升降方向；读取失败立即拒绝运动
│
├─ 4. Z↓ → 开接液盘(D4512=2→0)
│
├─ 5. 按Z方向触发:
│   ├─ Z↓: 先写 D3102~D3105(XY目标) → 触发 D4522/D4521=2 → 等500ms → 写0复位 → 等XY到位 → 再写 D3106~D3107(Z目标) → 触发D4520=2 → 等500ms → 写0
│   ├─ Z↑: 先写 D3106~D3107(Z目标) → 触发 D4520=2 → 等500ms → 写0复位 → 等Z到位 → 再写 D3102~D3105(XY目标) → 触发D4522/D4521=2 → 等500ms → 写0
│   └─ Z不变: 写 D3102~D3107(XYZ目标) → 触发 D4522/D4521/D4520=2 → 等500ms → 写0
│
├─ 6. 轮询 D5018/D5022/D5025，等全部到位(容差±5)；超时抛异常
│
└─ 7. finally: 确保全部触发位 D4520~D4522=0；Z↑ → 关接液盘(D4513=2→0)
```

## 八、引擎自动调度流程

```
MoveCraneToStationAsync(craneNo, stationCode)
│
├─ 1. 查 station_coords 缓存 → 读 x/y/z 坐标
├─ 2. 预约工位 → 已被占? → 等待30s → 超时放弃
├─ 3. CheckSafetyAsync → 不通过? → 返回失败
├─ 4. SetAbsSpeedAsync → 写9个速度寄存器
├─ 5. MoveAbsoluteAsync → 执行绝对移动(含Z轴安全逻辑)
├─ 6. 读到位坐标 → 偏差日志
└─ 7. finally: 释放工位预约；坐标仅实时显示，不写数据库
```

|--------|------|------|-----------|

## 十一、天车 XYZ 偏移补偿

### 概念
各天车（机械手）的机械安装可能存在微小误差。machine 表中 `x_dis/y_dis/z_dis` 字段作为该天车的全局偏移量，所有绝对位移自动叠加。

### 规则
- 查找：天车编号 → 站号映射（1→ST901, 2→ST102, 3→ST104, 4→ST904, 5→ST905）
- 工位坐标（如 ST709=890,250,1507）→ 加上天车偏移
- 安全高度 Z=400 → **不加**偏移
- -1（不动该轴）→ **不加**偏移
- 默认值: 0（无偏移）

### 示例
研磨天车 x_dis=5, y_dis=0, z_dis=-2，目标 ST709(890,250,1507)
→ 实际走 (895, 250, 1505)

## 十四、研磨自动流程引擎（GrindingFlowEngine）

> 代码：`Service/GrindingFlowEngine.cs`

### 主循环（每 500ms 一轮）

```
① 扫描4台研磨机状态（Modbus 读 DI/R 寄存器）
② 卡死检测（Loading/Unloading/WaitingForUnload 超 60s → Idle）
③ 加工监视（Machining + PLC请求下料=1 → WaitingForUnload）
④ 【优先】下料（WaitingForUnload + 天车空闲 → 取料放到 ST710）
⑤ 【次之】上料（Idle+请求数据=1 + 天车空闲 → ST709 取料送研磨机）
```

**调度策略：下料优先于上料。** 研磨机被成品工件占着必须优先卸出，否则无法接下一单。
加工期间天车空闲时可服务其他研磨机，多台可并行加工。

### 工件缓存生命周期

```
写入缓存 → 上料出队 → PendingWorkpiece
  ├─ 充磁前失败 → 工件还在ST709架上 → 自动放回缓存
  ├─ 充磁后失败 → 工件已在天车上 → ⚠ 需人工处理
  └─ 下料完成 → PendingWorkpiece = null（正常清空）
```

### 研磨机优先级

ST701(新代1) > ST702(新代2) > ST703(西门子1) > ST704(西门子2)

### 天车串行化

天车 #5 一次只能充磁一个工件，用 `SemaphoreSlim(1,1)` 序列化所有研磨流程。

### 取料送料 12 步流程

1. 写工件参数(直径/版孔/长度) + 数据传输完成(3s 长信号) — TypeA:40011-9 / TypeB:R7311
2. 天车 XY+Z 到上料架 ST709(890, 250, Z计算值)
3. 充磁取料（轮询 X6=1 确认充磁到位）
4. Z 升到安全高度(绝对Z=400，safeZHeight 配置值)
5. XY 移到研磨机位置（如 ST701=3654,339）
6. 等研磨机请求上料 + 门打开(门开=1)
7. Z 下降到装料位置(研磨机Z - d/2) — **此步 200ms 轮询 D4523 下压信号**
8. 上料到达锁紧位置(3s 长信号) — TypeA:40011-10 / TypeB:R7312
9. 等尾座锁紧完成 — TypeA:40001-11 / TypeB:R7303
10. 退磁释放工件（轮询 X7=1 + D5029=0 确认）
11. Z 升到安全高度(绝对Z=400，safeZHeight 配置值)
12. 上料完成(3s 长信号) — TypeA:40011-11 / TypeB:R7313

### 下料 11 步流程

1. 等待研磨机门打开
2. XY+Z 到研磨机取料位置(研磨机Z - d/2)
3. 充磁取工件（先吸住，防止松开尾座后工件掉落）
4. 下料到达位置(3s长信号) — TypeA:40011-12 / TypeB:R7314
5. 等待尾座松开完成 — TypeA:40001-13 / TypeB:R7305
6. Z 升到安全高度(绝对Z=400)
7. XY 移到下料架 ST710(25000, 360)
8. Z 下降到下料位置(1300 - d/2)
9. 退磁放下工件
10. Z 升到安全高度
11. 下料完成(3s长信号) — TypeA:40011-13 / TypeB:R7315 → 研磨机空闲

### Z 轴计算公式

#### 研磨线（已完成）

| 场景 | 公式 | 说明 |
|------|------|------|
| 上料架取料 Z | `rackZ - Round[(d/2/zFactor1)+(d/2/zFactor2)]` | 1506 - 226 = 1280 (d=205) |
| 研磨机装料 Z | `grinderZ - Round(d/2)` | |
| 下料架放料 Z | `rackZ - Round[(d/2/zFactor1)+(d/2/zFactor2)]` | 1300 - 226 = 1074 (d=205) |
| 安全高度 | 绝对 Z = `safeZHeight` (默认 400) | |

#### 1号线 / 2号线（新建，公式已确认）

| 工位 | Z 公式 | 说明 |
|------|------|------|
| 总上料架/货叉/打号机/中转架/动平衡架/研磨上料架 放取料 | `rackZ - Round[(d/2/zFactor1)+(d/2/zFactor2)]` | 同研磨取料公式 |
| 双头镗/锦州斜床/沈阳斜床 装料 | `machineZ - Round(d/2)` | 同研磨机装料公式 |
| 安全高度 | 绝对 Z = `safeZHeight` (默认 400) | |

> 系数: zFactor1=0.9537, zFactor2=0.866, 从 `motion_settings.json` grinding 段读取

### Y 轴计算公式（斜床专用）

天车送工件到斜床时，Y 轴目标 = 斜床数据库 Y + 偏移量：

```
Y偏移 = (顶尖距离 - 工件长度) / 2 + 版孔移动距离
Y目标 = 斜床Y坐标 + Y偏移
```

| 参数 | 配置位置 | 默认值 | 说明 |
|------|------|:---:|------|
| 顶尖距离 | `motion_settings.json` skewBed.centerDistances[站号] | 1450 mm | 每台斜床独立配置 (ST108~ST112, ST606~ST610) |
| 大孔移动距离 | skewBed.largeBoreOffset | 运行配置 | 堵孔=100(大孔) 时使用 |
| 小孔移动距离 | skewBed.smallBoreOffset | 运行配置 | 堵孔=70(小孔) 时使用 |

代码调用:
```csharp
int yOffset = _cfg.SkewBed.ComputeYOffset(stationCode, length, plugHole);
int targetY = skewBedY + yOffset;
```

例：ST108顶尖距离、工件长度和大孔偏移均取运行配置，代入同一公式；文档不再固定写死某台斜床的标定值。

### 下压急停处理

Z 下降时 200ms 快轮询 D4523：
```
D4523=1 → ① D4518=2→0 急停伺服
         → ② 复位 D4520/D4521/D4522=0
         → ③ 抛出 PressureStopException
         → ④ 引擎暂停 + 卡片 Line5 显示"⚠ 下压急停！需手动恢复"
```

恢复步骤：① 写 D4523=0 ② 清除报警 D4514=2→0 ③ 重新启动引擎

数量显示在控制栏右下角。可清空缓存。
