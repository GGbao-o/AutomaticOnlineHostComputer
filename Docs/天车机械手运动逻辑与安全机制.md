# 天车 / 机械手运动逻辑与安全机制

> 生成日期：2026-05-13  
> 最后更新：2026-05-16  
> 适用范围：全项目天车(1~5号)、机械手(1~3号)所有运动操作

---

## 一、机械手 X 轴禁用的六层防护

| 层 | 机制 |
|---|------|
| **UI 层** | `IsCraneSelected = false` → X±/X回原点/充磁/退磁/接液盘按钮 `IsEnabled=False` |
| **VM 命令层** | `MoveAxisAsync('X')` 检测到机械手 → 直接 `return` 不执行 |
| **VM 命令层** | `HomeXAsync()` / `MagnetOnAsync()` / `MagnetOffAsync()` / `DrainOpen/CloseAsync()` → 全有 `IsCraneSelected` 守卫 |
| **VM 绝对移动层** | `MoveAbsoluteAsync` 强制 `xTarget = -1` |
| **引擎调度层** | `MoveManipulatorToStationAsync` 只读 Y/Z 坐标，X 不读 |
| **PLC 层** | `MoveAbsoluteAsync` 中 `xTarget < 0` → 不写 D3102/D3103，不触发 D4522，轮询永远判 OK |

## 二、安全机制清单

| # | 机制 | 实现位置 | 作用 |
|---|------|---------|------|
| 1 | **任务前安检** | `CheckSafetyAsync` | 检查忙闲(D5006)、故障(D5009)、伺服报警(D5011)、有版(D5029)，四项全通过才放行 |
| 2 | **手动模式守卫** | `EnsureManualModeAsync` | 所有手动操作前先写 D4001=2 + D4500=2，急停除外 |
| 3 | **Z 下降安全顺序** | `MoveAbsoluteAsync` | Z↓：先走 XY → XY 到位 → 再走 Z（防工件撞下方设备） |
| 4 | **Z 上升安全顺序** | `MoveAbsoluteAsync` | Z↑：先走 Z → Z 到位 → 再走 XY（防低高度拖拽） |
| 5 | **接液盘互锁** | `MoveAbsoluteAsync` | Z↓前自动开液盘，Z↑后自动关液盘 |
| 6 | **防重入** | `AsyncRelayCommand` | 按钮命令执行中 `CanExecute=false`，防止连点重复写寄存器 |
| 7 | **2→0 脉冲规范** | 全部触发寄存器 | 写 2 触发 → 写 0 复位，PLC 不卡在触发态 |
| 8 | **超时复位** | `MoveAbsoluteAsync` finally | 绝对移动无论成功超时都在 finally 复位触发 |
| 9 | **到位补偿** | `PollAxesAsync` | 首次未到位自动补偿一次重试 |
| 10 | **预约互斥** | `ProductionFlowEngine` | 天车/机械手去工位前先预约，防止两台同时去同一工位 |
| 11 | **工位等待** | `WaitForStationAsync` | 工位被占最多等 30s，超时放弃 |
| 12 | **退磁容错** | `MagnetOffAsync` | 10次失败→充磁再退磁，总上限50次(~25s) |
| 13 | **运动范围约束** | 配置文件 `start_x/end_x` | 数据库已有字段，引擎可校验（待接入） |

## 三、运动寄存器速查

### 绝对移动（到指定坐标）

| 步骤 | X | Y | Z | 协议 |
|------|------|------|------|------|
| 写目标坐标 | D3102~D3103 | D3104~D3105 | D3106~D3107 | FC16 DINT，低字在前 |
| 触发移动 | D4522=2 | D4521=2 | D4520=2 | FC06 INT，脉冲触发 |
| 读位置 | D5018~D5019 | D5022 | D5025 | FC03 |
| 到位复位 | D4522=0 | D4521=0 | D4520=0 | FC06 INT |
| 速度 | D2501~D2503 | D2510~D2512 | D2519~D2521 | FC06 |

> 当前业务确认：D3102~D3107 是目标绝对坐标区；D4522/D4521/D4520 是 X/Y/Z 轴绝对移动触发/复位位，不承载坐标值。

> 注：Z 轴位置读取以 PLC 实际实现为准；若当前程序只读 `D5025` 单点，则请保持与代码一致，不要在文档中拆成双字。

### 页面手动按钮（相对输入，绝对执行）

页面上的 `X+ / X- / Y+ / Y- / Z+ / Z-` 按钮不直接走 PLC 原生相对运动寄存器。上位机先读取当前坐标，再根据按钮输入的距离计算新的绝对目标坐标，最后统一走绝对移动流程。

| 示例 | 当前坐标 | 页面输入 | 计算后的绝对目标 | 执行动作 |
|------|------|------|------|------|
| X+100 | (100,100,100) | X +100 | (200,100,100) | 写 D3102~D3103=200，触发 D4522=2 |
| X-80 | (100,100,100) | X -80 | (20,100,100) | 写 D3102~D3103=20，触发 D4522=2 |
| 输入目标 | 任意 | (200,100,100) | (200,100,100) | 写 D3102~D3107，触发 D4522/D4521/D4520=2 |

### PLC 原生相对运动（保留/调试）

| 步骤 | 寄存器 |
|------|--------|
| 距离 | D4501 |
| 方向(1正/2负) | D4502 |
| X触发 | D4505=2 |
| Y触发 | D4504=2 |
| Z触发 | D4503=2 |

> D4501~D4505 表示 PLC 原生相对运动能力，写2触发即可，PLC 自行管理复位。当前页面按钮主流程不直接使用。

### DINT 32位寄存器（小端字节序）

| 读地址 | 含义 | 字节序 | 代码公式 |
|--------|------|:---:|------|
| D5014~D5015 | X绝对编码器 | 低字在前 | `(r[15]<<16) \| r[14]` |
| D5016~D5017 | X原点清零值 | 低字在前 | `(r[17]<<16) \| r[16]` |
| D5018~D5019 | X显示坐标 | 低字在前 | `(r[19]<<16) \| r[18]` |

| 写地址 | 含义 | 字节序 |
|--------|------|:---:|
| D3102~D3103 | X绝对目标 | D3102=低字, D3103=高字 |
| D3104~D3105 | Y绝对目标 | D3104=低字, D3105=高字 |
| D3106~D3107 | Z绝对目标 | D3106=低字, D3107=高字 |

> 汇川 PLC 的 32 位有符号整数均为小端字节交换（低字在前）。目标坐标写入 D3102~D3107；D4522/D4521/D4520 仅作为 X/Y/Z 绝对移动触发/复位位。

## 五、Z 轴特殊逻辑

```
Z ↓ 下降（取料/放料场景）：
  开接液盘 → 等500ms → 写XY目标绝对坐标并触发XY → 等XY到位 → 写Z目标绝对坐标并触发Z → 等Z到位
  ↘ 到位后如果没检到版 → StepDownUntilPickupAsync（每次降5mm，最多10次）

Z ↑ 上升（取料后提起）：
  写Z目标绝对坐标并触发Z → 等Z到位 → 写XY目标绝对坐标并触发XY → 等XY到位 → 关接液盘

Z 不变（水平移动）：
  写XYZ目标绝对坐标并触发XYZ → 等全部到位
```

## 六、速度体系

| 场景 | 速度寄存器 | 配置来源 | 默认值 |
|------|-----------|---------|:---:|
| 绝对移动（三轴同步） | D2501~D2503 / D2510~D2512 / D2519~D2521 | `motion_settings.json` absMove | 500 mm/s |
| 页面手动按钮（相对输入，绝对执行） | D2501~D2503 / D2510~D2512 / D2519~D2521 | `motion_settings.json` absMove | 500 mm/s |
| PLC 原生相对运动（保留/调试） | D2504~D2506 / D2513~D2515 / D2522~D2524 | `motion_settings.json` relMove | 300 mm/s |
| JOG 点动 | D2507~D2509 / D2516~D2518 / D2525~D2527 | `motion_settings.json` jogMove | 200 mm/s |
| Z 快慢两段 | D2528~D2530 | `motion_settings.json` zAxis | 低速段待接入 |

> 说明：当前文档以页面业务逻辑为准，页面手动按钮采用“相对输入，绝对执行”，因此和自动调度一样使用绝对移动速度参数。PLC 原生相对运动和 JOG 参数仍保留，用于调试、扩展或 PLC 原生模式。`D2528~D2530` 为 Z 轴降低速预留，当前文档仅登记地址，不改变现有动作逻辑。

## 七、绝对移动完整流程

```
MoveAbsoluteAsync(xTarget, yTarget, zTarget)
│
├─ 1. EnsureManualModeAsync: D4001=2, D4500=2
├─ 2. 读当前 Z，判断升降方向
│
├─ 3. Z↓ → 开接液盘(D4512=2→0)
│
├─ 4. 写目标坐标与触发顺序:
│   ├─ Z↓: 先写 D3102~D3105(XY目标) → 触发 D4522/D4521=2 → 等XY到位 → 复位D4522/D4521=0 → 再写 D3106~D3107(Z目标) → 触发D4520=2
│   ├─ Z↑: 先写 D3106~D3107(Z目标) → 触发 D4520=2 → 等Z到位 → 复位D4520=0 → 再写 D3102~D3105(XY目标) → 触发D4522/D4521=2
│   └─ Z不变: 写 D3102~D3107(XYZ目标) → 触发 D4522/D4521/D4520=2
│
├─ 5. 轮询 D5018/D5022/D5025，等全部到位(容差±5)
│   └─ 首次未到位 → 补偿重试一次
│
└─ 6. finally: 复位全部触发位 D4520~D4522=0；Z↑ → 关接液盘(D4513=2→0)
```

## 八、引擎自动调度流程

```
MoveCraneToStationAsync(craneNo, stationCode)
│
├─ 1. 查 station_coords 缓存 → 读 x/y/z 坐标
├─ 2. 预约工位 → 已被占? → 等待30s → 超时放弃
├─ 3. CheckSafetyAsync → 不通过? → 返回失败
├─ 4. SetAbsSpeedAsync → 写9个速度寄存器
├─ 5. MoveAbsoluteAsync → 执行绝对移动(含Z轴安全逻辑)
├─ 6. 读到位坐标 → 偏差日志
└─ 7. finally: 释放工位预约 + 位置写库
```

## 十、研磨机自动连接

启动时自动连接4台研磨机（ST701~ST704），每5s轮询状态并更新全厂状态卡：

| 研磨机 | 站号 | 类型 | 读的寄存器 |
|--------|------|------|-----------|
| 研磨机1 | ST701 | 新代 TypeB | R7308(状态), R7301(请求数据), R7306(加工中), R7307(门开) |
| 研磨机2 | ST702 | 新代 TypeB | 同上 |
| 研磨机3 | ST703 | 西门子 TypeA | 40001 DI: bit0(报警), bit14(加工中), bit9(请求数据) |
| 研磨机4 | ST704 | 西门子 TypeA | 同上 |

IP 从数据库 `machine` 表读取，无 IP 则跳过。连接失败自动退避重连（5s→30s）。

| 反馈 | X点 | 线圈地址 | 读法 |
