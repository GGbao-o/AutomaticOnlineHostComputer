## 二、寄存器完全速查（天车/机械手）

> 协议：Modbus TCP，端口 502，汇川 PLC  
> 所有天车、机械手（共8台）寄存器地址完全相同，通过不同 IP 区分

### 2.1 状态读取（FC03，D5000~D5029 批量读30个）

| D编号 | 信号 | 类型 | 说明 |
|:---:|------|:---:|------|
| D5005 | 天车当前任务编号 | INT | |
| D5006 | 天车忙闲 | INT | 0=空闲, 1=忙 |
| D5007 | 状态机步骤 | INT | |
| D5008 | 模式 | INT | 0=待机, 1=自动, 2=手动 |
| D5009 | 故障 | INT | 0=正常, 1=故障 |
| D5010 | 运行条件缺失 | INT | 位图 |
| D5011 | 伺服报警 | INT | 位图 |
| D5012 | PLC伺服指令报警 | INT | 位图 |
| D5013 | PLC报警 | INT | 位图 |
| D5014~D5015 | X绝对编码器 | DINT | 小端，低字在前 |
| D5016~D5017 | X原点清零值 | DINT | 小端 |
| D5018~D5019 | X显示坐标 | DINT | 小端 |
| D5020 | Y绝对编码器 | INT | |
| D5022 | Y显示坐标 | INT | |
| D5023 | Z绝对编码器 | INT | |
| D5025 | Z显示坐标 | INT | |
| D5029 | 有版信号 | INT | 1=有版 |

> **DINT 字节序**：32位有符号整数，小端（低字在前）。例：D5018=低16bit, D5019=高16bit  
> **读取公式**：`(r[高位]<<16) | r[低位]`

### 2.2 手动操作区（D4500~D4523，FC06 单寄存器写）

| D编号 | 常量名 | 功能 | 写入方式 |
|:---:|--------|------|------|

| D4507 | `D_ManualHomeY` | Y回原点触发 | 2→0 脉冲 |
| D4508 | `D_ManualHomeX` | X回原点触发 | 2→0 脉冲 |
| D4510 | `D_ManualMagnetOn` | 充磁触发 | 2→0 脉冲 |
| D4511 | `D_ManualMagnetOff` | 退磁触发 | 2→0 脉冲 |

| D4514 | `D_ManualClearAlarm` | 清除报警 | 写2，等状态恢复后写0 |

| **D4522** | `D_ManualXAbsMove` | **X绝对移动触发/复位** | **写2 → 等500ms → 写0（脉冲模式）** |

> **D4520~D4522 不承载坐标值！** 它们是触发/复位位。目标坐标写入 D3102~D3107，然后脉冲触发移动。  
> D4501~D4505 是 PLC 原生相对运动能力（保留/调试用），当前页面按钮主流程不使用，统一走绝对坐标模式。

### 2.3 绝对移动 — 目标坐标与触发

**目标坐标（D3102~D3107，FC16 批量写，DINT 小端）：**

| 轴 | 地址 | 字节序 |
|:---:|------|:---:|
| X | D3102~D3103 | D3102=低字, D3103=高字 |
| Y | D3104~D3105 | D3104=低字, D3105=高字 |
| Z | D3106~D3107 | D3106=低字, D3107=高字 |

**触发流程：**
```
① 写 D3102~D3107 目标坐标（FC16）
② 写触发位 D452x=2（FC06）
③ 等 500ms
④ 写 D452x=0 复位
⑤ 轮询 D5018/D5022/D5025 等轴到位（容差±5）
```

## 三、各设备通信协议

### 3.1 锦州斜床 — Modbus TCP（ST108、ST109、ST111、ST110）

**协议**：Modbus TCP，端口 502，单元 ID=1，FC03 读 / FC06 写

**读信号（FC03，INT16 单寄存器）：**

| 地址 | 信号 | 说明 |
|:---:|------|------|
| 10350 | 准备就绪 | 0=未就绪, 1=就绪 |
| 10351 | 操作模式 | 0=手动, 1=人工自动, 2=全自动 |
| **10352** | **请求数据** | 1=CNC 请求上位机下发参数 |
| **10354** | **请求上料** | 1=CNC 请求天车送料 |
| **10355** | **尾座顶紧信号** | 1=已顶紧（夹紧完成） |
| **10357** | **请求下料** | 1=加工完成，请求天车取料 |
| **10358** | **尾座张开到位** | 1=已张开 |
| 10339 | 设备报警 | 0=正常, 非0=故障 |

**参数读取（FC03，FLOAT 双寄存器，IEEE 754 单精度，高字在前）：**

| 地址 | 信号名称 | 寄存器数 |
|:---:|------|:---:|
| 10300~10301 | 版长 | 2 |
| 10302~10303 | 堵孔尺寸 | 2 |
| 10304~10305 | 成活直径 | 2 |

**写信号（FC06，INT16，写1导通，PLC 执行后自动复位）：**

| 地址 | 信号 | 说明 |
|:---:|------|------|
| 10370 | 加工模式 | 1=粗车, 2=精车, 3=研磨, 4=粗精, 5=精磨, 6=粗精磨 |
| **10371** | **远程尾座顶紧** | 天车上料到位，触发夹紧 |
| **10372** | **远程启动** | 天车上料完成，PLC 关门加工 |
| **10373** | **远程尾座张开** | 天车下料到位，触发张开 |
| **10374** | **尾座停止** | 天车下料完成 |

> ⚠️ 锦州斜床没有独立的"数据传输完成"信号——上位机写完参数后，PLC 通过检测寄存器值变化自动进入下一状态。

### 3.2 沈阳斜床 — FANUC FOCAS（ST112、ST606~ST610）

**协议**：FANUC FOCAS，TCP 端口 8193，通过 Fwlib32.dll 读写宏变量

**读信号（宏变量，CNC→上位机）：**

| 宏变量 | 信号 | 说明 |
|:---:|------|------|
| #1000 | 机床准备就绪 | 0=未就绪, 1=就绪 |
| **#1001** | **请求数据** | 1=请求上位机下发参数 |
| **#1002** | **请求上料** | 1=请求天车送料 |
| **#1003** | **尾座夹紧到位** | 1=已夹紧 |
| **#1004** | **请求下料** | 1=加工完成，请求取料 |
| **#1005** | **尾座分开到位** | 1=已分开 |
| #1006 | 自动门开 | 0=门关, 1=门开 |
| #1012 | 机床操作模式 | 0=手动, 1=人工自动, 2=全自动 |

**写信号（宏变量，上位机→CNC）：**

| 宏变量 | 信号 | 说明 |
|:---:|------|------|
| #800 | 版辊长度 | FLOAT, mm |
| #801 | 成活直径 | FLOAT, mm |
| #802 | 堵孔尺寸 | FLOAT, mm |
| #909 | 加工模式 | 1~6（同锦州斜床） |
| **#1101** | **数据下发完成** | 写1导通 |
| **#1102** | **天车上料到位** | 写1导通 |
| **#1103** | **天车上料完成** | 写1导通 |
| **#1104** | **天车下料到位** | 写1导通 |
| **#1105** | **天车下料完成** | 写1导通 |

**级联清零规则：**
```
写 #1102=1 → 先清 #1101=0
写 #1103=1 → 先清 #1102=0
写 #1104=1 → 先清 #1103=0
写 #1105=1 → 先清 #1104=0
```

**核心 API（Fwlib32.dll）：**
```csharp
cnc_allclibhndl3(ip, 8193, timeout, out ushort hndl)  // 连接（句柄类型必须是 ushort！）
cnc_freelibhndl(ushort hndl)                           // 断开
cnc_rdmacro(ushort hndl, index, 10, out ODBM)          // 读宏变量
cnc_wrmacro(ushort hndl, index, 10, ref ODBM)          // 写宏变量
```

### 3.3 双头镗 — Modbus TCP（ST103/ST402）

**协议**：Modbus TCP，R 区寄存器实际地址 = `R*2+1`。本轮下料完成时执行 `R6108=1 → R6102=0 → R6104=0`，R6108保持为1，不等待设备反馈。

| 地址 | 方向 | 信号 | 握手规则 |
|:---:|:---:|------|------|
| R6101 | 读 | 请求数据 | =1 → 上位机下发参数；SkipBoring 出队前也必须为1 |
| R6102 | 写 | 数据下发完成 | 写1 |
| R6103 | 读 | 请求上料 | =1 → 可以写 M912 送料 |
| R6104 | 写 | 上料完成 | M912送料回待机且M900=0后写1 |
| R6107 | 读 | 请求下料 | =1 → 可以写 M913 取料 |
| R6108 | 写 | 下料完成 | M913到Pos3且M900=1后写1 |

R6105/R6106/R6109/R6110 不再使用。

**参数地址：**

| R地址 | Modbus地址 | 参数 | 说明 |
|:---:|---:|------|------|
| R2041 | 4083 | 长度 | 16位无符号整数原值，不乘100 |
| R2043 | 4087 | 直径 | ERP值*100，整数 |
| R2044 | 4089 | 左堵厚 | ERP值*100，整数 |
| R2045 | 4091 | 右堵厚 | ERP值*100，整数 |
| R2046 | 4093 | 内孔锥度 | ERP/手工任务值，按*100写入（16位整数） |
| R2047 | 4095 | 内孔成活/版孔 | ERP值*100，整数 |
| R2048 | 4097 | 圆角大小 | ERP/手工任务值，按*100写入（16位整数） |

#### TypeB — 新代数控（ST701~ST702）

**UnitId = IP 末段**（如 192.168.2.90 → 90）  
**Modbus 地址 = R 编号 × 2 + 1**（例：R7301 → 14603）

| R编号 | Modbus地址 | 方向 | 信号 | 写入方式 |
|:---:|------|:---:|------|------|

## 四、交互流程

### 4.1 1号线完整流程

```
S1 任务创建(UI) → S2 机械手1取料(ST007→ST711)
→ S3 货叉分派(→双头镗) → S4 双头镗握手(加工)
→ S5 前天车取料→打号机 → S6 前天车放中转架
→ S7 后天车取中转架→斜床 → S8 后天车动平衡分流
```

**线路分派规则**：主页面任务只有点击启动后才进入总上料架全局FIFO。全局调度器在M800=1时按每条线斜床 `maxWorkpieceLengthMm` 能力、线路运行状态和前端压力选择；达到大直径阈值时强制1号线。派发后必须读取到M800=0才允许识别下一块，即使全局FIFO暂时为空也继续观察复位，避免在批次间隔漏掉M800下降沿。
**动平衡判断**：版长 ≥ 800mm → 需要动平衡 / < 800mm → 直接放研磨机上料架  
**货叉路径**：正常工件经双头镗后由M913送Pos3；SkipBoring由M914直接送Pos3。前天车只从Pos3取料。

**全局调度器状态判读**：

```text
未启动任务：只在主页面，不在全局FIFO
等待总上料架派发：任务已启动并进入全局FIFO
等待上一块M800复位：防重复派发门尚未解除，FIFO为空也继续读取M800
等待新板M800=1：复位门已解除，尚无新物理板
已派发N号线前端缓存：任务数据已绑定到当前物理板，后续由对应线路引擎处理
```

不允许用“全局FIFO为空时直接清除M800等待状态”来优化空闲逻辑；如果上一块仍未取走且M800保持1，后续任务会把同一块板再次派发。

### 5.1 绝对移动完整流程

```
MoveAbsoluteAsync(xTarget, yTarget, zTarget)
│
├─ 1. EnsureManualModeAsync: D4001=2, D4500=2
├─ 2. 写入本次指定轴的目标坐标

│
├─ 4. Z↓ → 开接液盘（D4512=2→0, 等500ms）
│
├─ 5. 按Z方向触发:
│   ├─ Z↓: 写 D3102~D3105(XY目标) → 写 D4522/D4521=2 → 等500ms → 写0复位
│   │       → 轮询 D5018/D5022 等XY到位 → 写 D3106~D3107(Z目标) → 写 D4520=2 → 等500ms → 写0
│   ├─ Z↑: 写 D3106~D3107(Z目标) → 写 D4520=2 → 等500ms → 写0复位
│   │       → 轮询 D5025 等Z到位 → 写 D3102~D3105(XY目标) → 写 D4522/D4521=2 → 等500ms → 写0
│   └─ Z不变: 写 D3102~D3107(XYZ目标) → 写 D4522/D4521/D4520=2 → 等500ms → 写0
│
├─ 6. 轮询 D5018/D5022/D5025，等全部到位(容差±5)；超时抛异常
│
└─ 7. finally: 确保全部触发位 D4520~D4522=0；Z↑ → 关接液盘（D4513=2→0）
```

### 5.2 Z 轴安全顺序

```
Z↓ 下降（取料/放料场景）：
  开接液盘 → 等500ms → 先走XY → XY到位后再走Z

  `StepDownUntilPickupAsync` 当前没有生产调用方，坐标方向仍需现场确认，不作为现行取料步骤。

Z↑ 上升（取料后提起）：
  先走Z → Z到位后再走XY → 关接液盘

Z不变（水平移动）：
  三轴同时走
```

**为什么**：Z↓ 时先 XY 后 Z 防止工件水平移动时撞下方设备；Z↑ 时先 Z 后 XY 防止低高度水平拖拽。

### 5.3 充磁/退磁

**充磁**：D4510=2 → 等800ms → D4510=0 → 轮询 X6(63494)=1 确认  
**退磁**：D4511=2 → 等800ms → D4511=0 → 轮询 X7(63495)=1 + D5029=0 确认  
**容错**：退磁失败 10 次后先充磁再退磁（防卡死），总上限 50 次（~25s）

### 5.4 有版检测

**地址**：X11 = 63497 (FC01 Read Coils)  
**时机**：充磁后等 3 秒

```
充磁 → Task.Delay(3000) → ReadXBitAsync(63497)
  X11=1 → ✓ 吸到工件, 继续
  X11=0 → 退磁 → Z↓5mm → 充磁 → 等3s → 再查（最多2次）
```

### 5.5 下压急停处理

X2（63490）磁铁下压限位变1 → PLC 自动写 D4523=1 → 上位机轮询到：

```
D4523=1 → ① D4518=2→0 急停伺服
         → ② 复位 D4520/D4521/D4522=0
         → ③ 抛出 PressureStopException
         → ④ 引擎暂停 + 显示"⚠ 下压急停！需手动恢复"

恢复步骤: ① 写 D4523=0 ② D4514=2→0 清除报警 ③ 重新启动引擎
```

> ⚠️ 下压信号不是异常！是工件接触的正常停止条件。触发后按上述恢复流程处理即可继续。

## 六、安全机制

### 6.1 锁机制总览

| 锁名称 | 保护区域 | 参与者 | 类型 |
|------|------|------|:---:|
| `_craneLock` | 天车#5（研磨） | 研磨流程上下料 | SemaphoreSlim(1,1) |
| `_transferRackLock1` | 1号线中转架×3 | ST901 + ST102 | SemaphoreSlim(1,1) |
| `_transferRackLock2` | 2号线中转架×3 | ST104 + ST904 | SemaphoreSlim(1,1) |
| `_manipulatorLock` | 前段引擎 | 机械手取料 + 货叉分派 | 独立锁 |
| `_craneFrontLock` | 前段引擎 | 前天车完整流程 | 独立锁 |
| `_craneRearLock` | 后段引擎 | 后天车完整流程 | 独立锁 |
| 机械手安全位检查 | ST010 / ST021 区域 | 后天车 + 机械手2/3 | 轮询等待 |

**锁获取顺序（防死锁）**：中转架操作 → `_transferRackLock`；研磨区操作 → 机械手安全位检查（可重试）→ 天车移动（内部已有 `_craneLock`）。不同 crane 锁对象互不嵌套，无死锁环。

### 6.2 中转架安全设计（防前后天车碰撞）

前天车放、后天车取，共用同一 `_transferRackLock`：

```
前天车 (放):
  ① 读 M811~M813 找空位
  ② await _transferRackLock.WaitAsync()
  ③ XY→选中坐标, Z降, 退磁, Z升
  ④ _transferRackLock.Release()

后天车 (取):
  ① 读 M811~M813 找有版位
  ② await _transferRackLock.WaitAsync()
  ③ XY→选中坐标, Z降, 充磁, Z升
  ④ _transferRackLock.Release()
```

### 6.3 机械手 X 轴禁用的六层防护

| 层 | 机制 |
|---|------|
| **UI 层** | `IsCraneSelected=false` → X±/X回原点/充磁/退磁/接液盘按钮 `IsEnabled=False` |
| **VM 命令层** | `MoveAxisAsync('X')` 检测到机械手 → 直接 `return` |
| **VM 命令层** | `HomeXAsync()` / `MagnetOnAsync()` / `MagnetOffAsync()` → 全有 `IsCraneSelected` 守卫 |
| **VM 绝对移动层** | `MoveAbsoluteAsync` 强制 `xTarget = -1` |
| **引擎调度层** | `MoveManipulatorToStationAsync` 只读 Y/Z 坐标，X 不读 |
| **PLC 层** | `xTarget < 0` → 不写 D3102/D3103，不触发 D4522，轮询永远判 OK |

### 6.4 安全检查清单

| # | 机制 | 实现位置 | 作用 |
|---|------|---------|------|
| 1 | **任务前安检** | `CheckSafetyAsync` | 检查忙闲(D5006)、故障(D5009)、伺服报警(D5011)、有版(D5029)，四项全通过才放行 |
| 2 | **手动模式守卫** | `EnsureManualModeAsync` | 所有手动操作前先写 D4001=2 + D4500=2 |
| 3 | **Z 下降安全顺序** | `MoveAbsoluteAsync` | Z↓：先 XY 后 Z（防工件撞下方设备） |
| 4 | **Z 上升安全顺序** | `MoveAbsoluteAsync` | Z↑：先 Z 后 XY（防低高度拖拽） |
| 5 | **接液盘互锁** | `MoveAbsoluteAsync` | Z↓前自动开，Z↑后自动关 |
| 6 | **防重入** | `AsyncRelayCommand` | 按钮命令执行中 `CanExecute=false` |
| 7 | **2→500ms→0 脉冲规范** | 全部触发寄存器 | PLC 不卡在触发态 |
| 8 | **超时复位** | `MoveAbsoluteAsync` finally | 无论成功超时都复位触发位 |
| 9 | **到位超时保护** | `PollAxesAsync` | 超时后抛异常，不自动重发运动 |
| 10 | **预约互斥** | `ProductionFlowEngine` | 天车/机械手去工位前先预约 |
| 11 | **工位等待** | `WaitForStationAsync` | 工位被占最多等 30s，超时放弃 |
| 12 | **退磁容错** | `MagnetOffAsync` | 10次失败→充磁再退磁，总上限50次 |
| 13 | **运动范围约束** | 数据库 `start_x/end_x` | 待接入 |

### 6.5 前后天车共享区互斥

后天车从转移架取料到斜床到位期间，前天车不能去打号机：

```
标志: RearCraneInTransit = true（ProcessRearCraneAsync 开始时设）
前天车: while(RearCraneInTransit) 等最多 300s → 后天车离开共享区后继续
清除点: SkewBedHandshakeAsync 完成后（异常时兜底清除）
```

### 6.6 研磨机安全要点

- **门安全**：天车上下移动前必须确认 `门开=1`（TypeA: 40001-15 / TypeB: R7307）
- **磨石报警**：仅 TypeA 有（40001-1/40001-2），请求数据阶段检查，任一报警暂停流程
- **心跳检测**：TypeA 连续两次读 40001-8（间隔500ms），值有变化=PLC 存活
- **工件缓存**：充磁前失败→自动放回缓存；充磁后失败→⚠ 需人工处理

### 7.2 斜床优先级

```
ST108 > ST109 > ST110 > ST111 > ST112
(锦州 Modbus 优先，沈阳 FANUC 兜底)
```

主循环每次扫描 5 台斜床，找第一台状态为 Idle + 已连接的分配给下一个工件。

### 7.3 研磨机调度策略

- **下料优先于上料**：成品占着研磨机必须优先卸出
- **加工期间天车不空闲等**：可服务其他研磨机的上料/下料
- **多台可并行加工**
- **天车 #5 串行化**：`SemaphoreSlim(1,1)` 序列化所有研磨流程

### 7.4 预约互斥

天车/机械手去工位前先 `ReserveStation(stationCode, ownerName)`，防止两台同时去同一工位。同一预约者重复预约同一工位幂等。操作完成或异常后在 finally 中 `ReleaseStation`。

### 7.5 天车 XYZ 偏移补偿

machine 表中 `x_dis/y_dis/z_dis` 字段作为该天车的全局偏移量，所有绝对位移自动叠加：

- 工位坐标 → 加上天车偏移
- 安全高度 Z=400 → **不加**偏移
- -1（不动该轴）→ **不加**偏移
- 默认值: 0

## 八、配置参数与公式

### 8.1 motion_settings.json 关键配置

| 段 | 参数 | 默认 | 含义 |
|----|---------|:---:|------|
| absMove | defaultSpeed | 500 | 绝对移动速度(mm/s) |
| absMove | tolerance | 5 | 到位容差(mm) |
| absMove | timeoutMs | 30000 | 移动超时(ms) |
| relMove | defaultSpeed | 300 | 相对点动速度(mm/s) |
| grinding | zFactor1 | 0.9537 | Z公式系数1 |
| grinding | zFactor2 | 0.866 | Z公式系数2 |
| grinding | safeZHeight | 400 | 安全高度(绝对Z) |
| skewBed | centerDistances | {ST108:1450, ST109:1450, …} | 各斜床顶尖距离(1号线DB站号) |
| skewBed | largeBoreOffset | 93 | 大孔偏移(mm) |
| skewBed | smallBoreOffset | 55 | 小孔偏移(mm) |
| safety | magnetOffMaxRetries | 50 | 退磁最大重试 |
| engine | stationWaitTimeoutMs | 30000 | 工位等待超时(ms) |

### 8.2 Z 轴计算公式

| 工位类型 | 公式 |
|------|------|
| 上料架取料 / 货叉 / 打号机 / 中转架 / 动平衡架 / 研磨上料架 | `rackZ - Round[(d/2/zFactor1)+(d/2/zFactor2)]` |
| 双头镗 / 斜床 装料 | `machineZ - Round(d/2)` |
| 安全高度 | 绝对 Z = 运行配置 `safeZHeight` |

> 系数 zFactor1=0.9537, zFactor2=0.866，从 `motion_settings.json` grinding 段读取

### 8.3 Y 轴计算公式（斜床专用）

```
Y偏移 = (顶尖距离 - 工件长度) / 2 + 版孔偏移
Y目标 = 斜床Y坐标 + Y偏移

顶尖距离: motion_settings.json skewBed.centerDistances[站号]（默认 1450 mm）
版孔偏移: largeBoreOffset（大孔）/ smallBoreOffset（小孔），从配置文件读取
```

例：ST108的顶尖距离和大小孔偏移均从运行配置读取，文档不固定写死标定值。
