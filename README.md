# Automatic Online Host Computer

这是一个新的 WPF .NET 8 项目骨架，用于自动线上位机的主界面、天车管理、机器管理、控制器管理、工艺管理和通信测试页。

## 当前内容
- WPF 主窗口框架
- 左侧导航
- 主页面看板布局
- 4 个管理页占位
- 通信测试页占位
- 深色现代 UI 风格

## 运行方式
在 Visual Studio 2022 中打开 `AutomaticOnlineHostComputer.csproj` 或将其加入解决方案后启动即可。
